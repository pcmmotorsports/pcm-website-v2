## 4. 修法:三個選項,而**只有一個是工程可以自己決定的**

```
甲  丙(DB CHECK 只收嚴 name)  ⇒ 🔧 工程可做。今天 0 列被擋(§2)。
    · 改什麼:ALTER TABLE public.shipments ADD CONSTRAINT shipments_recipient_name_not_blank
              CHECK (NOT pcm_b2_is_blank(recipient_snapshot->>'name'))
      🔵 用既有的 pcm_b2_is_blank —— 同一張表已經有 5 條約束在用它, 不自己發明一套
      🔬 那支的本體我唯讀讀出來了(讀 pg_proc.prosrc, 沒呼叫它 —— pcm_readonly 對它沒有 EXECUTE):
           btrim(translate(COALESCE(t,''), E'\t\n\r\v\f' || U&'\00A0' || U&'\3000', '       ')) = ''
         ⇒ NULL 與【7 種空白字元】都算空(含 NBSP U+00A0 與全形空格 U+3000)
         🟢 正式庫本體與 repo `20260805170000:56-70` 逐字相同 ⇒ 兩邊沒有漂移
      🛑 而那支的 COMMENT 自己警告:「改這支等於同時改那四條守門的語意」
         ⇒ 📌 **本片【只新增第 5 個消費端, 一個字都不改那支函式】** —— 不碰既有四條的語意
    · 為什麼:今天擋 name 的是【應用層兩處】, 而 DB 是最後一道。繞過應用層的寫入路徑

    · 影響:既有 4 列**推定全過** —— 🛑 我量的是 `btrim` 後的長度, 不是 `pcm_b2_is_blank` 本身
              (`pcm_readonly` 對它沒有 EXECUTE ⇒ 呼叫不了)⇒ 📌 **那一格是【推的】, 不是【量的】。**
              而貼板當下的前置閘會用真的那支函式再問一次(§4-b ⑪)。

    · rollback:ALTER TABLE public.shipments DROP CONSTRAINT shipments_recipient_name_not_blank;
```

### 🔴 而 ⑩ 我第一次跑是【零判別力,而它看起來像過了】
第一次跑 ⑩ 之前我剛把電話清成 `''`(⑦)⇒ 那條「順手收嚴 phone」的假約束**根本建不起來**

✅ 修法:**加一格前置條件斷言**(「那條假約束真的建起來了嗎」+ 先把三欄補回真值),再跑一次才是真的。
🎯 **⇒ 又一次同一族:一個沒測到的格子,長得跟一個通過的格子一模一樣。**

### ⚠️ 這一輪證不到什麼
1. **鑽機不是正式庫** —— 它的 `shipments` 是空表 + 我們自己寫的種子。我證的是**這支 SQL 的行為**,不是「貼到正式庫會發生什麼」。
2. **沒測併發** —— `ADD CONSTRAINT` 與同時進行的建箱撞在一起會怎樣,我沒造。
3. **沒測大表** —— 4 列。§4 甲那段的天花板(AEL + 當場全表重驗)仍然只是讀出來的,不是量出來的。
4. **兩層的空白集合一不一樣,我沒量** —— ③④ 只證 DB 那一層守得住(見表內訂正)。

### 🔵 而 codex 有一顆 must-fix 是【錯的】—— 記下來,因為它差點讓我去改一支共用函式
codex 主張 PostgreSQL 把 `E'\v'` 解成**字母 `v`** 而非 VT ⇒ 名字 `v` 會被誤判成空白。
🔬 **我在 PG 17 實測(而它自己標了「本次 PG 連線遭沙箱拒絕,未宣稱實跑」)**:
```
E'\v' 的 ascii ⇒ 11   ·  E'\v' = 'v' ⇒ f  ·  E'\v' = chr(11) ⇒ t
pcm_b2_is_blank('v') ⇒ f · ('vvv') ⇒ f · ('Vivi') ⇒ f   ⇒ 字母 v 不會被誤判
pcm_b2_is_blank(chr(11)) ⇒ t                            ⇒ 真的 VT 守得到
translate 兩端長度 7 = 7                                 ⇒ 沒有錯位
🟢 正對照 ('') ⇒ t · ('  ') ⇒ t · ('王大明') ⇒ f
```
📌 **⇒ 那顆 must-fix 不成立。而它的形狀值得記:一個【從文件推出來的】結論,
與一個【量出來的】結論,在 finding 清單裡長得一模一樣** —— 差別只在它自己標了那一句。
