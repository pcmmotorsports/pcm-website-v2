# 計畫：車款清單讀不到時，商品頁的選車入口與提示文案

- 日期：2026-09-23
- 施工窗：前台窗（worktree `/Users/sean_1/pcm-ops`）
- 來源：Fable 審 `~/pcm-mailbox/fable-901-車款驗不了文案-R2-20260923.md` 的 nit N-2。Sean 2026-09-23 選甲＝另開一片修。
- 前一片（已合進 `origin/dev ef0d4de69`）處理的是「網址指名了一台車而清單讀不到」那半；**本片處理的是「網址沒有車款、而清單讀不到」那半**，兩者不重疊。
- 狀態：**只有計畫，還沒改程式。**

## 1. 現在客人會看到什麼（2026-09-23 本機 production build 實測）

商品頁在「車款清單讀不到」時，畫面上有兩個問題：

| 看到的東西 | 為什麼是問題 |
|---|---|
| 一句「車款清單暫時無法載入，請稍後再試或**改用自行輸入**」 | 「改用自行輸入」那條路在**帳號的愛車頁**才有（`app/account/vehicle/actions.ts`），**商品頁沒有**。等於叫客人去做一件他在這一頁做不到的事。 |
| 「選擇車款，確認是否適用」這個入口照常顯示 | 點開之後廠牌清單是**空的**，而且**沒有任何說明**（實測選項 0 個、沒有空狀態文字）。客人只會看到一個打不開東西的選單。 |

實測數字（`/products/probe-extreme-4`，清單讀不到）：
`[role="alert"]` 1 則＝上面那句；`.pfc-expand` 1 個＝選車入口；點開廠牌欄後 `.vsc-option` **0 個**、沒有空狀態字樣。

## 2. 怎麼重現

1. 起本機鑽機：`bash scripts/storefront-probe/up.sh`
2. 讓車款清單真的壞掉：
   ```
   PGPASSWORD=postgres psql -h 127.0.0.1 -p 55533 -U postgres -d postgres -Atc "alter function public.get_vehicle_taxonomy_base() rename to get_vehicle_taxonomy_base_off; alter function public.get_vehicle_taxonomy() rename to get_vehicle_taxonomy_off;"
   ```
3. **一定要先清掉網站快取再起 server**（`rm -rf apps/storefront/.next/cache`），否則看不到這個狀態 ——
   車款資料有「上一份好資料」機制（`lib/single-flight-stale.ts`），讀不到時會回上一份好的，而那一份是**正常資料**
   ⇒ 畫面完全正常。🔴 **這一點本身就是實測踩到的**：沒清快取那一次，頁面顯示的是「此商品適用 Yamaha YZF-R7」。
4. 開 `http://localhost:3020/products/probe-extreme-4`（網址**不要**帶 `?vehicle=`）。
5. 測完把函式改名回去。

> 也可以走客人的路徑到同一個狀態：在帶車款的網址上按「移除車款條件」，清掉之後就是本片這個畫面。

## 3. 改成什麼

1. **商品頁那一句換成商品頁版本**：去掉「或改用自行輸入」，改成「車款清單暫時無法載入，請稍後重新整理再試一次。」
   - 列表頁那一句維持原樣（`VEHICLE_TAXONOMY_UNAVAILABLE`），因為列表頁的語境不同，而且那句是既有拍板字面。
   - 做法：新增一個商品頁專用字串，不去改共用那一個。
2. **清單讀不到時，商品頁的選車入口收起來**：不要讓客人點開一個空的選單。那一區改成只留上面那句說明。
   - `ProductFitmentCheck` 需要知道「清單是讀不到，不是這一頁不需要」⇒ 由 `ProductPage` 把 route 的 `vehicleTaxonomyFailed` 傳下去（與前一片的 `vehicleUnverified` 同一個來源，只是不要求網址帶車款）。
3. **不改的**：適用車款表（那是商品自己的資料，讀得到就照顯示）、購物車行為（本來就不帶車）、網址。

### 為什麼不用「留著入口但在選單裡顯示一句空狀態」

客人在那個狀態下**做不了任何事**——清單讀不到，選了也選不出東西。留著入口只是把失望往後延一步。
一個看得見的缺（入口不見、旁邊有一句說明）比一個點開是空的選單清楚。

## 4. 會不會動到已拍板的規則

| 已拍板的 | 本片有沒有動到 |
|---|---|
| 「認不得的車不撿選車紀錄裡的舊車、列 3 台同廠牌建議」（Sean 2026-09-22） | **沒有**。那條講的是「清單讀得到而裡面沒有這台」，本片講的是清單讀不到。 |
| 「車款清單讀不到時畫面不留舊車、三邊一致」（Sean 2026-09-23） | **沒有**，本片是它的延伸：把「網址沒有車款」那半也補齊。 |
| 「車款清單暫時無法載入，請稍後再試或改用自行輸入」這個字面（2026-09-06 Sean 拍甲） | **列表頁那一句不動。** 只在商品頁改用另一句，理由是那條「自行輸入」的路在商品頁不存在 —— 這是 `products-message-state.tsx:50-56` 已經寫下的同一種判斷（分類與品牌那兩句當初也因為沒有自行輸入而去掉尾巴）。 |

⚠️ 若主視窗或 Sean 認為「商品頁換字」也算改拍板字面，停下等裁示再做；我的判斷是不算，理由如上。
