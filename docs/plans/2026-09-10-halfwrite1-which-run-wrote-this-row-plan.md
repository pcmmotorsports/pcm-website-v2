## 2. 受詞釘住 —— 「半寫入」是**哪一層**(三種修法完全不同,板列只講了一種)

```
🔴 不是  一個 DB 交易內的半套      —— 每一批自己是一個交易, 交易本身是原子的
🔴 不是  多張表之間的不一致        —— upsertBatched 一次只打一張表
✅ 是    【同一次同步的多個交易之間】—— 500 列一批, 批與批之間沒有任何東西綁著
         ⇒ 第 1..k 批已 commit · 第 k+1 批回捲 · 第 k+2.. 批從來沒被送出去
🔵 而 runAtomicGroups(變體群)是同一個形狀, 只是單位從「批」變成「群」
```
📌 **⇒ 修法不能往「加交易」那個方向想** —— 交易已經是對的,缺的是**跨交易的紀錄**。
