## 3. 多久跑一次
既有六條 pg_cron(實查 `cron.schedule` 字面):
```
pcm-order-ineligible-gate  */2      pcm-settle-sweep       */2
pcm-email-sweep            */5      pcm-capture-recheck    */10
pcm-expire-unpaid-orders   0 * * * *   pcm-anomaly-alert    0 1 * * *
```
🔵 **建議 `*/10`(與 capture-recheck 同頻)**。理由:
　 · 它補的是**罕見競態**, 不是熱路徑 ⇒ 不需要 `*/2`
　 · 而它**必須比 `pcm-anomaly-alert`(一天一次)密** —— 否則告警信會先報出一個
