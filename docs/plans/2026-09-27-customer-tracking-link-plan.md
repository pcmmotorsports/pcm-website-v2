# 給客人的物流追蹤連結 —— plan（鐵則 8，等 Sean 批）

> 2026-09-27 網站施工窗「進度 86」寫。主視窗派工：Sean 選了下一階段「給客人的物流追蹤連結」。
> 這件會改出貨信的內容（寄信類），所以先寫 plan，不改程式。

## 一句話

新竹物流的公開查詢頁**沒辦法用連結直接打開某一件包裹**：客人要自己輸入 10 碼貨號，還要填圖片驗證碼。
所以能做到的是「給客人單號＋一個連到新竹查詢頁的按鈕」，客人到了那一頁還要自己貼上單號、輸入驗證碼。
出貨信現在已經有單號，客人訂單頁現在什麼都沒有。

## 2. 客人會看到什麼（推薦做法：甲）

**出貨通知信**（只有新竹物流的包裹加這一行，自取自送、順豐不加）：

```
貨運:新竹物流
追蹤碼:1234567890
查詢配送進度:https://www.hct.com.tw/Search/SearchGoods_n.aspx(請輸入上面的追蹤碼)
```

單號更正信同樣在「正確的貨運單號」下面加這一行。

**客人訂單頁**（已出貨才出現；分批出貨就每一箱列一行）：

```
新竹物流  追蹤碼 1234567890  〔複製單號〕
〔到新竹物流查詢〕   ← 開新分頁到新竹查詢頁，需自行貼上單號並輸入驗證碼
```

- 自取／自送的箱寫「本批為自取／自送，無追蹤碼」，不給按鈕。
- 物流商不是新竹（例如順豐）時只列單號，不給按鈕，等查到順豐的查詢頁再補。
- 稿上寫「送達後收起來」，但**我們沒有送達資料**，所以做不到；出貨之後就一直顯示。
- 作廢的箱不顯示。
