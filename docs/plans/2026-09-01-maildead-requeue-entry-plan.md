```

   📌 而兩邊都沒有壞 —— 寄送側不再重試是對的, 排信側防重複寄也是對的。**病在交集。**
```
✅ **DB 那一半已經在正式庫上**:`admin_requeue_dead_email(uuid)`

⇒ 📌 **做這個入口, 正好就是那個改動。⇒ 兩列一起做, 不分開。**
