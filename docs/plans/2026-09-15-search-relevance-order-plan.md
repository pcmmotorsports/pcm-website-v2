## 4. 改什麼

### 4-1 `storefront_search_product_ids`(DROP + CREATE,回傳多一欄)
- `RETURNS TABLE(id uuid, is_exact boolean, tier smallint)`:
  - `tier` 0 = 料號完全相符;1 = 每個詞都在(折疊後的)標題 + 副標,或品牌名(詞長 ≥ 3);2 = 部分詞;3 = 其他
  - 命中集合(哪些商品會出現)**一字不動**,只加欄位與改 `ORDER BY`
- `ORDER BY tier, 無圖, price_general DESC NULLS LAST, id`(無圖 = `pcm_card_image_is_placeholder(images->>0)`)
- 回傳形狀改了 ⇒ `DROP FUNCTION` + `CREATE FUNCTION` + REVOKE/GRANT 照 192 那一代還原(anon / authenticated / service_role)
- 🔴 不改 `pcm_search_fold`、不改索引

### 4-2 目錄 RPC 兩支(以 20260916120000 為底 CREATE OR REPLACE)
- `kw` CTE 多拿 `k.tier`;推薦排序第一鍵從「完全命中」換成「`tier`」(只在推薦 + 有關鍵字時)
- 其餘鍵序不動:`tier → fit_rank → no_img → 既有推薦鍵`
- 價格排序 / 最新排序:維持今天(不看相關度)

### 4-3 不動
- TS 不用改(S2);`catalog_facet_counts` 不排序、不用改;板 192 的折疊與命中規則不動
