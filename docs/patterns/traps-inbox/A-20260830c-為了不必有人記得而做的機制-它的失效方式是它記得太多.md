## 第一層:自動跟上,跟到了不該跟的

`scripts/866-rail-cap-verify.sh` 為了不再依賴人工維護的清單,把
「掃描**全部** migration 的 `ALTER TABLE public.order_manual_refunds …` 並**原樣重播**」
做成機械式的。它的註解**自誇**(逐字):

> 「⇒ 之後誰再加一支 ALTER,本檔**自動**跟上,不必有人記得回來改。」

📌 而那段自誇不是空話 —— 它是**為了修一個真的病**才寫的:
前一版用 `head -4` 取那三個作廢欄的 ALTER(**位置式**)⇒ 後面的 ALTER 一律不會進來,
而 token 自檢只找 `voided_at` ⇒ **切漏了照樣全綠**。它同一段還寫著:
「**規矩要變成程式,不是變成註解**」。**那個改動是對的。**

🔴 **而 2026-08-30 一支完全合法的新 ALTER 把它弄紅了**:

```
D3-d 加了兩句   ALTER TABLE public.order_manual_refunds ENABLE ALWAYS TRIGGER …;
機械掃描原樣接進 schema.sql  ⇒  而那個 trigger 在那個時點還不存在
⇒ ERROR: trigger "order_manual_refunds_immutable_bu" … does not exist
⇒ 整份 schema 套不起來, 那支 harness 從 PASS=48 變成連跑都跑不起來
```

**它不是漏掉東西,是【多收了東西】。而多收的來源正是那個「自動跟上」。**

📌 **⇒ 那段掃描的用途是【重建表的形狀】,而 `ENABLE TRIGGER` 不是形狀,是【接線】。**
自動化把「所有 `ALTER TABLE <這張表>`」當成同一類東西 —— 而它們不是。

## 🔴 第二層:為了修「多收」而加的過濾器,失效方向會**反過來**

第一版過濾器(我寫的):

```python
if re.search(r'\b(EN|DIS)ABLE\b[^;]*\bTRIGGER\b', stmt, re.I):
    continue          # 句中出現 ENABLE TRIGGER ⇒ 整句跳過
```

**codex R2 給的可執行反例**:

```sql
ALTER TABLE x ADD COLUMN c text, ENABLE TRIGGER foo;   -- 合法的【一句兩動作】
```

⇒ 舊寫法把它**整句 `continue`** ⇒ **連那個欄一起漏掉**
⇒ 而**schema 照樣套得起來、照樣印綠**,只是少一欄。

🔴 **兩層的可觀察性完全不同,這是本條的重點**:

| | 訊號 |
|---|---|
| 第一層(多收) | **schema 套不起來** ⇒ 當場紅、指得出行號 ⇒ **它會來找你** |
| 第二層(少收) | **schema 套得起來、少一欄** ⇒ 全綠 ⇒ **沒有任何人會來告訴你** |

📌 **⇒ 一個為了修「它多收了」而加的過濾器,它自己的失效方向是「少收」——
而少收那一側,正好是本檔第一版就踩過、而且已經把教訓寫在自己註解裡的那個坑**
(位置式 `head -4` ⇒ 切漏了照樣全綠)。
🔴 **同一支檔、同一種失效方向、第二次。** 而第二次是**在修第一次的路上**發生的。

**收窄後的寫法**(動作清單**每一項都是**佈線才跳過):
```python
_m = re.match(r'\s*ALTER\s+TABLE\s+(?:IF\s+EXISTS\s+)?(?:ONLY\s+)?\S+\s+(.*);\s*$', stmt, re.I | re.S)
if _m:
    _acts = [a.strip() for a in _m.group(1).split(',')]
    if _acts and all(re.match(r'(EN|DIS)ABLE\b.*\bTRIGGER\b', a, re.I) for a in _acts):
        continue
```

## 判別動作(兩個問題,缺一不可)

```
① 對一個「自動跟上 / 不必有人記得」的機制:
   問「它跟上的東西裡, 有沒有一種是它【不該】跟的?」
   —— 它的分母是【語法上長得像的全部】, 而你要的是【語意上同一類的那些】。
      這兩個集合不相等, 而它們的差在【第一次有人寫出新形狀】的那天才顯形。

② 對任何為了修「它多收了」而加的過濾器:
   問「這個過濾器【少收】的那一側, 有沒有訊號?」
   —— 多收會來找你(它壞給你看);少收不會(它安靜地少一格)。
   🔴 而修「多收」的人正在看著紅色, 那個紅色會讓他覺得自己在把事情變好
      —— 那是最不會去想「我會不會修過頭」的時刻。
```
