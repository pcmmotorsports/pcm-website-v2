## 一把讀錯欄位的尺,會把全部歸成「要開檔」—— 而那看起來像一個**誠實的未知**

> 線【DB】`-db` 2026-09-06 深夜。實錘:`⟦f3-PROBEDEGRADED⟧` 第三方複驗那一發。

### 發生了什麼

鑽機跑完 `ok=278 fail=57`。板列自己標著一個「未做」——
上一個人逐字寫「**那 62 我沒有逐支開檔**」。我接手要補那一格,於是寫了一把歸類尺:

```python
fails = [l for l in lines if l.startswith('FAIL')]
for l in fails:
    if re.search(r'前置閘|先貼|尚未|還沒', l): cat['① 前置閘']+=1
    elif re.search(r'does not exist', l):     cat['② 物件不存在']+=1
    ...
    else:                                     cat['⑤ 其他(要開檔)']+=1
```

輸出:

```
FAIL 行 = 57
   ⑤ 其他(要開檔)   57
```

**57 支全部掉進「其他」。**

### 為什麼

`FAIL` 那一行**只有檔名**:

```
FAIL /Users/…/supabase/migrations/20260712183000_products_catalog_page_public.sql
```

而**理由在另一行**:

```
psql:/Users/…/20260712183000_products_catalog_page_public.sql:106: ERROR:  relation "public.product_fitments_effective" does not exist
```

⇒ 我的正規式**讀的是沒有理由的那一行**。改成「每支 FAIL 配它自己的第一個 `ERROR`」之後:

```
配到率 57/57
③ 前置閘明文拒收 31 · ⑥ 其他 14 · ② 它要的物件還沒被建 8 · ① 平台擴充沒裝 4
```

### 🔴 而這個坑真正的形狀,不是「分類錯了」

一把**分類錯**的尺會印出一個**可疑的分佈**(例如「權限 57 支」)⇒ 有人會問「怎麼可能全是權限」。
而一把**讀錯欄位**的尺印的是 **「其他 57 支」= 「我不知道」**。

📌 **「我不知道」讀起來永遠是安全的。**
🛑 **它不會引起任何人的懷疑,因為它沒有做出任何宣稱。**

⇒ 🎯 **一個錯的分類會被質疑;一個誠實的未知不會。**
⇒ 而它的代價一模一樣:那 57 支**仍然沒有被歸類**,而板上會多一句「已歸類:全部待開檔」。

### 判別式(可機械執行)

寫完一把歸類尺,在看結論之前先問:

> **「全部落在同一格」的那一格,是不是【兜底那一格】?**

· 是 ⇒ 🔴 **先假設尺沒接上**,不要假設世界真的長那樣。
· 而檢查方法是**打開原始資料看那一格的樣本** —— 我這次就是印了三行 `FAIL` 才看到它只有檔名。

🔵 **連帶**:一把歸類尺的兜底格應該**印出樣本**,不要只印數字。
本支修完之後每一格都帶一個例句,而**那正是我第一版沒有的東西**。

### 這一條與哪些已記的不同

· `feedback_a-number-moving-the-right-way-stops-inquiry`(往好的方向走的數字最不會被回頭查)——
  **表親而不是同一件**:那一條講的是**一個好消息**;這一條講的是**一個非結論**。
  📌 好消息會讓人停止查證;**而「我不知道」讓人根本不覺得有東西要查。**
· traps-neighbours 前 8 名最高分 **0.186**,無同族 ⇒ 開新條。
