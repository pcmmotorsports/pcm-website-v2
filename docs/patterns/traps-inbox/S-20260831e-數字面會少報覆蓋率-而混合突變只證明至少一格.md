# 數字面會少報覆蓋率;而一發混合突變只證明【至少一格】被守住

> 線【出貨】`-1e` · 2026-08-31 · 兩格都是**我自己的尺**騙了我一次

## 一、數字面(grep)少報覆蓋率

我要知道 9 個 pass-through 欄位有沒有被斷言守住。第一把尺是**數字面**:
```
python 掃 724 支測試檔, 找 (res|result)\.<欄位名>
⇒ pendingDoubleChargeCandidateCount 命中 **0**
🔵 負對照 現造欄位名 ZZQ_NOSUCH_FIELD_8831 ⇒ 0 (尺不是恆真)
```
**而我後來對它下突變 ⇒ 突變【被殺掉】(rc=1)。**

📌 **⇒ 那把尺少報了。** 一個欄位可以沒有任何**具名**的 `res.X` 斷言,
而被別的**行為**斷言(例如 `alerted` 的門檻)間接守住。
🔴 **⇒ 數字面是【代理】,突變是【實物】。兩把尺方向相反,不要互相追認。**
⚠️ 而少報的方向是「我以為沒守住」⇒ 我會去補一條多餘的斷言 —— **代價低。**
若反過來(多報)代價才高;**這一格今天沒有量到多報,未數。**

## 二、🔴 一發混合突變只證明【至少一格】

我一度把四個欄位**一起**突變成常數:
```
四格一起  ⇒ rc=1 · Tests 1 failed | 80 passed (81)
```
**如果只跑那一發,我會判「這四格有守住」。**
逐格重跑之後:
```
pendingDoubleChargeCandidateCount  rc=1 ✅ 殺得掉
orderRefundsStuckCount             rc=0 🔴 活著
orderRefundsStuckOvernightCount    rc=0 🔴 活著
orderRefundsManualFailedCount      rc=0 🔴 活著
⇒ 一殺三活
```
📌 **⇒ 一發混合突變證明的是「這一組裡至少有一格被守住」,不是「每一格」。**
**而它印出來的 `rc=1` 與「四格都被守住」那個世界,長得一模一樣。**
✅ 補完斷言後逐格重跑 ⇒ **四格全部 rc=1。**

## 📎 與正本既有那條的關係(相反方向,兩條並存)

正本已記:**「一發突變同時紅多格 ⇒ 後面那幾格【沒有】被證到」**。
🔵 **那條講【一因多果】(一發突變讓很多格紅, 而那些紅不獨立);**
**本條講【多因一果】(很多處突變只換來一格紅, 而那一格被讀成全部)。**
⇒ **兩條的解法相同:一次只動一個地方。而它們的誤讀方向相反。**

## ⚠️ 射程

```
· 「少報」只量到一個實例(1/9 個欄位)⇒ 它的頻率**未數**。
· 我沒有量過反方向(數字面【多報】覆蓋率)有沒有發生。**未數。**
```
