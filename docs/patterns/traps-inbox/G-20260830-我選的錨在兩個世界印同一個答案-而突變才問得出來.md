## 發生什麼

丁 要做的事:**每一頁都要有頁首與頁尾**,續頁才認得出是哪一張單。
我寫了一道守門 `pagesMissingRunningChrome(pages, {head, foot})`,頁首的錨我選了 **「訂單編號」**
—— 因為跨頁頁首印的逐字就是「出貨明細單 訂單編號 PCM-… · 箱號 …」。

它綠了。三個世界(5/6/7 項)每一頁都命中。

**然後我照規矩跑了一發突變**:把 `.pd-runhead{display:table-header-group}` 改成 `display:block`
(= 頁首不再逐頁重複)、**重 build**、再跑。

```
預期：第 2 頁缺頁首 ⇒ 紅
實際：🔴 全 綠
```

## 為什麼

第 2 頁的**客服說明**裡就有那四個字 —— 逐字:

> 收到商品後有任何問題…請掃描左方 QR Code 加入官方 LINE 帳號,並提供本單上的**訂單編號**。

⇒ **那個錨命中的從來不是頁首。** 它命中的是一段**永遠都在第 2 頁**的文案。

📌 **⇒ 錨在【頁首活著】與【頁首被關掉】兩個世界印同一個答案。**

(那是另一個方向的假答案)⇒ 比對前要把連續空白壓成一個空格。

## 🔴 同族第二個成員(同一晚, `n=2`):**量點住在一個不會隨我的改動而移動的區域裡**

同夜稍晚,我要比較「改了版面之後,底部區有沒有離開紙底」。我量的是**最下面一列墨水離紙底多遠**:

```
flex 版   819px 高 · 最下墨水列 790 ⇒ 距紙底 10.5mm
block 版  819px 高 · 最下墨水列 790 ⇒ 距紙底 10.5mm   ← 一模一樣
```
⇒ 我差點判「兩版沒有差別」。

🔴 **而那 10.5mm 量到的是【頁碼】** —— 它住在 `@page` 的下邊界帶裡,
**那一帶不屬於內容流** ⇒ **不論我怎麼改版面, 它都在原地。**
排除下邊界帶 14mm 之後,兩個世界立刻分開:**45.0mm vs 61.3mm(差 16.3mm)**。

📌 **⇒ 與上面那條是同一個病的兩個成員**:
```
成員一（錨）  我挑的字串，在【兩個世界都出現】        ⇒ 它命中的是別的東西
成員二（量點）我挑的位置，【兩個世界都不會動】        ⇒ 它量的是別的東西
共同形狀：我以為我在量 X，而我量到的是一個【與 X 無關而剛好在附近】的東西
```
⚠️ **而成員二沒有被突變抓到 —— 它是被【兩個數字一模一樣】抓到的。**
🔴 **一模一樣本來應該是好消息**(「改動沒有副作用」),而它在這裡是**尺壞掉的徵狀**。
⇒ 判別句:**兩個【應該不同】的世界印出同一個值時, 先懷疑尺, 不要先寫結論。**

## 🔴 同族第三個成員(同一晚, `n=3`):**我的尺太窄, 而那個 0 讀起來像一個發現**

同夜再晚,我要核「`CLAUDE.md` 說的零留痕四步,在它指的那份檔裡在不在」。我 grep 的是「**內容雜湊**」:

grep -c 內容雜湊  docs/patterns/cowork-review-chain.md ⇒ 0

⇒ 我差一步就寫下「**`CLAUDE.md` 指到一份沒有那四步的檔**」—— 一個很像發現的結論。

## 🔴 同族第四個成員(同一晚, `n=4`):**我的字集漏了一種【合法的寫法】**

同夜最晚,我寫一支測試去找「哪幾支 migration 定義了 `admin_create_manual_order`」。
我的 pattern 是 `/CREATE OR REPLACE FUNCTION\s+public\.admin_create_manual_order/`。

```
撈到 1 支 ⇒ 而那一族的下一格當場紅成「🔴 沒有任何一版已經 apply」
```
⇒ 那個紅**讀起來像一個重大發現**(「我們對正式庫的每一句推論都沒有地基」)。

🔴 **而真相是**:最早那一支用的是**裸 `CREATE FUNCTION`**(`20260824020000:186`)——
它是**第一次建**, 當然不需要 `OR REPLACE`。**兩種寫法都合法, 而我的字集只認一種。**
✅ **抓到它的是我為那一族寫的正對照**(「定義它的 migration ≥ 2 支」), 不是我讀出來的。

📌 **⇒ 四個成員並排, 這一族的形狀完整了**:
```
成員一（錨）  我挑的字串在兩個世界都出現     ⇒ 命中的是別的東西
成員二（量點）我挑的位置兩個世界都不會動     ⇒ 量到的是別的東西
成員三（字集）我挑的字比對象窄               ⇒ 什麼都沒命中，而 0 讀起來像結論
成員四（寫法）對象有【好幾種合法寫法】而我只認一種 ⇒ 少算，而少算的方向會產生一個【很像發現的紅】
```
🔴 **三與四的差別值得分開**:三是**同義詞打錯**(我要找的東西用別的字寫);
四是**同一件事在語法上有多種等價形式**(`CREATE` vs `CREATE OR REPLACE`、
加不加引號、大小寫)—— **後者不是打錯, 是【我不知道還有那一種】。**
⇒ 所以四的自檢不是「換個關鍵字再試」, 是:**先問「這東西有幾種寫法」, 再問「我的分母對不對」。**

⚠️ **而四個成員裡, 沒有一個是【讀出來的】** —— 四個都是**正對照或突變**抓到的。
📌 **⇒ 這一族的共同結論不是「要更小心」, 是【每一把新尺都要先對一個你確信成立的東西跑一次】。**

## 📎 為什麼這一條特別容易漏

**挑錨的人與寫守門的人是同一個, 而挑錨那一刻【他正看著對的那個世界】。**
在對的世界裡,那個錨確實印在頁首上 —— 他看到的是真的。
🔴 **他沒有看到的是:那個字在【錯的世界】裡也還在。**
⇒ 而那需要**去把它關掉**,不是**再讀一次**。
