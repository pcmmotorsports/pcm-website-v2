# 一個【寫大的射程宣告】,在所有自動量具底下全綠

> 🔴 **先講新在哪一軸**:本條**不是**「機制沒裝好」,也**不是**「守門恆綠」——
> **機制是對的,而【我對它的描述】把範圍寫寬了。**
> ⇒ 查重要用「**射程 / 描述 / 註解說寬了**」去打;用「守門 / 恆綠 / 負對照」會命中舊條。

## 判別句(主句)
> **三綠、探針、突變 —— 它們量的全是【機制】。**
> **沒有任何一把尺量得到「這行註解把射程說寬了」。**
> **而下一個人讀的是註解,不是機制。**

## 我開了哪幾條、為什麼判它不同族(§12-36)

尺一(`traps-neighbours.py`,2026-08-29 跑)**前 8 名最高 `0.2662`** —— 分數側無近親。逐條開檔判:

| 既有條目 | 它講什麼 | 為什麼不是本條 |
|---|---|---|
| memory `a-mechanism-must-judge-not-just-ask` | 機制要能**自己判真假**,不能只是換成一張表單 | 那是**機制的能力**;本條的機制**能判、也判對了** |
| memory `a-guard-on-a-safe-path-is-net-negative` | 裝在沒事的路上 ⇒ 機制本身是風險 | 那是**該不該裝**;本條已經裝了而且有效 |
| memory `three-different-questions-about-one-defect` | 一個缺陷三個問題,量一個就以為驗過 | 那是**驗證的分母**;本條的驗證全過,錯的是**旁邊那段文字** |
| memory `a-constraint-with-two-directions-needs-two-mutations` | 約束有兩個方向,兩個都要突變 | 那是**測試的方向**;本條兩個方向都測了 |

📌 **一句話分野:舊條問【這個機制對不對】,本條問【我對它的描述對不對】。**
🔴 **而所有自動量具都只答得出前一個。**

## 實例(2026-08-29,同一片改動,對抗審查兩輪)

```
R1 四條 ⇒ 打機制的 1 條、打我【宣稱】的 3 條
R2 三條 ⇒ **全部打宣稱**
⇒ 七條裡六條，錯的都是文字不是行為
```

**三次機制我都做對了,三次我把它的射程寫大了**:
```
① 我寫豁免的理由是「boundaries 的型別沒涵蓋 app 根 config」
   🔴 而審查用 `--no-inline-config` 實跑 ⇒ 真成因是「**apps → 同一個 app** 沒有規則允許」
   ⇒ 而我照那個錯理由寫的【重判觸發條件】也跟著錯 —— **它指向一個永遠不會到來的日子**

② 我寫「豁免的射程綁在這個 selector 上」
   🔴 而 `ignores` 是【整個 flat-config 物件】層級 ⇒ 射程是**這個物件裡的所有規則**
   ⇒ 往那個物件加第二條規則 ⇒ **測試檔會無聲地連帶被豁免**

③ 我在一把尺的檔頭寫「這把尺的偏誤方向是保守(寧可漏報不做假紅)」
   🔴 而兩輪審查**各證偽一次** —— 第二次是我修完之後又寫了一遍
```

## 🔴 為什麼它比機制錯難發現
```
機制錯 ⇒ 測試紅 / 探針紅 / 突變殺得掉 ⇒ **有東西會叫**
射程寫大 ⇒ 行為完全正確 ⇒ **三綠全綠、探針全過、突變全中**
⇒ 而它會在【下一個人手上】變成錯：他照那個寫大的範圍去用它
```
📌 **⇒ 這一族的受害者不是寫的人,是讀的人 —— 而寫的人拿不到任何回饋。**

## 動作(本條的用途)
```
寫下任何「這個豁免只涵蓋 X」「這個守門只擋 Y」「這把尺的偏誤方向是 Z」時，問一句：
  **這個範圍是我【讀機制讀出來的】，還是我【希望它是】的？**

而分得開的做法只有一種：**讓那個機制自己說** ——
  跑一發【只會在「射程如我所述」時成立】的探針。
  例：我宣稱「只關掉這一個 selector」⇒ 就造一個【該被別的規則擋】的世界，它必須紅。
```
⚠️ **而這一步很容易被跳過**,因為那時候一切都是綠的 —— **沒有任何東西在催你。**

## 誠實邊界
```
· 三個實例來自【同一片改動】+ 一把尺的檔頭 ⇒ 不是三個獨立情境
· ①② 是 codex 抓的、③ 是 code-reviewer 抓的 ——
  🔴 **沒有一條是我自己發現的** ⇒ 本條講的正是「自己發現不了」，而它自己就是證據
· 「所有自動量具都量不到」是**我列得出來的那幾把**（三綠 / 探針 / 突變 / 自檢）——
  我沒有掃過全 repo 有沒有哪把尺其實讀得懂註解 ⇒ **未確認**
```
