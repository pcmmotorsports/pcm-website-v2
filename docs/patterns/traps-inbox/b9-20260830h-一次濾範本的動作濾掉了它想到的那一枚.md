# 一次「濾掉範本」的動作,濾掉了它想到的那一枚 —— 而剩下的兩枚變成了資料

> `-b9` 2026-08-30 · 母題:**錯的那次和對的那次長得一樣**
> 實錘鏈:`-0b` 掃 ⇒ `-48` 裁 ⇒ `-b9` 開檔核 ⇒ 那件待辦不存在

## 形狀

一張表的**表頭裡住著它自己的範本**。掃描器要數「板上有幾枚戳」,於是**手動濾掉範本**。

```
表頭第 34 行  [重驗 <誰> · <L幾> · <時刻>]     ← 它想到了, 濾掉了
表頭第 52 行  [重驗 …]  ✅對的例子             ← 🔴 沒濾到
表頭第 53 行  [重驗 …]  🔴錯的例子             ← 🔴 沒濾到
```

⇒ 那兩枚被算成**真的戳**,而它們的「誰」欄是 `…`
⇒ ⇒ 結論寫成:**「2 枚戳的作者永遠查不出來 —— 那不是格式歧異,是資訊遺失」**
⇒ ⇒ ⇒ 於是生出一件**待辦**:去把那兩枚修好。

🛑 **而那件待辦不存在。沒有作者被弄丟。**

## 🔴 為什麼它特別難被抓到

**它把自己的病報出來了**:`-0b` 逐字寫了「範本自己會命中掃描」,並且說它濾掉了。
📌 **⇒ 一份【已經承認這個病、並且宣稱處理過】的報告,比一份沒提的更可信。**
而它處理的是**它想得到的那一枚**。

⇒ 下一手(`-48`)照收、沒開檔核,把待辦下給第三手(`-b9`)。
✅ 第三手開檔核了 ⇒ 停在這裡。**而它已經走過兩個人。**

## ✅ 修法:**判準要機械,不能靠「記得有幾枚」**

```
🔴 壞:「濾掉範本」        ← 要人記得範本有幾枚、在哪幾行
✅ 好:「只看以 | 開頭的行」 ← 資料列的定義, 與範本有幾枚無關
```

📌 **兩者在【乾淨的板子】上印同一個數 —— 而在髒的板子上不會。**
⇒ 而你手上這張板子是不是乾淨的,**正是你要用這把尺去回答的問題。**

## ⚠️ 而有一個看起來很自然的修法是錯的

`-48` 原本裁「**把範本改成不會被掃描命中的形狀**」。
🔴 **改了它就不能被複製貼上** —— 而範本存在的唯一理由就是被複製貼上。
⇒ **那是拿一個病換另一個。判準改對了,範本就不需要動。**

## 📌 一句

> **佔位符本身變成資料**,這一族的通例是「忘了濾」。
> **而這一次是【濾了】—— 濾掉了想得到的那一份,而剩下的變成資料。**
> ⇒ **「我有處理」與「我處理完了」在報告上長得一模一樣。**

## 🔴 追記(2026-08-30,同日):**這條坑在同一份檔上,今天發生了第三次 —— 而第三次是我犯的**

```
① 板頭範本被算成戳（-0b 濾掉第 34 行那一枚，沒濾掉第 52/53 行那兩枚）
② 我給「施工工具」那個標記寫數法時用了不濾的 grep -c
   ⇒ 它印 5，而真值 4 —— 多出來的是【那行說明自己】
🔴 而我是在【寫完本條之後】，同一次編輯裡犯的 ②
```

### 而 `-e9` 指出它其實是**第四次**,前面還有一次寫在同一份檔裡

`docs/launch-todo.md:150-154` 逐字記著(2026-08-23):
> ~~原本寫 `grep -c '| zzz-bogus |'`~~ —— 那條命令**會命中它自己這一行**
> ⇒ 它永遠回 ≥1,而它旁邊寫著「應為 0」⇒ **一個永遠達不到它自己宣稱值的負對照**。
> 📌 形狀:**負對照寫在被它掃描的那份檔裡** ⇒ **量具的名字出現在解釋它的句子裡 = 它已經被污染了。**

🛑 **⇒ 所以這不是「今天新發現的坑」** —— **它七天前就寫在這份檔裡, 而今天有三個人各踩一次。**

## 📌 ⇒ 而那把這條坑的成因往上推了一層

**它不是「有人忘了濾」。**

> ### **是【寫下說明】這個動作本身會擴大分母 ——**
> ### **而寫說明的人,正是最不會想到要濾掉自己的那個人。**

⇒ 你寫下「本節含 4 列施工工具」的那一秒,檔案裡的「施工工具」就從 4 變成 5。
**而你腦中那個 4 是你剛剛數的,它感覺非常新鮮。**

## ✅ 所以修法不能是「記得濾掉說明」

那要求每個人記得自己寫過什麼,而**下一個跑這條數法的人不會知道你寫過**。

```
🔴 壞:grep -c '<字面>' <檔>                  ← 說明、範本、註解全部算進去
✅ 好:grep '^| ' <檔> | grep -c '<字面>'      ← 只有資料列
```

📌 **判準永遠是「那一行以 `| ` 開頭」** —— 一個**與你寫了什麼無關**的形狀。

前四次都是「範本被算進**分母**」。這一次不同:

```
-0b 掃戳的套用率，報「2/44」⇒ 主視窗據此裁定改 canonical 定義
🔴 而 -b9 用嚴格尺（濾資料列 + `[重驗 ` 帶空白 + 誰欄 fullmatch）量 ⇒ **38/38**
⇒ -0b 攤開它的尺，三個病：
   ① 分母 44 = 真戳 38 + 表頭示範與規則引文
   ② 正格判準 `^\[重驗 線` —— 凍在 -e9 早期訊息那版，比規格舊兩版
      （而規格已明文把「線A 式」標成 🔴 錯）
   🔴 ③ 它那 2 枚「正格」，就是規格的 :17 【🔴 錯示範行】
      與 :23/:28 引用它的規則文
```

> ### **⇒ 它拿【規格的反例】當合規的分子。**

📌 **⇒ 所以那個 `2/44` 的兩端都壞了, 而它印出一個看起來很有說服力的數字** ——
**低到足以推翻一條規矩, 而且低得「很合理」(誰都相信新規矩沒人照做)。**

🛑 **⇒ 而它差一點成功**:主視窗已經下令改 canonical 定義,
**並指定了要寫進去的那句話「套用率 2/44, 改成跟現實一致」** ——
**那句話會留在一份 canonical 檔裡, 而它讀起來完全正常。**

## ⇒ 這一次的新判準(`-0b` 自己加的,收進本條)

> **一個數字重現不了 ⇒ 先治尺, 不要治那個被它指控的東西。**

⚠️ 而它為什麼難:**壞尺印出來的數字, 指控的方向通常是【合理的】** ——
「新規矩沒人照做」比「我的尺壞了」更像真的。
⇒ **⇒ 所以「這個數字合不合理」不能當作它對不對的證據。**

## ✅ 而兩把尺同值那一格值得寫下來

`-0b` 用 `-b9` 的嚴格尺**獨立重跑 ⇒ 38 / 0(不合規)**,與 `-b9` 同值。
📌 **⇒ 這是本檔少見的一格:兩個人、兩份實作、同一個答案。**
**而它之所以站得住, 是因為【判準先寫出來了】** —— 不是先看到數字再回頭定義合規。
