# 第一條 · 輸出是「空白」與輸出是「`0`」**不是同一件事**

## 實例(當天,我自己)

> **數法**(逐條可重跑;分母當場數不寫死):
> `ls docs/runbooks/*.md` 之後 `wc -l` ⇒ **32 支**
> 尺 B = 對每支跑一段 `awk`:圍欄內含 `grep -c` 或 `wc -l` 的行,**往下看 3 行**找 `應該`/`期望`/`應為`。
> **第一發輸出:空白** · **植入假檔後:9** · **刪掉假檔後:8**。

我寫了一把尺去撈「指令與期望值分行」的檢查(runbook 裡的自檢步驟)。
**第一發的輸出是【空白】** —— 不是 `0`,是**一個字都沒有**。
我讀成「零命中」。

而它其實是**尺沒有跑到**(`awk` 的緩衝寫法錯了,整條管線沒吐東西)。

**我怎麼知道的**:我把一個**假的壞檔案**植入 `docs/runbooks/` 本身、再跑一次 ⇒ **跳出 9**
(假檔內容:一行 `cat .env.local` 接 `grep -c "SUPABASE"`, 下一行註解寫「應該 >= 3 行」;跑完即刪, `ls` 複驗 0)。
⇒ **⇒ 是那個 9 告訴我前一發壞了。沒有它,那個「空白」會被我寫成「零命中」寫進報告。**

## 判別句

```
空白 ＝ 尺【沒有跑到】（管線斷了 / 語法錯 / 檔案沒開成）
0    ＝ 尺跑了，而沒撈到
🔴 而在終端機上，兩者都是「什麼都沒有」
```

📌 **⇒ 所以「零命中」這句話落筆之前,要先確認你看到的是一個【`0`】,不是一片空白。**
✅ **可執行的動作**:讓那把尺**永遠印出一個數**(`| grep -c ''` 或 `| wc -l` 包在最外層)——
**一個印不出數字的管線,它的沉默沒有資訊。**
⚠️ 而那還不夠 —— **印得出 `0` 的尺仍然可能是壞的** ⇒ **正對照那一步不能省**(見下面「與既有兩條的差別」)。

## 與既有兩條的差別(我開檔讀了才判)

```
既有 memory `feedback_absence-read-as-verified`：
  「空的／零／沒印出東西」被讀成「我檢查過了、沒問題」
  ⇒ 講的是【零這個結果】被讀成【驗證通過】

既有正本〈一個「零命中」要怎麼樣才算數〉（標題錨，不用行號）：
  窄網零命中 ⇒ 只證明「我找的那個字沒出現」；而中間還隔著「確認那把網真的在動」
  ⇒ 講的是【0 的射程】

🆕 這一條：
  🔴 **我根本沒有拿到一個 0** —— 我拿到的是【空白】，而我把它當成 0 了
  ⇒ 上面兩條都【預設你手上有一個 0】；這一條發生在那之前一步
```
📌 **⇒ 它是那兩條的【上游】**:先確認你有一個數,再問那個數的射程。

## 兩個實例(同一夜,同一條線)

```

② 「揀貨單」那一類（#10 列印片的字面殘留）
   grep 命中 63 處 ⇒ 逐處開檔 ⇒ **缺陷 2 處**
   其餘幾乎全在【刻意保留的歷史註解】裡（⛔ ~~揀貨單~~ **訂單明細**）
```

## 判別句

📌 **⇒ 一個「命中」不等於一個「違規」。**
🔴 **而只看命中數不開檔的人,今天會報一個 16 與一個 63。**
✅ **那 16→0 與 63→2 的差,就是【開檔】那一步的價值** ——
**而它不是一句主張,是兩個當天量到的比例。**

⚠️ **而反過來也要說**:開檔**也可能把真的漏掉** ——
本條**不主張**「開檔之後就對了」,只主張**「不開檔的那個數字沒有意義」**。

⚠️ **這兩個比例的射程**:各一次、各一種字面、各一個人判的。
**未數**:同樣兩類字面在別的目錄下的比例。⇒ **它是兩個樣本,不是一個分佈。**
