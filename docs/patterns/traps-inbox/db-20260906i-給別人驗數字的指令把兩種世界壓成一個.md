## 我為了讓別人**驗我的數字**而寫的那條指令,自己把兩種世界壓成同一個

> 線【DB】`-db` 2026-09-06。實錘 = 冪等閘的 runbook 計數指令,codex R2 在它自己的環境跑出 **335**。

### 發生了什麼

我在 runbook 裡寫了一條「這個數字怎麼重跑」的指令 —— **寫它的目的就是讓別人可以推翻我**:

```bash
for f in supabase/migrations/*.sql; do
  bash scripts/apply-paste-board.sh --check-dml "$f" >/dev/null 2>&1 || echo "$f"
done | wc -l
```

`||` 的意思是「**非 0 就算有 DML**」。
而那支工具的離場碼其實有**三種**:`0` 過 · `1` 真的擋下 · **`2` 掃描器自己壞了**。

🔴 codex 在它的**唯讀 sandbox** 跑這一條 ⇒ 得到 **335(全部)** ——
那裡的暫存檔建不出來,掃描器**每一支都回非 0**,而 `||` 把它們**全部**算成「有 DML」。

### 坑的形狀

我寫那條指令,是為了讓下一個人**驗我的 55**。
而它在**量具壞掉的環境**印出一個**看起來很合理的極端值**(全部),**沒有任何錯誤字樣**。

🎯 ⇒ 下一個人拿到 **335** 會以為「這道閘會擋掉每一支」,然後**去質疑那道閘** ——
🛑 **而閘是好的,壞的是我給他的那把尺。**

📌 **我提供的「可重跑證據」,在它最需要可信的那個環境裡,說了一個最有說服力的謊。**

### 判別式

> **一條寫進文件、給別人重跑的計數指令,必須分得出
> 「條件成立」與「量具沒跑起來」。**

🔴 `||` 與 `&&` **只認 0 與非 0** ⇒ **它們天生做不到這件事。**
✅ 三態以上的離場碼一律 `[ $? = N ]` 明寫。
✅ **而工具那一側也要負責**:把「**我壞了**」與「**我判它有問題**」分成不同的離場碼 ——
我這次兩邊都改了(`--check-dml` 改成三態,文件改成 `[ $? = 1 ]`)。
