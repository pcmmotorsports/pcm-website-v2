# C4-20260830 · 兩個來源一致,只有在它們**真的獨立**時才是證據

> 投件窗 線C(`-b4`)· 2026-08-30 · **-48 指定投件,並要求把它自己那一手具名寫進來**
> 📌 **落點是一個【判斷】的形狀,不是一個工具的形狀** —— 所以它沒有一個字面可以 grep。
> ⇒ 觸發情境寫成:**「我有兩個來源都這樣說,所以我比較有把握」的那一刻。**

## 已經有一條規則管一半了 —— **而它管不到這一種**

`~/.claude/rules/00-work-rules.md` §6-b 第 1 條逐字:
> **「同一把量具量 N 次=一個證據複印 N 份,一致不是效度。」**

✅ 那條管的是**你知道自己用了同一把尺**的情況。
🔴 **而本條管的是另一種:兩個來源【看起來不一樣】—— 不同的人、不同的工具、不同的 session ——
而它們共用一個你沒有看見的成因。**

> **⇒ 前者你會警覺;後者【感覺起來就是交叉驗證】,而那正是它危險的地方。**

# 三個現場,同一晚(2026-08-29 夜 → 08-30 晨)

## ① 同一個人的兩把尺,對同一筆各判一次紅
```
`-b9` 抽樣核 20 條「檔案:行號」引用，#9 被判「全檔都沒有」
判它紅的第一發：抽樣尺（逐行比對，跨行引文必判紅）
判它紅的第二發：一發【手打路徑】的 grep 複驗
   apps/storefront/src/**lib**/legal-content.ts  ← **不存在**
   真路徑        apps/storefront/src/**data**/legal-content.ts ← 在，而那句話就在 :9
⇒ 檔不存在 ⇒ grep 什麼都沒印 ⇒ **被讀成「零命中」**
```
🔴 **⇒ 兩發都紅 ⇒ 判的人【更確信了】。**
📌 **而那兩發不是兩個證據,是同一個人的兩個失誤 —— 而它們在報告上與「兩個獨立來源都紅」長得一模一樣。**
⚠️ 順帶,第二發自己也是一個獨立的坑:**「檔案不存在」與「檔在而零命中」,在 `grep` 的畫面上是同一片空白。**

## ② 我造一把更好的尺去驗它的尺 —— **而我的尺有同一類 bug,深了一層**
```
我寫了一個正規化器（砍 markdown 記號與空白）去重驗那 20 條
⇒ 第一發，我【也】判 #17「真的沒有」
✅ 而 #17 我早一步已經【直接開檔看過】，它就在 :88-89
⇒ 成因:那段引文跨行，而續行帶著 `//` 註解前綴 —— 我的正規化沒有砍它
```
📌 **⇒ 我以為我在做「更嚴格的複驗」,而我只是把同一個盲區換了一個包裝。**
🔴 **⇒ 而若我沒有先手動開過那一筆,我會用我的尺【確認】它的尺,然後兩個人一起錯。**

## ③ 🔴 而**判斷者那一側**(`-48` 要求具名寫進來,逐字)
```
主視窗今晚多次以「兩個窗各自量到同一件事 ⇒ 可信」下判斷
🔴 而它自陳:【從來沒有驗過那兩發是不是用同一把尺】
```
> **⇒ 而那不是它偷懶 —— 那個前提【從來沒有被說出來過】,所以也沒有人會想到要驗它。**
📌 **⇒ 這一格比 ①② 重要:①② 是量測者的錯,而 ③ 是【匯總者】的錯 ——
而匯總者收到的是兩份結論,他看不到兩把尺。**

# ✅ 判別動作(機械的,而且便宜)

在寫下「**兩個來源都這樣說**」之前,問**一句**:

> ### **這兩發,有沒有共用任何東西?**

```
共用【人】     ⇒ 同一個窗跑的兩發 ⇒ 它的盲區會跟著兩發一起走
共用【工具】   ⇒ 兩發都用 grep / 都用同一支 harness / 都讀同一份轉述表
共用【輸入】   ⇒ 兩發餵的是同一份清單、同一組關鍵字、同一個路徑字串
共用【前提】   ⇒ 兩發都假設「那支檔在那個位置」「那個欄位叫那個名字」
```
🔴 **命中任何一格 ⇒ 那不是兩個證據,是【一個證據的兩份副本】。**
✅ 那時能寫的只有:「**我用兩種做法量,結果一致**」——
**不能寫「兩個獨立來源證實」。**

## 而要讓它真的獨立,最便宜的一刀
```
✅ 讓第二發【不經過第一發的任何輸入】——
   尤其:不要拿第一發抄來的【路徑字串】去跑第二發
   （① 就是這樣壞的:路徑是手打的，而第一發也沒有驗過它）
✅ 而更硬的一刀:第二發用【相反方向】的問法
   第一發問「那句話在不在那幾行」⇒ 第二發問「那句話現在在【哪一行】」
   ⇒ 後者答得出一個位置 ⇒ 而「答不出位置」與「答錯位置」分得開
```

# ⚠️ 這一條的射程(寫出來,免得被當成萬用懷疑論)

```
❌ 它【不是】說「多個來源沒有用」—— 真的獨立的兩發，價值極高
❌ 它【不是】要你把每一次交叉驗證都拆開查 —— 那會讓匯總變得不可能
✅ 它只要求一件事:**在寫下「兩個來源一致」那一刻，問那一句。**
   ⇒ 而那一句通常五秒就答得出來:「這兩發是不是同一個窗跑的?」
🔴 而它最該生效的時機是【好消息】:
   兩發都紅、兩發都綠 ⇒ 那正是最不會有人回頭查的兩種結果
```

# 📌 一句話帶走

> **「兩個來源都這樣說」在報告上是一句加強語氣的話 ——**
> **而它的效力全部來自一個沒有被寫下來的前提:那兩個來源沒有共用任何東西。**
> **⇒ 而那個前提,通常是假的。**
