## 畫面上有一句誠實的話,**不代表旁邊那個數字被修正了**〔安靜〕

> **判別句:我那句警告,跟它要警告的那個東西,在不在【同一個視線】上?**
> 不在 ⇒ 讀者會把它們讀成**兩件無關的事**,而那個錯的東西照樣被抄走。

### 實例(2026-08-17 A 窗,訂單列表)

關鍵字命中超過 100 筆時,同一個畫面上:
```
頁首   琥珀橫幅:「符合這個關鍵字的訂單超過 100 筆，目前只找了最新的 100 筆」
       ← 真話，而且【無條件顯示，含 0 筆】。這一格做得很好。
工具列 「共 N 筆」
       ← 而契約自己寫著（types.ts:398-400）:截斷時 total【只代表前 100 筆再套篩選後的數量，
         不是完整命中數】⇒ 這個數字的語意【已經被偷換】，而它長得跟平常一模一樣
```
🔴 **兩個東西各說各話**:一個說「結果太多」,另一個給一個**看起來就是答案的數字**。
**而沒有任何一個字把它們接起來。**

### 為什麼它安靜

```
① 警告【存在】⇒ 任何「有沒有提示使用者」的檢查都會通過（而且它真的無條件顯示，做得比多數地方好）
② 錯的那個東西【格式完全正常】—— 一個數字，跟不截斷時長得一模一樣
③ 🔴 兩者由【不同的人、在不同的時間】做對與做錯:
   橫幅是為了「0 筆不要被讀成查無此單」加的（合約明文要求）
   而那次沒有人回頭問「那旁邊那個數字呢」
④ 寫警告的人會覺得這件事已經處理完了 —— 他處理的是【他當時看到的那個症狀】
```

### 動作(不是決心)

1. 加警告的當下,**問一句:這頁上還有哪個東西正在講同一件事,而它沒有被改?**
2. **能改那個東西本身,就不要只加警告** —— 本次的修法是**把數字改成講得出實話的字面**,
   而**橫幅一個字都不用動**(它本來就沒說謊)。**兩句都真、各自站得住,才不需要互相解釋。**
3. 非加警告不可 ⇒ **讓它與被警告的對象在同一個視線**(同一格、同一列、緊鄰),不是頁首。

### 與既有條目的關係

- 與 canonical「**比較圖會製造出不存在的差別**」同族:**都是【呈現】讓讀者得到錯的結論**,不是量測錯。
