# 【新增實例】一條**正確的**規矩擋住了正確的東西,而它的**暗示**指向錯的成因

> 2026-08-28 夜,線B(`-d3`)。**不推翻既有任何一條。**
> 🔴 **這一條為什麼是新的(先讀這段, 否則會被讀成 `:11322` 的重複)**:
> ```
> 正本 :11322「成因不是【忘了重新 add】—— 那個解釋會讓你防錯地方」
>   ⇒ 那是【一個錯的解釋】。可以靠「不要相信直覺的解釋」擋。
> 本條
>   ⇒ 規矩【是對的】、它【擋對了】、我【正確地遵守了它】,
>     而它附帶的暗示把我指向錯的成因。
> ```
> 📌 **前者擋得住;後者擋不住 —— 因為那個暗示來自一條你正在正確遵守的規矩。**

## 判別句(兩句,兩個不同的層)

```
① 一條正確的規矩擋住了正確的東西, 而它把成因指向錯的地方。
② 在多窗共用樹上, 「沒有人 commit」不是「什麼都沒變」。
```

## 事發

我為 `scripts/naked-cells.py` 的每一組輸出訂了一條規矩:
**「數字要帶著【時點 + 尺的 sha】走;sha 對不上 ⇒ 那組數字全部作廢, 重量。」**

21:00 量到 `57 格 / 33 支`。之後我改了那支尺的**註解與輸出文字**(邏輯零改動)⇒ sha 變了
⇒ 照規矩重量 ⇒ **21:13 得到 `55 格 / 31 支`**。

**規矩擋下了一次過期 ✅** —— 而它的暗示是「**尺變了**」,於是我差一點去查那支尺。
**查尺會查到「邏輯零改動」, 然後我會困惑。**

## 真成因

```
git log --since=21:00 ⇒ 3 顆 commit, 而【沒有一顆動到 *.test.ts/tsx】
分母 git ls-files '*.test.ts' '*.test.tsx' ⇒ 688 支, 三次相同
🔴 而這把尺讀的是【工作樹】, 不是 HEAD
   當下 dirty 的測試檔 7 支, 其中【1 支不是我的】:
     apps/storefront/src/lib/cron/heartbeat.test.ts  ← 線D 正在寫
```
⇒ **變的不是尺, 是被量的東西。而它變的方式不經過 commit。**

📌 **而今晚我們一直用 `git log` / 未推顆數 / `HEAD` 來判斷「世界有沒有動」——**
🔴 **那些全部看不到工作樹。**

## ⇒ 可執行的那一格

**任何讀工作樹的量測, 數字旁邊要多一欄:**
```
當時 dirty 的檔數, 以及【其中有幾支不是我的】
```
🔴 **第二個數才是關鍵**:`dirty 3 支全是我的` 與 `dirty 3 支有 2 支是別人的`, 意義完全不同 ——
前者我知道我改了什麼, 後者**我量到的東西正在被別人改寫**。
⚠️ 而這一欄**今晚每一組數字都缺**(線B 自陳), 而**它對每一個窗都成立, 不只那把尺** ——
**任何讀工作樹的量測都一樣。**

## ⚠️ 同一夜、同兩條線,撞了兩次 —— 而**兩次的形狀不同**

線B 與線D 今晚在同一條線上撞到彼此兩次:
```
第一次  線D 改的 heartbeat.ts 讓 `pnpm lint` rc=1
        ⇒ 我的 commit 會被 pre-commit 擋
        ✅ **有訊號**:一行紅字, 指名那個檔與那條規則
第二次  線D 改的 heartbeat.test.ts(工作樹, 未 commit)讓我的數字從 57 變 55
        🔴 **零訊號**:兩次量測都是綠的、都印出一個乾淨的數字
```
📌 **第一種會叫;第二種不會 —— 而第二種改變的是【我拿去做決定的那個數】。**

## 而這對已經核完的那 57 格**沒有影響**(而理由值得寫)

```
那 57 格是【逐格開檔核過】的, 不是「尺報幾格算幾格」
⇒ 尺的輸出會漂, 而【開檔核過的判決不會】
```
⚠️ 但**清單的行號在下一個人讀到時同樣可能已經漂了** ⇒ 動手前照工作單檔頭那三個限定重跑一次。

## 附:同一夜的姊妹格 —— **一把尺擋得住「多收了」,擋不住「換成了」**

主視窗給的 commit 回核尺是「數這顆收了幾支」:
```
git show --name-only --pretty=format: HEAD | grep -vc '^$'   ⇒ 7
```
🔴 **而「7」對【收了我的 7 支】與【收了 6 支我的 + 1 支別人的】印同一個數。**
⇒ 我改成**把 7 支逐支印出來看**, 那才答得出「收了什麼」。
📌 **主視窗自陳:那把尺是它為了取代一把更差的尺而給的 —— 它比原本那把好, 而它仍然有一個沒被講出來的射程。**
