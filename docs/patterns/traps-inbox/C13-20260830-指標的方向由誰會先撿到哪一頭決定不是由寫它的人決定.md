# C13-20260830 · **一個指標的方向,由【誰會先撿到哪一頭】決定 —— 不是由寫它的人決定**

> 投件窗 線C(`-b4`)· 2026-08-30 11:1x · **主視窗 `-48` 指認,掛我的名**
> 🔴 **母題**:寫指標的人,想的是**自己回頭找**;而真正會撞到它的人,**從來沒讀過起點那一頭。**

---

# 現場

從一份要交給 Sean 的清單裡砍掉兩題,搬到另一份檔。上游的要求逐字:

> 「移走的兩題要有**落點**,不要就這樣消失。」

```
✅ 照做的最小形狀：在原清單寫一行「另有兩題延到下批 ⇒ 見 <那份檔>」
⇒ ⇒ 🔴 而那只接上了【一個方向】
```

**上游事後自己講出了成因(原字面)**:
> 「我寫『移走要有落點』時,腦裡想的是**我們自己回頭找**
>  ⇒ 而真正會撞到它的人,是一個**從來沒讀過這份清單的人**。」

---

# 🔴 機制

> ## **寫指標的人,站在【起點】那一頭。**
> ## **而他寫下的那一刻,他【剛剛才離開起點】—— 所以那個方向對他是自然的。**

```
他的路徑：清單 → 砍掉 → 搬走 → 「我要記得它在哪」⇒ 指標指向終點
而下一個人的路徑：撿到那份「下一批」的檔 ⇒ 「這是什麼？誰放的？還算數嗎？」
⇒ ⇒ 🔴 他手上那一頭【沒有任何東西指回去】
⇒ ⇒ ⇒ 而他會做的事是：**當成一份無主的舊檔，放著**
```

📌 **⇒ 而這與「忘了寫」不同** —— **指標寫了,而且寫對了,只是寫在【不需要它的那一頭】。**

---

# ✅ 判別動作

> ## **我寫這個指標,是為了讓【誰】找到【什麼】?**
> ## **而那個人,手上會先拿到哪一頭?**

```
✅ 便宜的形狀：**兩頭都寫**（各一行，成本近乎零）
   起點 → 「另有 X 延到下批，見 <檔>」
   終點 → 「本檔的 X 從 <哪份清單> 移出，**不是取消**」
🔴 而終點那一行要回答的不是「它在哪」，是【它為什麼在這裡、還算不算數】
   —— 因為撿到終點的人問的是那個問題，不是路徑問題
```

## ⚠️ 而它有一個更廣的形狀,值得一起記
```
同族：一支工具存在，而下一個人 `find` 不到它（正本已記）
同族：一份交接檔寫得再完整，只要沒有一條路從「新窗開工的第一件事」通到它，
      它就等於不存在（CLAUDE.md 路由表那一格已記）
🔴 本條補的是它們的【方向】那一半：不是「有沒有路」，是「路是【朝著誰】鋪的」
```

---

## ⚠️ 分界(查重開過,判不併)

```
`C12`（本 inbox）「板子行號當識別字」⇒ 相鄰而不同：
   那是【識別字會改變所指】；本條是【指標只鋪了一個方向】——
   C12 的指標是壞的，本條的指標是好的而朝錯邊
正本「一把工具存在與下一個人找得到它是兩件事」⇒ **母題**，本條是它的方向版
CLAUDE.md 路由表「沒有一條路通到它，它就等於不存在」⇒ 同族，而那條講【有無】，本條講【朝向】
```

## ⚠️ 射程
```
✅ 證到：一次（兩題搬檔），而成因是【上游自己講出來的】，不是我推的
❌ 沒證：「下一個人更可能先撿到終點」——這是我與上游的共同判斷，**沒有量過**
   （要證它需要去數：歷史上那些被移走的東西，後來是被誰、從哪一頭撿回來的）
🔴 而本條自己有一個要提防的形狀：它讀起來像「所有指標都要雙向」——
   **不是**。判準是【誰會先撿到哪一頭】；若終點那一頭根本不會有人單獨撿到
   （例如一個只有腳本讀的中間檔），單向就夠了。
```
