# 第一條 · 「零命中」被讀成【不需要】—— 那是從事實跳到規範

> **本節每一個數字的數法**(全稱句守門要求;逐條可單發重跑):
> `grep -rlE '"(puppeteer|puppeteer-core|pdfkit|jspdf|@react-pdf/renderer|pdf-lib|@sparticuz/chromium)"' --include=package.json . | grep -v node_modules | grep -c ''` ⇒ **0**
> **正對照**同一把尺:把上面那串換成 `"next"` ⇒ **2**
> `git grep -c "application/pdf" -- apps packages scripts | grep -c ''` ⇒ **0**

## 實例(當天量的)

那一列逐字寫著「**不用加套件**」。
依據是一發掃描:產 PDF 的相依(`puppeteer` / `pdfkit` / `jspdf` / `@react-pdf` / `pdf-lib` / `@sparticuz/chromium`)
在任何 `package.json` ⇒ **0 支**。

**我複量**(2026-08-31):

```
0 支（同一批字面）
🔴 正對照：同一把尺找 "next" ⇒ 2（尺是活的，碰得到 package.json）
   git grep application/pdf -- apps packages scripts ⇒ 0
```

⇒ **那個掃描【是對的】。0 就是 0。**

## 而錯的是下一步

🔴 **「0 支相依」不是「不用加套件」的證據,它是【還沒做】的證據。**
📌 **那句話把「今天沒有」讀成了「不需要」。**

**實際上它需要什麼**:要伺服器把 HTML 變成 `.pdf`,那條路是**無頭瀏覽器(chromium)**
⇒ 新相依 + 部署體積 + 冷啟動 + 平台設定(鐵則 12④)。
⇒ 而板上那句「不用加套件」**讓讀的人不去問這件事**。

## 與既有那一條的差別(我開了檔才判的)

既有正本那一條(用標題錨,不用行號):

> 〈**`grep` 不到只證明「這個名字不存在」,不證明「這件事沒被做過」**〉

```
既有那一條：零命中 ⇒ 錯的【事實】結論（「這件事沒被做過」）
🆕 這一條  ：零命中 ⇒ 錯的【規範】結論（「這件事不需要做」）
```

🔴 **而後者更貴**:
「不存在」是一個**會被下一個人去查**的宣稱;
**而「不需要」會讓下一個人【不去查】** —— 它關掉的不是一次查證,是**整條路的動機**。
⚠️ **這一段是【判斷】不是量測** —— 它沒有分母, 也沒有負對照。
**未數**:「有幾個人因為讀到『不需要』而沒去查」—— 那件事沒有留下痕跡,而那正是它難的地方。
✅ **有一個可數的旁證**:2026-08-31 主視窗**把這一件重新派了一次**(訊息在對話裡)——
而它派之前讀的就是那一列。**n=1, 不宣稱更多。**

⇒ 📌 **判別動作**:看到一句「不用 / 不需要 / 不必」時,問一句
**「這是量出來的,還是從一個【零】推出來的?」**
**零只能告訴你【現在沒有】。它對【要不要】一個字都沒說。**

⇒ 📌 **一份寫得很完整的 plan 躺在信箱裡 —— 而完整度不會讓它被找到。**

## 而我加完那條路之後,溢出工具說:**那條路會被丟掉**

```
那一列本來就在溢出名單裡（形狀A，丟 2842 字）
⇒ 我加的字直接落進【被丟掉的那一段】
成因量到的：那一列 7 根豎線 = 6 格，而表頭 6 根 = 5 格
        多出來的那一格從「2026-08-29 -c8 訂正路徑並接手」開始 ⇒ 整段渲染時消失
```

✅ **修法**:把多出來的那根豎線換成 `<br>` ⇒ 6 格併回 5 格。
**零損失逐字驗**:`before.replace('|','') == after.replace('<br>','',1).replace('|','')` ⇒ **True**。
⇒ 溢出 **17 列/24731 字 ⇒ 16 列/21889 字**。

## 判別句

📌 **一個為了「讓下一個人找得到」而寫的指路標,被寫進了一段【沒有人看得到】的地方。**
🔴 **而檔案裡那些字一個都沒少** —— `grep` / `cat` 讀得到,
**這個病只在【把它渲染成表格】的地方成立** ⇒ 而寫的人從來不那樣讀它。

⇒ **可執行的動作**:**在一列上補「指路」性質的內容時,補完當場跑一次溢出工具,
並且比【那一列在不在名單裡】,不是只比總數。**
(總數可以不變 —— 一列本來就在名單裡的話,你加的字只是讓它丟得更多。)
