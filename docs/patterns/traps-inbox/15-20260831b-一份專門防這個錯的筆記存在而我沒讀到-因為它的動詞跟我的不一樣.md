## 15-3 · 一份**專門防這個錯**的筆記存在、撈得到、而我沒讀到 —— 因為**它的動詞跟我的不一樣**

### 現場

我寫提案推薦「那支曝露探針接成 **Vercel cron 路由**」。比較表三欄,**每一欄的理由都是量到的**:
CI 那條是探針檔頭明令的、launchd 那條是 `com.pcm.*` 13 支裡 disabled 12 的實際存活率、
cron 路由那條是 storefront 已有 5 支同型 + 後台有心跳。

🛑 **而整個推薦是空的**:那 5 支不是 Vercel 在排,是 **`pg_cron` 經 `net.http_get`** 打 HTTP 路由
(`vercel.json` 的 `crons` ⇒ `None`);而我們的探針是一支 **shell 腳本**,要 psql + 四支 `$HOME` 憑證檔
⇒ **資料庫打不動它** ⇒ **不是接法選錯,是那個東西不存在可接的形狀。**

### 🔴🔴 而真正的那一格在這裡

```
memory/feedback_a-route-scheduler-can-live-in-the-database.md（寫於 2026-08-24, 七天前）
description 逐字:
  「掃『誰會呼叫這支 HTTP route』時, 分母至少三族:平台排程(vercel.json/vercel.ts)、
    CI(workflows)、資料庫排程(pg_cron + pg_net)。漏最後一族會系統性誤判『零排程』。」
How to apply 逐字給了指令:
  grep -rln "cron.schedule\|pg_cron" supabase/migrations/
🔴 它甚至點名了【同一支檔】:supabase/migrations/20260723120000_m3_s2_settle_sweep_pgcron.sql:12
```
⇒ **那份筆記是為了防止今天這件事而寫的,而它連檔名都對上了。而我沒有讀到它。**

### 🔴 為什麼沒讀到 —— 不是我懶,是**動詞不一樣**

```
那份筆記的動詞  「**掃** 誰會呼叫這支 route」        ← 一個【偵測】動作
我當時的動詞    「**推薦** 這支探針要接在哪」        ← 一個【設計】動作
⇒ 分母是同一個(平台 / CI / DB 三族), 而【動詞不同 ⇒ 它讀起來不像在講我這件事】
```
📌 **⇒ 索引與檢索是靠【名詞】對齊的,而人是靠【動詞】判斷「這關我的事嗎」。**
🛑 **⇒ 所以一份筆記可以在分母上完全命中,而在【它像不像我正在做的事】上完全落空。**

### 🔴🔴 而它有第二層,是機械的 —— 就算我想 grep,也撈不到

`MEMORY.md`(每 session 載入的主索引)自己的規矩第 15 條逐字寫著:
> 「加新 memory 時,**把它的關鍵字補進所屬族那一行**,否則那支檔對『動手前 grep 一次』而言**等於不存在**」

**而那支 memory 從來沒有被補進去。當場數(2026-08-31 12:3x,補之前):**
```
grep -c 'pg_cron'    MEMORY.md ⇒ 0        grep -c '資料庫排程' MEMORY.md ⇒ 0
grep -c 'cron'       MEMORY.md ⇒ 0        grep -c '排程'       MEMORY.md ⇒ 0
grep -c 'a-route-scheduler-can-live-in-the-database' MEMORY.md ⇒ 0
🔵 正對照 grep -c '曝露探針' MEMORY.md ⇒ 1（尺會動）
🔵 負對照 grep -c 'ZZNOSUCHZZ' MEMORY.md ⇒ 0
```
📌 **⇒ 所以「動手前 grep 一次索引」這個動作,對這支檔【回的一定是 0】** ——
**而那個 0 與「這件事沒有人記過」印同一個東西。**
✅ **已修(機制,不是提醒)**:把它的關鍵字補進品質族那一行 ⇒ 補後 `pg_cron` / `資料庫排程` / `三族` 各 ⇒ 1。

### ✅ 判別句與處置
```
判別句:當我要【推薦一個接法】時, 先問「有沒有人記過【這個東西怎麼被呼叫】」——
        用【名詞】(route / 排程 / cron)去搜, 不要用我當下的【動詞】(推薦 / 接)。
🔴 而比判別句更硬的一格:**一份筆記沒有進索引 = 它對搜尋而言不存在**,
   而它的檔案還在、內容還對、日期還新 ⇒ **從任何一個角度看它都是健康的。**
   ⇒ 落 memory 的那一步不是「寫完檔」, 是「寫完檔 + 關鍵字進索引」, 少了後者等於沒寫。
```
