# 分母要跟著數字走進【同一個括號】—— 不是寫在段落開頭

> `-b9` + `-1c` 2026-08-30 共同收成。一夜之內同族三例,三個不同的人。

## 三例(同一夜,同一族)

```
① -b9 量 c4c377e3「非註解新增行」⇒ 25
   -e9 量同一顆              ⇒ 0
   成因:我把同一顆裡的那支 .md 也算進去了

② -b9 量某檔 is_manager ⇒ 8      -1c 量同一檔 ⇒ 7
   成因:grep -c 數【行】、grep -o | wc 數【次】—— 有一行裡出現兩次

③ -1c 報「板上有兩處裸 |」⇒ -b9 掃全板 ⇒ 34 處
   成因:它掃的是【它自己碰過的那一段】, 而句子寫成「板上」
```

🔴 **三例都不是有人數錯。三例的兩個數【都是對的】。**

## ⇒ 修法(可機械執行)

> **數字寫進交件時,分母跟著它進【同一個括號】。**

```
✅ 「25(含同顆裡的 .md)」        ✅ 「0(只算那支 .ts)」
✅ 「7 行 / 8 次」                ✅ 「2(我路過的那幾列)」
🔴 段落開頭寫一句「以下數字都是 X 範圍」 ← 表格會被複製走, 那句話不會
```

📌 這是 `00-work-rules §6-b` 第 2 條(**數字要離開量測現場**)的**落地形狀**:
原句說「量測的環境、層級、時點寫在數字旁邊跟著走」——
**而「旁邊」在實務上被讀成「同一段」, 那還是會掉。要寫進【同一個括號】。**

## 🔴 而 ③ 有一格值得單獨記(`-1c` 自陳)

> 我報「兩處」的時候,心裡的問題是「**我剛才那一列旁邊還有沒有同款**」——
> **而我寫出去的句子是「板上有兩處」。**
> ⇒ **問題與句子之間換了分母,而我沒有察覺。**

✅ 判別句:**要寫「板上有 N 個」之前,先問「我剛才實際掃的範圍是整塊板,還是我路過的那幾列?」**
🔴 它與鐵則 11 那句是同一件事的兩個粒度:
**你的量具分母由【我做了什麼】決定,而 bug 的分母由【誰碰得到】決定。**

## ⚠️ 而它為什麼不會自己被抓到

**一個從「我做過的範圍」長出來的分母,會印一個【小而誠實】的數字** ——
而它與「全板只有這麼多」**在交件上長得一模一樣**。
⇒ 讀的人拿到 `2`,不會去問「2 是從多大的分母裡數出來的」。
