## 事件

一片高風險 migration(動錢 + DB 結構)走完三輪對抗審查:

```
R1  codex                              FAIL  6 must-fix + 4 nit
R2  codex（同模型，修完再審）            FAIL  4 must-fix + 10 nit
R3  adversarial-reviewer（opus，換模型）  FAIL  3 must-fix + 2 consider + 3 nit
```
**每一輪都抓到真 finding,每一條都被修掉。**

而事後有人問了一個問題,**三輪都沒有問過**:

> **它做的那件事,等不等於 Sean 那句拍板?**

---

## 🔴 三輪各自問了什麼 —— 它們是三條**不同的**推理鏈

```
R1 / R2 ：這道鎖【繞得過去】嗎？斷言【恆綠】嗎？後置斷言驗得夠不夠？
R3     ：它【叫人走的那條路】，今天真的走得通嗎？
```
📌 **⇒ 三條都在問「這片碼對不對」。**
而「它是不是那件事」需要**把拍板原句貼出來逐字比**,而那個動作**不在任何一輪的交辦裡**。

🔴 **⇒ 而這不是三個審查者不夠好** —— 他們各自答得很好,**而三個問題的聯集裡沒有那一格。**
**⇒ 那一格的缺席,是【交辦】的缺陷,不是【審查】的缺陷。**

---

## 為什麼它特別容易缺席

```
① 拍板原句住在【別的載體】（決策板 / mailbox），而審查者看的是 diff
   ⇒ 它不在審查者的視野裡，除非有人把它貼進交辦
② 作者【最不適合】答這一格 —— 他寫那片的時候就是照他自己對那句話的理解寫的
   ⇒ 他去比對，比的是自己的理解對自己的實作 ⇒ 只證得出「我內部自洽」
③ 而它【看起來已經被涵蓋了】：交辦裡通常有一句「這片要做什麼」
   —— 而那句話是【作者寫的轉述】，不是拍板原句
   🔴 ⇒ 審查者拿它當基準時，比的是「實作 vs 作者的轉述」，兩邊同一個人
```

## 判別動作(可執行)

```
高風險片的審查交辦裡，要有一條【獨立的、與正確性分開的】：

  「把拍板原句【貼出來】（不是轉述），逐字比對這片做的事。
    只回答【等不等於】，不回答【做得對不對】。」

🛑 而那一格【不能由作者答】—— 理由見上面 ②。
🔴🔴 而【貼原句的人】也不能是作者(線G 補) —— 兩個角色都要離開作者:
    ① 原句由誰貼   ② 比對由誰做
  ⇒ 只擋②而不擋①的話, 產出的是【作者貼、作者比】以外的中間態:
    **作者貼、別人比 —— 而別人比的是【作者選出來貼的那一段】。**
```
✅ **本次的處置**:作者(我)**主動宣告利益衝突並拒絕自判**,由主視窗改派**沒有立場的窗**核那一格。
