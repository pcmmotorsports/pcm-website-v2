# 「把我的機制拿掉,它還綠嗎」—— 一個五分鐘的實驗

> 🔴 **先講新在哪一軸**(查重時我自己差點判成舊條):
> · 「負對照要跑」「該紅真的紅」⇒ **正本已有**,不是本條的主句。
> · 本條問的**不是「守門會不會叫」**,是 **「叫的那一聲是不是我造成的」**。
> ⇒ 查重要用「**成因 / 共線 / 把機制拿掉**」去打;**用「負對照」一定命中舊條然後被判成不新**。

## 判別句(主句)
> **把你剛裝的那個機制【拿掉或關掉】,其他一切不動,再跑一次。**
> **它還綠 ⇒ 那個綠不是你造成的 —— 而你正打算把它寫進報告。**

## 我開了哪幾條、為什麼判它不同族(§12-36)

**尺一(traps-neighbours,2026-08-29 跑)前 8 名最高 `0.2876`**,而工具自己的示範是
`0.4658` 開檔讀後仍判【不併】⇒ 分數這一側沒有近親。**逐條開檔判如下:**

| 既有條目 | 它問什麼 | 為什麼不是本條 |
|---|---|---|
| 正本 `:10618`「把突變留成測試 ≠ 那個測試會抓到那個突變」 | **我這一格和 bug 是不是同一個東西**(量錯對象) | 那條的守門**指著旁邊那個東西**;本條的守門**指對了**,壞的是【結果的成因歸屬】 |
| 正本 `:20162`「我的第一個動作破壞了我要量的那個狀態」 | 觀察行為改變了被觀察者 | 那是**量測擾動**;本條裡我的機制**沒有改變任何東西** —— 它根本沒承重 |
| memory `feedback_an-absent-dimension-cannot-fail` | 測資裡沒有那個維度 ⇒ 全過零證據 | 那是**分母缺一格**;本條的分母是滿的,**成因有兩個** |
| memory `feedback_a-mechanism-must-judge-not-just-ask` | 機制要能自己判真假 | 那是**機制的形狀**;本條的機制形狀正確,而它**沒有接上** |

📌 **一句話分野:舊條問【我量的是不是對的東西】,本條問【這個結果是不是我造成的】。**
**而兩者在一個綠上完全分不開。**

## 三層(2026-08-29 線C,同一支測試上依序被打出來)

### ① 撿來的世界
```
一支 e2e 靠「這棵工作樹沒有 .env.local ⇒ supabase client 拋錯 ⇒ 撈取失敗」⇒ 綠
而審查打死它：**主樹【有】 .env.local**
⇒ 那個條件每棵樹不一樣，而「今天為什麼綠」變成一個沒有人知道答案的問題
```
📌 **一個撿來的世界與一個造出來的世界,都印同一個綠。**

### ② 改成【自己造】之後,綠**沒有改變**
```
改用 `page.route(… POST → abort)` 自己造那個失敗 ⇒ 仍然全綠
🔴 而區分實驗：把 `abort()` 換成 `fallback()`（= 我什麼都不中斷）⇒ **兩格照樣全綠**
⇒ 那棵樹上有【第二個成因】，兩個成因都通向同一個失敗 ⇒ **共線**
```
📌 **⇒ 我的機制在畫面上生效了,而它一格都沒有承重。**
✅ **補救不是刪掉它**(在沒有第二成因的環境裡它才是唯一成因)——
是**讓測試斷言「我的機制真的發生過」**;而**那一格自己要打一發突變**:
把攔截的比對字串打錯 ⇒ **只有那一行紅,其餘三行照樣綠** —— **那三行正是會藏住它的三行。**

### 🔴 ③ 而我為此寫的「誠實邊界」本身不夠誠實
```
我寫：✅「我造的失敗【足以】讓它紅」= 已證  /  ❌「【必要】」= 未證
🔴 而「足以」那半的證據是【突變實作】（把 error 那一格拿掉 ⇒ 紅）
   —— 它證的是「那段被守的碼承重」，**不是「誰造成了那個世界」**
```
📌 **證明【被守的碼承重】與證明【誰造成了那個世界】是兩個宣稱,而我用前者結案後者。**
🔴 **⇒ 一個誠實標註,可以把一個【證不出來的東西】切成兩半,然後只標其中一半。**
**⇒ 這比「完全沒標」難發現 —— 因為它看起來已經自我限制過了。**

## 可執行的動作(本條的用途)
```
裝了任何「讓它變紅 / 變綠」的機制之後，多跑一發：
  1. 把那個機制【拿掉或關掉】，其他一切不動
  2. 結果沒變 ⇒ 那個綠（或紅）**不是你造成的** ⇒ 現在就寫下來，不要等審查抓
  3. 分不開（有第二成因）⇒ **不要寫「已證」**，寫「共線，在這個環境證不出來」，
     並補一格【斷言我的機制發生過】—— 而那一格自己也要打一發突變
```
