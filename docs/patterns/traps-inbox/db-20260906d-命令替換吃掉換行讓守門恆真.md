## 命令替換的結果**不是你以為的那個東西** —— 同一夜兩個實例,一個讓守門恆真,一個讓 `rm` 清空目錄

> 線【DB】`-db` 2026-09-06。實錘 = `scripts/apply-paste-board.sh` 的 `has_bad_char()`,v2 第一發。

### 發生了什麼

我要一道守門拒收含 TAB 或換行的路徑(它們會把 TSV 切成別的欄,也會讓 `cut -f` 取到另一個檔):

```sh
has_bad_char() { case "$1" in *"$(printf '\t')"*|*"$(printf '\n')"*) return 0 ;; *) return 1 ;; esac; }
```

`$(…)` **會剝掉結尾的換行 —— 全部的**。
所以 `$(printf '\n')` 不是換行,是**空字串**。
樣式因此變成 `*""*`,而**空字串是每一個字串的子字串** ⇒ **命中一切**。

症狀:selftest **42 格裡 17 格紅**,全部紅在

```
🔴 前置①:貼板路徑含 TAB 或換行 ⇒ 拒。
```

而那些路徑**乾乾淨淨**。

### 🔴 坑的形狀

一道要偵測「**某個字元在不在**」的守門,在那個字元被替換成空字串之後,
變成一句**恆真的話**。

🔵 **而它壞掉的方向是【擋掉全部】—— 那反而是幸運的。**
🛑 **同樣一行寫在【允許清單】那一側,就是恆真【放行】** —— 而畫面上一切正常,
   17 格紅會變成 17 格綠,**沒有任何訊號**。

📌 ⇒ **我這次看得見它,是因為我剛好把它寫在「拒收」那一側。那是運氣,不是設計。**

### 判別式

> **任何 `$(…)` 產生的值,拿去當【樣式】或【比較對象】之前,先問它會不會是空的。**
> 而**換行這一種永遠是空的** —— 不是「可能」,是命令替換的定義。

✅ 修法:bash 用 ANSI-C quoting `$'\t'` / `$'\n'`,不要走命令替換;
換行那一半改用 `printf '%s' "$x" | wc -l` 判。

### 這一條與已記的差在哪(查重跑過)

`scripts/traps-neighbours.py` 分母 2,934,最高 **0.255**,而**第一名是我自己一小時前投的另一則**
(`db-20260906c`,不同主題)⇒ 無同族。

🔵 **而工具沒撈到、我自己 grep 到的那一條要在這裡分清楚**:
`memory/feedback_a-value-that-means-absence`(「一個『查無』的哨兵值長得跟真值一樣」)——
**名字幾乎一樣,而機制不同**:
· 那一條的空值來自**資料**(欄位裡放了一個代表「沒有」的哨兵),問題是**我問錯了問題**。
· **本條的空值來自語言本身** —— `$(…)` 的定義就會剝掉換行,**我問的問題是對的,而值在到達之前就被改掉了**。
⇒ 🎯 **一個是「讀錯了資料」,一個是「值在路上被吃掉」。** 解藥也不同:那條是 `COUNT(DISTINCT)`,本條是**別用命令替換造那個值**。

## 實例二(同一夜,幾小時後)· `$(…)` 的結果**被斷詞** ⇒ 一個精確的 `rm` 變成清空整個目錄

> 同檔同支腳本的 selftest。**查重時是這一則排第一(0.301)⇒ 不另開條,接在這裡。**

我要刪掉 selftest 造的那支「檔名含 TAB」的 fixture:

```sh
rm -f "$T/dir/"*$(printf '\t')*.sql
```

`$(printf '\t')` 產生一個 **TAB**,而 **TAB 在預設 `IFS` 裡**。
未加引號的命令替換會被**斷詞** ⇒ 那**一個**引數裂成**兩個**:

```
"$T/dir/"*        與        *.sql
```

第一個 glob 展開成**那個目錄裡的全部檔案** ⇒ `rm -f` **把整個目錄清空了**。

🔴 **而症狀不在原地**:清空之後,**後面另一格**才紅在

```
🔴 前置①:貼板編號 09 在【全部貼板】裡命中 0 支
```

那一格什麼都沒做錯 —— **它的檔被前面那一發刪掉了**。

### 兩個實例的共同形狀

| | 實例一 | 實例二 |
|---|---|---|
| `$(…)` 產生的東西 | 換行 ⇒ **被剝成空字串** | TAB ⇒ **被斷詞成兩個引數** |
| 用在哪 | `case` 的**樣式** | `rm` 的**引數 / glob** |
| 壞法 | 樣式變 `*""*` ⇒ **恆真** | glob 變 `dir/*` ⇒ **全刪** |
| 症狀落點 | 原地(17 格一起紅) | **後面別的格**(讀起來像那一格壞了) |

🎯 **共同的判別式**:
> **任何 `$(…)` 的結果,在放進【樣式】或【命令的引數位置】之前,先問:
> 它裡面會不會有空白、TAB 或換行?**

· 換行 ⇒ **一定**被剝掉(命令替換的定義)。
· TAB / 空白 ⇒ 不加引號**會斷詞**;而加了引號 **glob 就失效** ⇒ 🛑 **兩條路都不對。**
✅ **⇒ 不要用命令替換去拼 glob。** bash 用 ANSI-C quoting(`$'\t'`),要精確刪就用 `find -name` 指名。
