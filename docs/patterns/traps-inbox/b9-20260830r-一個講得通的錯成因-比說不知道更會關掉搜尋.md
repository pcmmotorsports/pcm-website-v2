# 一個**講得通的錯成因**,比「我不知道」更會關掉搜尋

> `-b9` 2026-08-30 · 來源:`-e9` 量到一個假 0 → 給了一個成因 → 那個成因**整個是錯的**
> `-01` 轉、`-b9` 當場複量推翻、`-01` 追出真成因。**三方都留下量測。**

## 事件

```
-e9 自查「/private/tmp 裡有幾支 commit 訊息檔」：
   find … ⇒ **0**        ls … ⇒ **38**
⇒ 它給的成因：「scratchpad 實路徑是 symlink，find 從 /private/tmp 走不進去」
⇒ -01 把那個成因【急播給全隊】
```

🔴 **而那個成因是錯的,而且方向【剛好相反】**(`-b9` 當場在自己的路徑上量):

```
/tmp          ⇒ lrwxr-xr-x  /tmp -> private/tmp      ← **/tmp 才是 symlink**
/private/tmp  ⇒ drwxrwxrwt                            ← 真目錄
而在 -b9 的路徑上：ls ⇒ 169 · find ⇒ 169   **兩者相同，不重現**
```

✅ **真成因(`-01` 追出來的,決定性單一變數驗證)**:

```
她的檔案實路徑從 /private/tmp 起算是 **5 層**，而她寫 `-maxdepth 4` ⇒ 差一層
⇒ 同一條 find 只把 4 改成 6 ⇒ **0 變 636**
```

## 🔴 為什麼「講得通的錯成因」特別貴

```
「我不知道為什麼」          ⇒ 下一個人會繼續找
🔴「因為 symlink」          ⇒ 下一個人【停止找】，並且開始
                              把那個解釋套用到別的地方去
```

> ### ⇒ **一個錯的解釋不是零分,它是負分 —— 它關掉了搜尋。**

⚠️ 而它為什麼會被相信:**symlink 是一個【真實存在、技術上很像】的機制** ——
它聽起來比「我數錯了層數」**專業**。
📌 **⇒ 一個成因的可信度, 與它的正確性無關 —— 而我們用可信度在篩選它。**
(同夜同族:`2/44` 那個數「低得很合理」⇒ 差點推翻一條規矩。)

## ✅ 可執行

> **兩把尺不一致 ⇒ 【不要當場猜成因】。**
> ### **先縮小到唯一變數,讓它自己說。**

本例的唯一變數是 `-maxdepth`:`4 ⇒ 6`,`0 ⇒ 636`。
**那一發【不需要理解 symlink、不需要理解檔案系統】—— 它只需要動一個數字。**

⇒ 而**猜成因**要的是知識;**縮變數**要的是紀律。
**⇒ 前者在你最有把握的時候最危險。**

## 📎 而這件事有一格正面的,要一起記

```
-e9 給了錯成因 ⇒ -01 沒有藏，直接更正並廣播
-b9 當場複量 ⇒ 推翻 symlink 那半，而【沒有順便猜第二個成因】
   （逐字回報的是「在我這裡不重現」＋「symlink 方向與你講的相反」，不是「所以是 X」）
-01 追出真成因 ⇒ 附決定性驗證（4→6 ⇒ 0→636）
```
📌 **⇒ 三個人各自只走一步, 而沒有人在自己那一步上多猜一格** —— **那是它三十分鐘內收斂的原因。**

## 🔴🔴 更正(`-1c` 量到,寫進本條的**同一個小時內**)—— **本條自己犯了它要防的那個病**

上面寫「**真成因(`-01` 追出來的)= `-maxdepth` 差一層**」。
🛑 **那句話對【`-e9` 那一次】成立, 而它【不是】那個假 0 的通解。**

```
`find` 假 0 是【兩個不同的病】，不能合併：

① -1c 那一次 ⇒ **symlink 問題**
   `find /tmp -maxdepth 1`（不加斜線、不加 -L）只回 symlink 自己
   再篩 name ⇒ 變 0
② -e9 那一次 ⇒ **maxdepth 問題**
   實路徑從 /private/tmp 起算 5 層，而寫 -maxdepth 4 ⇒ 差一層

🔴 加 `-L` 救不了 maxdepth 問題；加深 maxdepth 也救不了 symlink 問題
```

📌 **⇒ 併成一條, 下一個人會【拿錯的修法去修對的病】** ——
**而他會看到一個沒有變的 0, 然後以為那個 0 是真的。**

### ⇒ 一次驗清楚的方法(`-1c` 給,四種寫法並排)

```
find X          find X/          find -L X          find <真路徑>
```
```
只有【第一種】掉下去 ⇒ symlink 問題
四種【都】掉下去     ⇒ 去查 maxdepth 或字集
```

## ✅ **symlink 那一族【定案了】—— `-b9` 2026-08-30 用 `-1c` 給的四種寫法實測**

主視窗當時標「symlink 那一族**仍未定案**」。⇒ **現在有數字了。**

```
find /tmp -maxdepth 1           ⇒ **1** 行     ← 🔴 只回 symlink 自己
find /tmp/ -maxdepth 1          ⇒ **4018** 行
find -L /tmp -maxdepth 1        ⇒ **4018** 行
find /private/tmp -maxdepth 1   ⇒ **4018** 行
```

🔴 **⇒ 與 `-1c` 預測的簽名【逐格相符】:只有第一種掉下去。**
⇒ **⇒ 所以那四種寫法並排, 不只是「一個建議的驗法」—— 它是【分得出這兩個病】的一把尺, 而它現在被演過了。**

📌 **⇒ 而這一發只花一個 tool call。**
**主視窗標「未定案」是對的(它沒有量);而【未定案】與【量不到】是兩件事** ——
**這一個屬於前者, 而它與後者在報告上長得一樣。**

### ⚠️ 而射程要標

```
· 這是 **macOS**（/tmp -> private/tmp）上的量測，不是通則
· 只演了 `-maxdepth 1`;更深的層數沒演（而那是【另一個病】，本檔上面那一節）
· 4018 是那一刻 /private/tmp 的內容數，它每分鐘都在變
  ⇒ 🔴 **要看的不是 4018，是【1 vs 4018 那個對比】** —— 而那個對比不會變
```
