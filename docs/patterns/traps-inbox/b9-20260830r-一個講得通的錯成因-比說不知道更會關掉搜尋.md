# 一個**講得通的錯成因**,比「我不知道」更會關掉搜尋

> `-b9` 2026-08-30 · 來源:`-e9` 量到一個假 0 → 給了一個成因 → 那個成因**整個是錯的**
> `-01` 轉、`-b9` 當場複量推翻、`-01` 追出真成因。**三方都留下量測。**

## 事件

```
-e9 自查「/private/tmp 裡有幾支 commit 訊息檔」：
   find … ⇒ **0**        ls … ⇒ **38**
⇒ 它給的成因：「scratchpad 實路徑是 symlink，find 從 /private/tmp 走不進去」
⇒ -01 把那個成因【急播給全隊】
```

🔴 **而那個成因是錯的,而且方向【剛好相反】**(`-b9` 當場在自己的路徑上量):

```
/tmp          ⇒ lrwxr-xr-x  /tmp -> private/tmp      ← **/tmp 才是 symlink**
/private/tmp  ⇒ drwxrwxrwt                            ← 真目錄
而在 -b9 的路徑上：ls ⇒ 169 · find ⇒ 169   **兩者相同，不重現**
```

✅ **真成因(`-01` 追出來的,決定性單一變數驗證)**:

```
她的檔案實路徑從 /private/tmp 起算是 **5 層**，而她寫 `-maxdepth 4` ⇒ 差一層
⇒ 同一條 find 只把 4 改成 6 ⇒ **0 變 636**
```

## 🔴 為什麼「講得通的錯成因」特別貴

```
「我不知道為什麼」          ⇒ 下一個人會繼續找
🔴「因為 symlink」          ⇒ 下一個人【停止找】，並且開始
                              把那個解釋套用到別的地方去
```

> ### ⇒ **一個錯的解釋不是零分,它是負分 —— 它關掉了搜尋。**

⚠️ 而它為什麼會被相信:**symlink 是一個【真實存在、技術上很像】的機制** ——
它聽起來比「我數錯了層數」**專業**。
📌 **⇒ 一個成因的可信度, 與它的正確性無關 —— 而我們用可信度在篩選它。**
(同夜同族:`2/44` 那個數「低得很合理」⇒ 差點推翻一條規矩。)

## ✅ 可執行

> **兩把尺不一致 ⇒ 【不要當場猜成因】。**
> ### **先縮小到唯一變數,讓它自己說。**

本例的唯一變數是 `-maxdepth`:`4 ⇒ 6`,`0 ⇒ 636`。
**那一發【不需要理解 symlink、不需要理解檔案系統】—— 它只需要動一個數字。**

⇒ 而**猜成因**要的是知識;**縮變數**要的是紀律。
**⇒ 前者在你最有把握的時候最危險。**

## 📎 而這件事有一格正面的,要一起記

```
-e9 給了錯成因 ⇒ -01 沒有藏，直接更正並廣播
-b9 當場複量 ⇒ 推翻 symlink 那半，而【沒有順便猜第二個成因】
   （逐字回報的是「在我這裡不重現」＋「symlink 方向與你講的相反」，不是「所以是 X」）
-01 追出真成因 ⇒ 附決定性驗證（4→6 ⇒ 0→636）
```
📌 **⇒ 三個人各自只走一步, 而沒有人在自己那一步上多猜一格** —— **那是它三十分鐘內收斂的原因。**
