## 判別句

```
突變證據要記【紅了幾格】, 不只記【有沒有紅】。
一發紅很多格 ⇒ 那一發的證明力**集中在一格上**, 其餘是連坐。
⇒ 而「紅得多」讀起來像【守得嚴】, 那是相反的。
```
