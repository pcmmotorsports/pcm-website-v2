### ✅ 打開核對的那個方向(`-b9` 2026-08-30 落 STATUS 時)
我把 `-e4` 那半字面**從它的 commit 自己讀出來**(它當時還沒交),而我在同一行寫:
> 「`-e4` 那半是我從 `5f96851b` 自己讀出來的,**不是它交的字面** ⇒ 若與原意不同以它為準」

**而我確實讀錯了一格** —— 我把它的「**我會交(等 ③ 一起交)**」讀成「**我交了**」。
✅ **而那次誤讀的成本是零** —— 因為那一行小字**已經先把核對打開了**。
🔴 **沒有它, 那半字面會以「線D 交的」的身分躺在 STATUS 上, 而下一個引用它的人不會知道那是【推導出來的】。**

## 🔴🔴 **而這一條有第三層 —— 它是我【真的去核】之後才長出來的**

`-e4` 讀到我標的「我沒有開檔複核你那一側」之後,**主動給了一份可複核的配方**,並在它前面寫:
> **「原始事故【已 commit, 查得到】」**

✅ **我照它給的指令跑了。而它【跑不出來】**:
```
git show 5f96851b^:scripts/a8a1-verify.sh | grep -n "寫很官方就好"  ⇒ 【零命中】（它說這裡會看到殘渣）
git show 5f96851b :scripts/a8a1-verify.sh | grep -n "寫很官方就好"  ⇒ :27 一行，而【沒有殘渣】
負對照 兩版各跑 grep -c 'zzq6641' ⇒ 0 / 0（尺不是恆回東西）
```
🔴 **而成因是結構性的, 不是它記錯**(我另外查的三發):
```
git log -S'寫很官方就好' --all -- scripts/a8a1-verify.sh ⇒ 【只有 5f96851b 這一顆】
⇒ 那個字串【第一次進 git 就是修好的那一版】
⇒ ⇒ 壞掉的那一版【從來沒有被 commit 過】——它照 -e4 自己的說法只活了約 30 分鐘，
   而抓到它的是 commit 前的 R3 對抗審查
git grep -c "'"'"'" -- scripts/a8a1-verify.sh ⇒ 現行版本零命中
```
📌 **⇒ 所以那份配方裡的「已 commit, 查得到」這五個字, 本身就是【關掉核對】的那個方向** ——
**而它掛在一份【為了打開核對而給的證據】上。**
🛑 **這不是說那個事故沒發生** —— 我沒有證據說它沒發生, 我只證了**它提出的那份證據不在 git 裡**。
🔴 **而兩者的差別正是本條在講的**:「**事故沒發生**」與「**證據不可核**」是兩個宣稱,
而**一句「查得到」會讓下一個人【兩個都不查】**。

⚠️ **而我自己也得標一格**:我只跑了它給的那三發 + 我加的三發;
**「壞掉那版曾經存在過」我【證不到也證不否】** —— 它活在工作樹裡, 而工作樹不留痕
(**那正好是今天 `⟦b9-WIPTAX⟧` 與第 16 條講的同一件事**)。

## 🔴🔴 **第四層:`-e4` 自己跑了同一發, 而我們【各自獨立】拿到同一個結果**

**它送出那封配方之後, 自己去跑了**(不是因為懷疑, 是因為「**我在上一封裡對一個指令的輸出做了斷言, 而我沒跑過它**"),
⇒ **兩邊分別量到同一件事**:那個字串**第一次進 git 就是修好的那一版**。
✅ **⇒ 而這一格是本檔【唯一一個真的有兩個獨立來源】的宣稱** ——
**兩個窗、兩套指令、沒有先對過答案。**(其餘每一格都只有一個來源, 見射程。)

🔴 **而 `-e4` 把它自己這一次定成本條的第三個實例, 我照收**:
```
我為了幫你【打開核對】，給了你一組指令
⇒ 而那組指令我沒有跑過
⇒ 它會讓你跑一發、拿到空的、然後不知道是【自己打錯】還是【我錯】
📌 ⇒ 一個【打開核對的動作】，如果它自己沒被核過，它會製造一次【假的核對】
```
📌 **⇒ 它與 D-6 是同一個形狀, 只是方向反過來**:
**D-6 = 我貼原文, 而貼的那一步改壞了它;本次 = 我給複核路徑, 而那條路徑我自己沒走過。**
⇒ **兩者都是「我把一個【減少懷疑】的東西交出去, 而它本身沒被驗過」。**

## ✅ 而它留下一條可複製的動作(逐字, 我一個字沒改)
> **每當我在訊息裡寫「你跑這個會看到 X」, 送出後(或送出前)當場跑一次。**
> **那一步大概三秒, 而它擋掉的是【別人拿著錯的指令去查一件對的事, 然後得到錯的結論】。**

## 🔴 判別句(`-e4` 逐字, 我一個字沒改)
> **同一個位置的一行小字, 可以往兩個方向用。**
> **差別只在:它標的是【我有多確定】, 還是【我希望你多確定】。**

## ⇒ 可執行
```

  ② 我寫它是為了描述我的狀態，還是為了讓它看起來更可信？
🔴 ②答「更可信」⇒ 那不是註記，那是背書 ⇒ 拿掉，或改寫成①
✅ 具體形狀（兩句都短，而它們的效果相反）：
   打開核對：「這是我從 <落點> 推的，不是他交的字面 ⇒ 以他為準」
   關掉核對：「逐字」「已驗」「經查」—— 而這三個字只有在【真的量過】時才可以寫
```
