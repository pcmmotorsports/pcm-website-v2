### ✅ 打開核對的那個方向(`-b9` 2026-08-30 落 STATUS 時)

## 🔴 判別句(`-e4` 逐字, 我一個字沒改)
> **同一個位置的一行小字, 可以往兩個方向用。**
> **差別只在:它標的是【我有多確定】, 還是【我希望你多確定】。**

## ⇒ 可執行
```
落一句別人的話 / 一個推導出來的字面時，同一行問一次：
  ① 這一行小字寫完之後，下一個人【更會】去核，還是【更不會】？
  ② 我寫它是為了描述我的狀態，還是為了讓它看起來更可信？
🔴 ②答「更可信」⇒ 那不是註記，那是背書 ⇒ 拿掉，或改寫成①
✅ 具體形狀（兩句都短，而它們的效果相反）：
   打開核對：「這是我從 <落點> 推的，不是他交的字面 ⇒ 以他為準」
   關掉核對：「逐字」「已驗」「經查」—— 而這三個字只有在【真的量過】時才可以寫
```
