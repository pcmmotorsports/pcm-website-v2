## 一個錨命中【兩列】有兩種成因, 而它們印同一個東西 —— 而處置相反〔定位〕

**線** `-ship` 2026-09-08 · 判 `⟦b4-SWEEPDEAD1⟧` 時撞到 · **自述**

### 事情

我要改板上那一列, 用錨去定位 ⇒ **命中兩列**。
第一反應是「我的尺太寬」—— 而我去查之後發現**兩種成因都可能, 而它們的處置相反**:

```
成因① 別的列在【引用】它 —— 內文提到那個錨(今晚的 :2286 / :991 / :992 就是這種)
      ⇒ 尺該收窄:只看【錨欄】不看整行
成因② 板上【真的有兩列】掛同一個錨
      ⇒ 尺沒有錯。收窄它反而會漏掉真的那一列
```
🔬 **我這一次是 ②**:`:660` 是資料列(12,403 字元 · 態 `open` · token `⟨未判·要讀完⟩`),
而 `:1627` 是一張**索引表**的列(**態欄是數字 `384`** · **63 字元** · **無 token**)——
**兩列的錨欄逐字都含那個錨**(一個帶反引號一個不帶)。

### 🎯 母題

**「同一個錨出現兩次」印出來的東西, 對兩種成因是一樣的** ——
而人的下一步通常是**回頭改尺**(因為「我剛剛才寫那把尺」是最近的記憶),
🔴 **而成因② 底下, 改尺會讓你漏掉真的那一列。**

📌 **⇒ 分辨器不是行號, 也不是錨** —— 是**那一列有沒有 token**:
```
✅ 資料列  ⇒ token 欄有 ⟨擋 / ⟨不擋 / ⟨未判 / ⟨—
🔵 索引表列 ⇒ 態欄是數字、無 token、幾十字元
```

### 🔴 而我同一發還錯了一次更基本的
```
第一版:enumerate(L) 的 0-based i 直接當行號印, 而斷言用的也是 i ⇒ 兩者差一
⇒ 我印出「命中 :1992」而工具說 :1992 ⇒ 看起來一致, 實際上我操作的是 L[1992] = 第 1993 行
✅ 修法:命中一律收 1-based, 而【與 board-row-by-anchor.sh 的答案對一次】
```
🛑 **兩把尺印同一個數才叫一致** —— 而我那一發是「我的數字看起來對」不是「兩把尺同意」。

### ✅ 可機械執行

> **拿錨定位而命中 >1 時, 先問【那幾列各自有沒有 token】, 再決定要不要改尺。**
> ⇒ 而**跨樹一律用錨不用行號**(同一個錨在不同 worktree 的行號不同;
>   主視窗 A 2026-09-08 差點拿 `tidy` 樹的 `:1988` 去裁 `-ship` 樹的 `:1992`)。
> 🔵 而**錨本身也不保證唯一** —— 那是「用錨不用行號」的下一層。

### 📎 鄰居
- 本檔正本 `:8750`「一個 `0` 可以有**兩個獨立原因**」—— 🔵 **同族而受詞相反**:
  那條講**同一個 0 有兩個成因**(排除一個之後 0 還在, 人會以為第一個沒修好);
  本條講**同一個 2 有兩個成因**(而其中一個成因下, 「修好」那個動作是錯的)。
- 本檔正本 `:9720`「同一個檔案裡的行號引用, 會被這個檔自己的增長弄壞」—— 板列每天被寫, 行號天天在動。

### ⚠️ 這一條證不到什麼
- 我**只看過這一個實例**(`⟦b4-SWEEPDEAD1⟧`)。板上還有幾個錨是雙列的, **我沒有掃**。
- 「索引表列一定沒有 token」是我從**一個樣本**歸納的 —— 而那張索引表我沒有通篇讀。
