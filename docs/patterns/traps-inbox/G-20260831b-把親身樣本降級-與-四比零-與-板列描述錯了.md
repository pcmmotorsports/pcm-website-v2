# 第一條 · 一個支持我假設的親身樣本,要用一個**與它無關的量測**去定位它有多重要

## 實例

我今晚親自被一道 hook 擋下來(它說我沒跑查重,而我跑了)。
那是「**流程有障礙**」這個假設的**直接樣本**,而且發生在我自己身上 ——
**沒有比這更容易採信的證據了。**

而我沒有拿它去支持結論。我算了一個**與它完全無關**的數:

```
問：正本的成長，有多少比例伴隨 traps-inbox 檔被刪？
數法（可重跑）：
  git log --since=2026-08-25 --format='%H' -- docs/patterns/guard-and-instrument-traps.md
  逐顆 git show --diff-filter=D --name-only --format= <hash> | grep traps-inbox/
實測：2 / 120 ≈ 1.7%
```

⇒ **那個數讓我的親身樣本【變得不重要】**:
**就算完全沒有障礙,那 118 顆 commit 仍然不會經過 inbox。**

## 判別句

📌 **降級一個親身樣本的方式,不是說「這只是一個樣本」** ——
那是**廉價的謙虛**:它聽起來謹慎,而**它不改變任何人的判斷**,
因為它沒有告訴你那個樣本到底有多重要。

✅ **要做的是【算出一個讓它不重要(或重要)的數】。**
```
「這只是一個樣本」⇒ 讀的人仍然可以照原樣採信它
「就算它成立，那 118 顆仍然不會經過」⇒ 讀的人【沒有辦法】再照原樣採信它
```
🔴 **⇒ 而最需要這一步的時候,正是那個樣本【支持你】的時候** ——
**反對你的樣本你本來就會去查;支持你的那個不會。**

# 第二條 · **四次全部由工具抓到、零次由人抓到** —— 那個 4:0 就是機制的量測值

> **這四次的數法**(全稱句守門要求):它們是**本 session 對話裡的四發**,
> 每一發都有一個當場的輸出(`python3 scripts/md-table-overflow.py <檔>` 從 N 列變 N+1 列)。
> 🔴 **而「零次由人抓到」是【我自己這一夜】的觀察, 不是全站統計** —— **未數**:
> 別人有沒有靠肉眼抓到過同一種形狀(那沒有留下痕跡, 見本節末尾的射程)。
> ⚠️ 四發之中前三發的落點:`docs/launch-todo.md` 兩處 + `~/pcm-mailbox/證據-出貨-十一個突變-20260831.md`;
> 第四發在 `docs/launch-todo.md:431`。**四個落點都可以開檔看到修法。**

## 實例(同一夜,同一個人)

我今晚四次寫出「表格裡的內容會在渲染時被丟掉」的形狀:

```
① 手打（追記寫在收尾豎線後面）
② 手打（反引號裡一根裸豎線）—— 而 ① 之後我才剛寫下「病換一種形狀就又長出來了」
③ 一支我自己寫的腳本【批次產出】12 列同款
④ 又一次反引號裡的裸豎線 —— 🔴 而我是在【寫「教訓該怎麼落檔」的那一顆】裡踩它的
```

**四次的抓到者**:
```
scripts/md-table-overflow.py ⇒ 4
我自己（讀過、寫過、剛被抓過）⇒ 0
```

## 判別句

📌 **⇒ 那個 4:0 不是「我不小心」的證據,是【機制優先律】的量測值。**
🔴 **而 ③ 特別**:一支工具**不會犯錯,它只會把你的錯法規模化** ——
而規模化的錯**看起來比手打的錯更像正常輸出**,因為**「齊」正是我們用來判斷「它有在工作」的訊號**。
🔴 **而 ④ 特別**:**正在書寫某條規則的當下,是它最容易被違反的時刻。**

⚠️ **這一條的射程**:4:0 是**一個人、一個晚上、一種形狀**。
**未數**:別人有沒有靠肉眼抓到過同一種 —— 那沒有留下痕跡。
⇒ 📌 **所以它是「機制在這一格贏了」,不是「人永遠抓不到」。**

# 第三條 · 一列可以同時「還開著」而「**講錯了發生什麼事**」

## 實例

板上 `#838` 那一列的標題逐字是「**traps-inbox 收割停了而堆積翻倍**」。
```
「還開著」  ⇒ ✅ 對（那 111 檔確實還躺著）
「收割停了」⇒ 🔴 錯（它沒有停 —— 只是 118/120 走的是另一條路）
「翻倍」    ⇒ 🔴 錯（27 ⇒ 112 是 4.1 倍，而板上那個 27 是六天前量的）
```
⇒ **那一列六天沒有人答得出「為什麼停」——**
📌 **因為問題問錯了:它預設了一個【從來就不是主要那條路】的管線。**

## 而工具答不出這一格(`-22` 指出,我複述)

`scripts/is-this-still-true.sh` 答的是「**這一列還成不成立**」,
**而答不出「這一列的【描述】成不成立」。**
> **數法**:`bash scripts/is-this-still-true.sh "<錨>"` 的五段輸出逐段看 ——
> ①有人 commit 修掉了嗎 ②板上那一列的態 ③字面還在碼裡嗎 ④下面有沒有就地訂正 ⑤mailbox 有沒有更正。
> 🔴 **五段沒有一段在問「這一列講的那件事是不是真的」** —— 而那不是它壞掉, 是它**沒有宣稱**要答那個。
> (它自己的射程段逐字列了掃不到的三樣:別的 session 的對話 / 正式庫現況 / OD 稿。)
```
一列可以同時：
  · 還開著（狀態對）
  · 而它講錯了發生什麼事（描述錯）
⇒ 🔴 而板子上只有【一格】，兩個宣稱擠在同一格
```

## 判別句

✅ **接手一列時要問【兩次】**(⚠️ 而「沒有工具會問」那句是**我這一夜的觀察, 未做全站盤點** ——
`grep -rl "描述.*成不成立" scripts/` ⇒ **0**, 而那只證明那個字面不在, 不證明沒有工具在做那件事):
```
① 這一列還成不成立？        ← 工具答得出
🔴 ② 這一列【描述的那件事】，真的是那樣嗎？ ← 沒有工具會問；只有去量那個前提才知道
```
📌 **⇒ 而抓到它的不是任何工具叫我去量,是我【去量了那個前提】。**
🔴 **⇒ 一個前提被寫進標題之後,它就不再被當成宣稱,而被當成背景。**
