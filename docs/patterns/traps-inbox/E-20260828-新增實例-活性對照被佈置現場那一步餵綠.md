> 2026-08-28,線B(`-d3`),假守門盤點第二輪。**不推翻既有任何一條**;
> 最近的鄰居是正本 `:11926`「對照組也是一把尺 —— 而它壞掉時,喊的是主結果不可信」,
> 我讀了那一整節(含 ①②③ 三條可執行的),判**不同族**:
> 那一條講的是「對照組與主查詢**差在寫法還是差在對象**」——**對照組自己寫錯**;
> 這一條講的是**對照組寫對了、機制也對,而它被【前置步驟】滿足** ——
> **沒有任何一段碼是錯的,錯的是「誰先動的手」。**

## 事發

`apps/admin/src/components/orders/cancel-result-panel.test.tsx:229`
斷言「本來就沒有 `r`/`rt` 時,**完全不呼叫** `replaceState`」——
整格只有一條負向斷言 ⇒ 元件根本不跑時也印綠。我去補一個**活性對照**:

```ts
cleanup();
setUrl(`?r=${SENT_CODE}&rt=${TOKEN}`);
render(<CancelResultUrlCleanup />);
expect(spy).toHaveBeenCalled();          // ← 第一版
```

讀起來完全正確:「換成該清的世界,它必須清一次。」

## 而 `setUrl` 自己就呼叫 `replaceState`

```ts
function setUrl(search: string) {
  window.history.replaceState(null, '', `/orders/abc${search}`);
}
```

⇒ 那顆 spy 在 `render` **之前**就已經被呼叫過一次了 ⇒ `toHaveBeenCalled()` 恆真。

**實測**:把元件的 `useEffect` 整個早退(`if (true) return;`,它完全不跑)
⇒ **這一格照樣過。**

## 修法:先記基準,再渲染

```ts
const before = spy.mock.calls.length;   // setUrl 自己也會呼叫
render(<CancelResultUrlCleanup />);
expect(spy.mock.calls.length, '連該清的時候都沒清 ⇒ 元件沒在跑').toBeGreaterThan(before);
```
同一發突變下當場紅:`expected 1 to be greater than 1`。

## 📌 判別句

**我的對照組,是被【受測物】滿足的,還是被【我佈置現場那一步】滿足的?**

⚠️ 這在原始碼上**看不出來** —— `setUrl` 是一支三行的 helper,名字叫「設定網址」,
它做的事(寫一次 history)**寫在它的實作裡,不在它的名字裡**。
⇒ 判法不是讀,是**打一發突變**:把受測物整個停掉,對照組**必須**紅。

## 🔴 抓到它的不是審查

它在正對照裡是綠的、typecheck 綠、lint 綠、code 讀起來對。
抓到它的是「**每補一個錨,就對那個錨各打一發突變**」這條紀律。
📌 **審查看的是碼,而這一格的病在「誰先動的手」——那不在碼的表面上。**

## 同一天的姊妹則:量守門的那把尺,犯的是同一種錯

我用來掃「裸的負向斷言」的腳本**會讀到註解**。
我為修好的格子寫的註解裡有一句「下面那條 `not.toMatch` 恆真」
⇒ 下一次量測時,那一格**已經修好了**卻又被判成裸的 = 假紅。
```
同一批檔、同一顆 commit:舊尺(不剝註解)24 格 · 新尺(剝註解)13 格
⇒ 11 格是被【我自己寫的說明文字】誤判的
```
📌 **一把用來找「恆真斷言」的尺,自己被文字餵出了恆真的判決。**
⚠️ 剝註解時**要把註解換成同樣行數的空白**,不能直接刪 ——
   直接刪會讓後面每一個行號往上飄,而**飄掉的行號看起來完全正常**
   (正本記過一份表 16 個行號差 1 的事故)。

### 🔴 而「剝註解會讓行號飄」這一格,有一份**已經發生過**的實錘

CLAUDE.md 路由表逐字記著:`docs/design/od-cascade-winning-values.md` 的「最後贏家」欄
曾有 **16 個行號差 1**(同方向、零例外)—— **不是稿變動造成的, 是產表當下就錯了**。
而那份檔逐字寫著「每一行都已個別用 grep/sed 對過原稿(不是套用單一固定偏移量)」
⇒ **它可信度最高的那句話, 正是最不該相信的那句。**

📌 **我這一發與那一發是同一個機制**(一個系統性的行號位移, 而位移後的行號看起來完全正常),
   差別只在:**那一次是產出之後才被發現, 這一次是在造出它之前停下來的。**
⚠️ 停下來的原因不是我謹慎, 是我**當場把新舊兩份輸出的行號並排看** ——
   `:44 :276 :290` vs `:49 :294 :308`。**一個人只看新那份, 它沒有任何形狀。**
