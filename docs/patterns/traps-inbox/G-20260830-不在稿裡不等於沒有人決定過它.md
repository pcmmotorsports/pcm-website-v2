# 「不在稿裡」不等於「沒有人決定過它」 —— 而拍板住在一行 CSS 註解裡

2026-08-30 線G。主視窗要我量「出貨單的內容那一側到底省得出多少高度」。

我把 7 項那張紙逐塊量完,分成三類:
```
照稿的          壓它 = 偏離 design ⇒ 要 Sean
我方自訂的      壓它不動稿
影響可讀性的    字級、行高
```
而唯一「我方自訂」的一塊是 6.74mm ⇒ 我算出上界 6.74mm,
而 6 項那個病只超出 3.3mm ⇒ 我下了結論:**6 項那半不用問 Sean 就解得掉**。

而那是錯的。

拆開看:那 6.74mm **不是空白,是一行字** ——「列印時間 2026-08-30 00:24」。
而 `print-a4.css:870` 的註解逐字:
```
/* 頁尾列印時間(`Q-⑨`=甲,Sean 2026-08-24「頁尾一行淡色小字」)。
   🔴 **稿上沒有這個元素** ⇒ 值不是搬的… */
```
它是 **Sean 自己拍的**。而我複驗過:稿裡「列印時間」出現 **0 次** ——
所以「它不在稿裡」是對的,而**我從那個對的事實推出了一個錯的結論**。

真正的上界是 **0**,而 6 項那半也不成立。

## 形狀

我的三分類**少了第四類:【Sean 拍過的】**。
而它在檔案上與「我方自訂」**長得一模一樣** —— 兩者都不在稿裡、都是我們寫的 code。

**唯一分得開的是那一行註解。**

⇒ 而若那一行註解沒寫,我會壓掉一個他拍過的東西,而**沒有任何東西會叫**:
稿沒有它 ⇒ 對稿不會紅;測試不驗它的高度 ⇒ 三綠不會紅;
畫面上它只是一行淡色小字 ⇒ 少了也不明顯。

## 自檢

要動一段「不在設計稿裡」的 code 之前,問:
**「不在稿裡」有兩種 —— 沒有人想過它,或者有人想過而那個人是 Sean。**
而分辨它們的唯一辦法,是**去讀那段 code 旁邊的註解**,或 `grep` 決策紀錄。

⚠️ 而反過來也要記著:**這一次是那行註解救了我。**
⇒ 所以「拍板要落檔」那條規矩,在這裡有一個具體的救援實例 ——
而它落的位置是**下一個要動那段 code 的人一定會看到的地方**,不是一份文件。

### 🔴 為什麼 `#1` 是互補而不是同一條
```
#1  拍板【落檔了】，而那個決定指著的檔沒跟著改
    ⇒ 下一個人照檔案判斷 ⇒ 判錯     （失敗案例：紀錄過期）
🔴 本條 拍板【落在對的地方】—— 就在那段 code 旁邊的註解裡
    ⇒ 而它【救了我】：我正要把它當成「我方自訂」壓掉
    ⇒ 而分辨「我方自訂」與「Sean 拍過的」，那一行註解是唯一的線索
```
📌 **⇒ #1 講的是【紀錄失效時會怎樣】, 本條講的是【紀錄有效時它長什麼樣】。**
⇒ 而本條的可執行那一半正是 #1 的反面:
**拍板要落在【下一個要動那段 code 的人一定會看到的地方】, 不是一份文件。**
⚠️ 而**兩條合起來才完整** —— #1 說「別讓它過期」,本條說「先讓它在正確的位置」。
