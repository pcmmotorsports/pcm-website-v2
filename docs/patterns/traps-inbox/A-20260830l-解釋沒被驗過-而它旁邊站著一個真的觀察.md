## 三次,原樣列出來 —— **不挑一個當代表**

```
① 我量到 find ⇒ 0 而 ls ⇒ 38（觀察正確）
   我寫的解釋：「symlink 讓 find 走不進去」
   🔴 真成因：-maxdepth 4 而路徑深 5 層（同一條指令改成 6 ⇒ 0 變 636）
      而 symlink 方向我還講反了（/tmp 才是 symlink）

② 我做了一支「當客人去讀一發」的探針，而它真的會紅（觀察正確）
   我寫的解釋：「那 8 條反例對它【全部不成立】」
   🔴 真相：我沒有逐條餵那 8 個世界。後來只補驗了 1 條（RLS）⇒ 1/8

③ 我出反例：一顆帶 pathspec 的 commit 過了（觀察正確）
   我寫的解釋：「git commit -- <pathspec> 不更新 index ⇒ 兩邊同一棵樹 ⇒ 放行」
   🔴 真成因（-e4 四世界對照實驗）：那道閘在比 tree【之前】先判
      「這顆有沒有碰受審面」，沒碰 ⇒ 靜默放行、連比都沒比
      而我那顆只改一支 docs/*.md ⇒ 受審面檔數 = 0
```

📌 **⇒ 三個都是【正確的觀察 + 沒驗過的解釋】,而三次都是同一個人在同一夜。**
🔴 **⇒ 那個密度本身是證據:它不是偶發,是一種【預設反應】。**

## 🔴 判別句

> ## **我的【結論】對,而我的【理由】錯。**

**⇒ 而結論對的時候,沒有人會去讀理由。**
⇒ ⇒ 🔴 **而錯的理由會跟著結論一起流出去。**
實錘:③ 那個錯理由被我寫給了 `-1c` 與 `-48`,**而 `-48` 照著它去設計了一個對照實驗的問法。**

## ✅ 可執行動作

落筆寫「**機制上說得通:因為 X 所以 Y**」的時候,問一句:

```
🔴 我有沒有一發輸出，是在【X 不成立】的世界裡跑的？
   有  ⇒ 那是機制
   沒有 ⇒ 那不是機制，那是一個【與觀察相容的故事】
```

📌 **⇒ 而「相容」與「正確」,在只有一個世界的樣本裡,長得一樣。**

**三次各自缺的那一發,現在寫得出來了:**
```
① 缺：把 -maxdepth 改大再跑一次（後來跑了 ⇒ 0 變 636 ⇒ symlink 那個解釋當場死）
② 缺：造一個 security_invoker 翻面的世界餵給探針（至今只補了 RLS 那一個）
③ 缺：拿一支【會碰受審面】的檔、同樣帶 pathspec 送一次（-e4 跑了 ⇒ 擋）
```

## 🔵 而為什麼它在**多人**的隊伍裡特別難防

`-48` 的歸納:**一個在你的樣本裡從不變化的東西,你不會發現它是變數。**

```
🔴 而那【不是「樣本太小」】——
   我跑了好幾顆，-e4 也跑了好幾顆
   而我們各自的樣本【內部一致】⇒ 每個人都通過了自己的複現檢查
⇒ ⇒ 而「連跑兩發相同」在這裡【幫不上忙】：同一個常數會複現同一個結果
```
📌 **⇒ 那是「重現性不是效度」在【多人】這一層的版本** —— **而多人那一層,今晚才第一次撞到。**
⇒ **⇒ 兩個人各自誠實、各自驗過、而合起來的結論是錯的。**

## ⚠️ 天花板

- 它擋不住「**我根本沒有寫出理由**」那一種 —— 沒寫出來的解釋,連被問的機會都沒有。
- 🔴 而它**特別擋不住「結論對」那一種** —— 而那正是本條要防的,**所以它的動作必須綁在【落筆的當下】,不能綁在【事後檢查】**:事後沒有人會回去讀一個對的結論的理由。
- 它是**規矩不是閘**:沒有東西會在你寫下一個沒驗過的機制時變紅。
