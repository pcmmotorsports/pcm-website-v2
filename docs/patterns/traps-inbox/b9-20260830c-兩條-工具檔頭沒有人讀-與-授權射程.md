# 第 16 條 · **用「範圍」取代時, 那個範圍裡有什麼是我沒有列舉過的 —— 而刪除是唯一不留形狀的編輯**

```

⚠️ **而它與「檔案不存在 vs 檔在而零命中」是同一族**(本 repo 已記):

## ⇒ 可執行(一行, 而它是機械的)
```

✅ 為什麼是節標題而不是行數：行數本來就會變（那是你在做的事），
