## 一格證人的副作用落在【別人的樹】上 —— 而它印的是自己的 `PASS`

**線** `-auth` 2026-09-06 · `⟦02-SELFTESTTIMEOUTGREEN⟧` · **自述**(而抓到它的是 codex,不是我)

### 事情
我要證「`selftest-git-isolation-gate.sh` 全量那半,遇到逾時會 `exit 2`」。
證人格寫成:**把上限設成 1 秒,跑一次全量掃** ⇒ 它一定命中「量不到」⇒ 回 2。**這一格會過。**

🛑 **而全量掃的定義是:把 81 支候選的 `--selftest` 每一支都真的跑一遍。**
⇒ 用 1 秒的上限 = **把那 81 支【每一支】都砍在第 1 秒**。
⇒ 📌 **那幾支會寫暫存檔的, 就被砍在【寫到一半】** ⇒ 它們的 fixture 留在工作樹上:

```
apps/_litsweep_selftest_ZQX9.test.ts          docs/handoff/_litsweep_selftest_ZQX9.md
docs/runbooks/_litsweep_selftest_ZQX9.md      docs/specs/_litsweep_selftest_ZQX9.md
scripts/_litsweep_selftest_ZQX9-down.sql      scripts/_litsweep_selftest_ZQX9.txt
supabase/migrations/29991231235959_zzq_selftest_fake_redefine.sql
+ 我自己的 zz-sgi-slow-*.sh ×4(巢狀跑了四次, 而每次只 rm 掉自己那個 $$)
```

🔬 **而它們不是「那些腳本不收尾」** —— 我停掉我的 gate 之後**讓 `literal-sweep` 自己跑完**,
它**把自己的六支檔全部清掉了**。⇒ ✅ **殘留是【被砍】造成的,而砍它們的是我的證人格。**

### 判別句
> **我這一格證人,跑起來會【動到】什麼?而那些東西是不是我的?**
> —— 一格證人的正確性只被「它有沒有印對」檢查,**它的副作用沒有任何人在看**。

### 🔴 為什麼這個形狀特別難自己發現
- **它會過。** `PASS`,而且是我想證的那件事真的被證了。
- **殘留在【別的目錄】**:`apps/` · `docs/` · `supabase/migrations/` ——
  我盯著的是 `scripts/`(我在改的那支檔)。
- **`git status` 上它們是 `??`**,與別人正在做的新檔**長得一樣** ⇒ 🛑 我第一眼以為那是別窗的東西。
- ⇒ 📌 **我是因為 codex 在審查時順手比對了工作樹,才知道我留了東西。**

### 修法
1. **證人格不要拿【真實的候選集】當靶** —— 造一支自己的假候選,只掃那一支。
   要證「全量那條路」⇒ **就要接受它的真實成本**(這裡是 81 × 上限),不能用縮短上限來偷。
   ⇒ 🎯 **「把上限調小讓它一定命中」看起來是省時間,而它其實是【換了一個受測物】** ——
     從「一支慢的腳本」換成「全部腳本都被砍」。
2. **跑完之後比工作樹**,而且比的是**全樹**不是你改的那個目錄:
   `git status --short` 前後兩份,差集必須是空的。
3. **收尾要收得掉巢狀那幾層**:我的 `rm -f "$SLOWF"` 只刪自己 `$$` 那一支,
   而巢狀自檢又各建了一支 ⇒ 四支留下三支。
4. 🔴 **要停一個正在跑的 harness,先停【父】、讓子自己跑完** —— 直接砍子程序,
   得到的就是本條開頭那堆殘留。
