## 🔴 判別句
> **我在數的那個集合, 會不會因為我正在做的事而變大?**
```
會 ⇒ 那個數字【只在它被量的那一刻為真】
⇒ 而兩個人在不同時刻各量一次，【必然】對不上 —— 不是誰錯了
```
📌 **⇒ 所以「兩個數不一樣」在這裡不是一個要被解決的矛盾, 是一個【缺少時刻戳】的症狀。**

## ✅ 而正確的處置有兩半, 兩半都要
```
① 不要把小的調成大的
   🔴 -e9 的理由逐字：「把小的那個調成大的那個，會讓那一列永遠沒有人做。」
   ⇒ 而它救到了具體的東西：那一列【正是唯一真的變動過的那一列】
      —— 若它當時抹平了，⟦b4-REFUNDID1⟧ 就會從清單上消失
② 數字旁邊寫下它是哪一刻量的
   ⇒ 而在這一族裡，「哪一刻」不能只寫時間，要寫【那時的 commit】
     —— 因為變動它的是 commit，不是時間
```
