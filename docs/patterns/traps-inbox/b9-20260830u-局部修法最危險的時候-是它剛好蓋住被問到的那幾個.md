# 一個局部修法最危險的時候,是它**剛好把被問到的那幾個都蓋住**

> `-b9` 2026-08-30 · `-48` 指名獨立成條、掛 `-b9` 的名

## 實錘

主視窗問:「**要不要替那三列補上識別碼(錨)?**」
那三列是 Sean 起床清單上的,他答完之後今天就會有人回來找它們。
**⇒ 補它們, 看起來完全合理。**

🔴 **而我先去量了母體**:
```
全板 247 列 · 有錨 153（62%）
未關（open/doing/parked）174 列 · 有錨 132（76%）
⇒ 未關而【無錨】= **42** 列          負對照（現造錨）⇒ 0
```

> ### ⇒ **那三列不是特例, 是 42 列裡的三列。它們只佔 7%。**

## 🔴 而沒有那一發量測會怎樣

```
補完那三列 ⇒「被問到的那幾個」全部有錨了
⇒ 下一次有人問「板上的錨夠不夠用」⇒ 他去看那幾列 ⇒ 有錨
⇒ ⇒ 而剩下的 39 列，沒有人會再想起來
```

> ### **⇒ 一個局部修法最危險的時候,是它剛好把【被問到的那幾個】都蓋住的時候。**

📌 **因為那讓【抽樣】與【全體】給出同一個答案** ——
而抽樣正好落在你剛修好的那一區,**那不是巧合, 那是因果:你是照著「被問到的」去修的。**

⚠️ **而它與「樣張只演一個世界」不同**:
```
樣張那一種：你的證據不夠
🔴 本條：你的證據【剛好夠】，而它剛好落在你動過手的地方
```

## ✅ 處置(`-48` 裁,而它的形狀值得抄)

**不是「不要做局部修法」** —— 那三列今天真的會被查,不補是錯的。
```
✅ 乙：補那三列（理由:它們今天就會被查，其餘 39 列不會）
✅ 丙：同時把「未關無錨 39 列」寫進板頭 + 一個當場能跑的數法
🛑 甲（一次補完 42 列）不做:那是一次大量的、每一個都要判斷的動作
   而它在 diff 上與「有人重新編號了 42 件事」長得一樣
```

> ### 🔴 **而丙正好解掉乙的代價**:
> 乙的代價是「**板上從此有兩種列, 而差別只有我們知道**」
> **⇒ 丙那一行把它公開了 ⇒ 就不再是只有我們知道。**

📌 **⇒ 所以修法不是「別做局部」, 是【做局部的同時, 把沒蓋到的那一塊寫成一個可以當場數的數字】。**
**⇒ ⇒ 而它必須寫成【數法】不是【數字】** —— 板頭那一行逐字寫著「**不要引用 42, 它會漂**」
(而它當場就漂了:補完三列之後是 **39**)。

## 📎 一句可執行的自檢

> **被要求修 N 個東西之前, 先問:**
> ### **「這 N 個, 是母體的幾分之幾?」**
>
> 答不出來 ⇒ **先去量, 再決定要不要修。**
> 而量完之後你可能仍然只修那 N 個 —— **差別是, 這一次你知道自己蓋了多少。**

## 🛑 而寫這一條的過程本身撞到今晚那條坑,留著

寫這一條的第一發 Bash 被 traps 查重 hook 擋下 —— **而那一發裡含著「產生本檔」的 `cat`**。
```
⇒ 閘一擋，整發不跑 ⇒ 檔案【沒有被建出來】
⇒ 而我下一步去跑查重，它回「草稿讀不到 [Errno 2]」
```
✅ **而那支查重工具自己把兩者分開了**,逐字:
> **「這是【路徑錯】不是【查無近親】—— 兩者的下一步完全不同。」**

📌 **⇒ 那正是 `-01` 今晚急播的那個形狀**(PreToolUse 擋的是整個 Bash 呼叫, 而前面那幾行看起來像跑過了)——
**而這一次沒有出事, 是因為那支工具【不肯把空手回報成零命中】。**
