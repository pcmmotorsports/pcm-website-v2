# 補角度給正本 `:23122`(正對照要與目標逐字同形)—— **那一條的壞法是【假綠】, 而同一個病往另一個方向走會產生【最貴的假紅】**

- 線【DB 與金流】· 2026-08-31 · 查重跑過:第 3 名 **0.2657** 正本 `:23122`,**開檔讀了** ⇒ 判**補角度、不另立**。
  (第 1 名 0.2804 `:20218`「量具裡藏著一個假設」、第 7 名 0.2578 `:23835`「假的對照組比沒有對照組危險」——
  兩條都讀了,**都是假綠那一側**。⚠️ 全表最高只有 0.28 ⇒ 照工具失效 ② 這一輪的字面重疊本來就低,**排名不是判定**。)
- 🔴 標題刻意含「正對照」與「假紅」—— 這兩個字很少同時出現,而下一個人就是帶著那個組合來的。

## 正本那一條講什麼

> 正對照走的是【版本號】那種寫法,目標走的是【檔名】那種寫法
> ⇒ 正對照只證明了「版本號那種寫法的尺是活的」,它**永遠救不了目標那一把**。
> **⇒ 那一格有正對照、有負對照、兩個都通過 —— 而它仍然是瞎的。**

⇒ 📌 **那一條的形狀是:對照與目標不同類 ⇒ 對照【通過】而尺是瞎的 ⇒ 假綠。**

## 🔴 而同一個病往另一個方向走 —— 我這一發

我在驗一支新 migration 有沒有把 trigger 換壞。**正對照**:送一筆超額 `INSERT`,期望上限閘擋它。

```
判定寫成   把 psql 回來的字串拿去比對 'PCM01'
它印       🔴 正對照失敗, 超額沒被擋:
           ERROR: 這張單在【現金 / 匯款】上目前只剩 700 元可退,退不了 9999 元。
```

**那道閘開火了。訊息就印在它自己的下一行。而我的尺說它沒開火。**

🔴 **成因與正本同一個:對照與目標不同類 —— 我比的是【話】,而 guard 給的是【碼】。**
`psql` 的錯誤訊息裡**沒有 SQLSTATE**。⇒ 修法:讓 plpgsql 自己 `raise notice 'SQLSTATE=%', SQLSTATE`,**比碼不比話**。

## 📌 而方向不同, 代價差一個量級

```
:23122  對照【通過】⇒ 假綠 ⇒ 一個不存在的閘被寫成「已驗證」
我這一發 對照【失敗】⇒ 假紅 ⇒ 而它不是普通的假紅
```

我們記過「**假紅可以排隊,假綠不能**」。🔴 **而這一發是那句話的例外, 理由在【它說了什麼】:**

```
一般的假紅  說「這個東西壞了」   ⇒ 人去查那個東西 ⇒ 發現沒事 ⇒ 損失是【一輪】
🔴 正對照的假紅 說「你對這個系統的理解是錯的」
   ⇒ 人不會去重新量, 他會去【重新設計】
   ⇒ ⇒ 📌 它把成本從「多跑一發」變成「推翻一個正確的設計」
```

⇒ 🛑 **所以「假紅比較便宜」那句話要加一個限定:【對照組的假紅不便宜】** ——
因為對照組是那個**你用來決定要不要相信其他所有格子**的東西。**它一紅,整發的結論都失去錨。**

## 🔵 同一發還有兩個量具的病, 三個全是 harness 不是被測物 —— 而第二個是禮物

```
① Q() 拿 RETURNING 時多收了一行命令標籤(INSERT 0 1)⇒ uuid 語法錯
② 突變跑在【已經 migrate 過】的庫上 ⇒ 前置閘先開火, 而那不是我要演的那一道
   ✅ 而它演出了【前置閘會動】—— 那是本片最重要的一道, 而我原本沒有格子在演它
   ⇒ 📌 補成一格驗收:「同一支重跑必須紅」。**一個 harness bug 變成一格守門。**
③ 上面那個正對照
```

## ⇒ 可執行的一句

> **一個對照組印出你不預期的結果時, 先問「這把尺與被量的東西是不是同一類」, 再問「要不要推翻結論」。**
> 常見的不同類:**碼 vs 話**、狀態碼 vs 畫面文字、退出碼 vs stdout、版本號 vs 檔名(那是正本 `:23122` 的那一對)。

⚠️ 而**兩條要互相指**:正本 `:23122` 答「怎麼挑對照」,本條答「**對照自己紅了的時候怎麼辦**」——
📌 **挑對照有人教,而【對照紅了】沒有人教, 因為大家預設對照會過。**
