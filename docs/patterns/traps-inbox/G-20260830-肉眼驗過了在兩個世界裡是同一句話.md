# 🔴🔴 「肉眼驗 ✅」在**它成立**與**某個外力剛好幫我們達成**兩個世界裡, 是同一句話

> 🔴 **而「肉眼驗」是 Sean 專屬用詞, 我們平常拿它當【最終憑據】** —— 這一條打的正是那一格。

## 那一次(2026-08-17,留在 `print-a4.css` 檔頭)

我們在 `@page` 裡加了頁碼(`@bottom-center{content:'第 ' counter(page) ' 頁…'}`),
請 Sean 用**真印表機、Chrome** 印了一份量具。他逐字回:

> **「列印出來,一切正確」**

追問總共幾頁 ⇒ **「3頁」**。⇒ 當時寫進檔案的是:**頁碼已驗。**

## 🔴 而那句話問不出差別

```
世界一：我們寫的 @bottom-center 生效了        ⇒ 紙上有一行頁碼 ⇒ 「一切正確」
世界二：Chrome 的「頁首及頁尾」沒關掉         ⇒ 紙上也有一行頁碼 ⇒ 「一切正確」
```
🛑 **兩個世界的紙看起來一樣, 而他的回答也一樣。**
⇒ 而「3 頁」證的是**跨頁條件真的被觸發**(排除了「只印一頁所以沒機會出錯」),
**它不證 counter 有沒有渲染** —— 頁數在列印對話框上就讀得到,不必看紙。

📌 **⇒ 那不是他答錯。是我們問的問題在兩個世界裡有同一個答案。**

---

## 🔴 為什麼這一條比一般的「量錯東西」貴

一般的量具坑,壞的是**我們的尺**,而我們可以再量一次。
**這一條壞的是【最終憑據】** ——「肉眼驗 ✅」在這個 repo 裡是**上訴的終點**:
它一寫下去,**沒有人會再去查它**,而它會被引用很久。

⚠️ 而它有一個放大器:**人會回答總評**。
> 「一切正確」「沒問題」「看起來對」——**這些句子的資訊量與世界數無關。**
⇒ 你問一個人「對不對」,拿到的永遠是一個**判斷**;
  而判斷**已經把兩個世界壓成一個**了 —— 壓的動作發生在他腦裡,你看不到。

## ✅ 可執行的自檢

```
🔴 觸發時機：你要請一個【人】去看一個你看不到的東西（紙、真機、正式站、他的螢幕）

🛑 不可以問的三種（它們都回一個判斷）：
   ✗「這樣對嗎？」  ✗「有沒有問題？」  ✗「你要不要看一下 X 有沒有生效」

✅ 要問的形狀：**一個動作 + 幾個【他照抄就好】的字面**
   ·「印一張，然後回我三行字，照抄，不用判斷」
   ·「紙的最下面正中央那一行，逐字唸給我」
   ·「那個勾現在是勾著還是沒勾」（⇐ 這是【分母】，缺它上一行就沒有射程）

✅ 而每一格自問一次：**這一格在【成立】與【不成立】兩個世界，會不會印不同的字？**
   ⇒ 不會 ⇒ 換一格，不要換問法。
```

📌 **⇒ 一句話**:**請人幫你看, 要他回報【兩個世界會不同的值】, 不是一個判斷。**
