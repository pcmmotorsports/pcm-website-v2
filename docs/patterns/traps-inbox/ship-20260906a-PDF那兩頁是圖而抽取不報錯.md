### 事情
`pdftotext -layout` 抽新竹官方標籤規格 PDF(30 頁)⇒ **1225 行**、目錄在、每一節標題都在、rc=0。

### 🎯 母題
**一個工具在「它讀不到」與「那裡沒有東西」這兩個世界印同一個東西。**
而這一次它連 `rc` 都是 0、連一行 warning 都沒有 —— **不是它壞了, 是它做完了它會做的事。**

### ✅ 判別句(抽任何 PDF 之後, 下「文件沒寫」之前)
> **抽出來的東西, 是不是【每一頁】都有?——哪幾頁一個字都沒有?**

機械做法:`pdftotext -f N -l N` 逐頁抽, 數每頁的**非空行**。
⛔ ~~0 行的那幾頁~~ —— 🔴 **我寫完這句就去量, 而它是錯的**:
```
p.29(整頁是圖)  非空行 = 3   ← 標題 + 小節名 + 頁碼, 內容零字
p.4 (正常文字)  非空行 = 13  ← 正對照
```
⇒ 📌 **一頁圖不會抽出 0 行, 它會抽出【標題與頁碼】** —— 那幾行讓它看起來像一頁正常的內容。
✅ 判準改成 **「異常少」而不是「零」**, 而**少到什麼程度要跟同一份文件的別頁比**(3 vs 13)。
🎯 而這一格本身就是本條的母題再演一次:**我用一個聽起來很機械的判準, 而我沒有先量它。**
🔵 而 `Read` 工具吃得下 PDF 的 `pages` 參數 ⇒ 那幾頁直接看。
