## 這一條在講什麼:**同一句話過期,後果依它的【語氣】差一個量級**

```
過期的【描述】   ⇒ 只是沒用           （讀的人拿不到東西，而**他知道**自己沒拿到）
過期的【肯定句】 ⇒ 一個確定的錯答案   ← **本條**
過期的【指令】   ⇒ 把人送到錯的地方   （commit `225266b0`，2026-08-29 線C）
```
🔴 **中間那一種最難抓 —— 它讀起來像一個【已經查證過的結論】。**

## 🔴 為什麼它比「過期的描述」嚴重一個量級

```
過期的描述 :「做法見 X」而 X 已經沒了
  ⇒ 讀的人打不開 X ⇒ **他知道他沒拿到東西** ⇒ 他會去問

🔴 過期的肯定句:「這兩顆未落地」
  ⇒ 他拿到一個**完整、明確、可以直接用**的答案
  ⇒ ⇒ **他不會去問，因為他沒有缺口感**
  ⇒ ⇒ 而他接下來的每一個決定，都建在那個錯答案上
```
📌 **判別句:這句話會不會【讓讀的人停止查證】。會 ⇒ 它是肯定句 ⇒ 它要帶量測時刻與量法。**

## ⚠️ 而它不是「有人寫錯」

```
寫下「未落地」的那一刻，它是【對的】。
而後來有人把那兩顆落地了 —— 而那個人**沒有義務**知道有這一句話在描述它。
🔴 ⇒ 一句肯定句的正確性，掛在【一個它自己看不到的世界】上。
```
🔴 **⇒ 所以本條不是「寫的人要更小心」** —— 那沒有可執行的動作。
✅ **可執行的是:**
```
❌ 「這兩顆未落地」
✅ 「這兩顆未落地(2026-08-16 量;`grep -n -- '--success' apps/admin/src/app/globals.css`)」
⇒ 📌 帶了量法，下一個人重跑只要三秒，而不必先判斷「這句話還準不準」
```
