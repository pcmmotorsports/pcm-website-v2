# 零命中的第四種:網夠寬、也在動, **而它撒在錯的載體上**

> 投稿人:線【信】`-mail` 2026-09-05。
> 📎 **併入建議**:`guard-and-instrument-traps.md:18730`「一個零命中要怎麼樣才算數」的**第四個實例**
> —— 原條的三種都是「網的形狀不對」(窄網 / 字對而東西換名 / 尺沒動), **這一種的網沒問題。**

## 事件

我在探針註解裡斷言一個行為 **「沒有人授權過」**。依據是我開檔查了規格:
那份 plan 裡的「那張」講的是**客人看不到那張已建好的匯款單**, 不是「取消哪一張」
⇒ 我據此寫下「**規格從來沒有講過取消的單複數**」。

🔬 **而那句話對規格而言是真的。** 我開了檔、引了行號、寫了成因。

🔴 **而 Sean 前一晚 22:2x 就拍了**, 原文逐字:
```
Q-多張匯款單: 客人同一批商品開了好幾張匯款單, 然後刷卡付掉其中一張。剩下的怎麼辦?
甲 = 全部一起取消 (推薦, = 現在碼的行為)
```
落點 `~/pcm-mailbox/Sean拍板-20260904-七題.md:579-580`。

## 🎯 為什麼它不是原條那三種

原條的三種失效**都在同一個載體裡**(掃 `admin/` 502 支檔, 而 pattern 不對)。
```
① 窄網:字對了而東西換了名字
② 尺沒動:正對照沒命中
③ 寬網撈到雜訊而逐個判掉之後仍是零 ⇒ 這時才算數
```
🛑 **而我這一次:網夠寬(整個 `docs/`)、尺會動(我真的撈到了那份 plan 並讀懂它)、
　 結論對那個載體而言正確** —— **錯的是【我撒網的地方沒有那個東西】。**

⇒ 📌 **⇒ 它印出來的不是「零命中」, 是一個【對另一個問題正確】的答案。**
　 🔴 **而那比零命中難抓一級**:零命中會讓人再想一下, 而**一個有依據、有行號、讀起來完整的結論不會。**

## 判別句(要加進原條的那一句)

> **「我掃的那個載體, 裝得下這個答案嗎?」**
> 而對「**他說過沒有**」這一類問題, 答案的載體**至少有三個**:
> 　`repo`(規格 / 註解 / commit body) · `~/pcm-mailbox/`(拍板原話) · `memory`(落檔過的拍板)
> ⇒ 🔴 **只掃 repo 就斷言「沒有人說過」, 是結構性失明, 不是不夠仔細。**

## 後果(它已經產生了)

那句話寫進探針註解, 定位是「**這格等的是授權**」
⇒ 🔴 **它會讓下一個人去端一題給 Sean, 而那題他已經答過了。**
⇒ 🔵 而它是主視窗告訴我的, 不是任何一把尺抓到的 —— **我這邊沒有任何東西會叫。**
