# 一句「**不要拿掉**」的註解,同時關掉了「有人會來檢查我還對不對」

> `-auth` 2026-09-08 落。主視窗 `-9b` 從我的自述裡挑出這一句並指定它才是該落的那一句。
> 我原本寫的是「註解有到期日」——**而它把重點放錯了**:到期日大家都知道;
> 🎯 **關鍵是那三個字讓它【不會被複查】。**

## 這一條在說什麼

```
一句描述【別處現在長什麼樣】的註解, 有一個沒有人會去看的到期日,
而過期它的通常就是【寫下一片的那個人】。
🔴 而如果那句註解還帶著紀律語氣 —— 「不要拿掉」「不要改」「這是拍板」——
   它就把一個【會過期的事實】包裝成一條【不該被動的規矩】。
```
🎯 **差別在讀的人會做什麼**:
```
事實  ⇒ 應該被【複查】(它現在還對嗎?)
紀律  ⇒ 應該被【遵守】(照做, 不要動它)
🛑 而讀的人分不出來 —— 他看到「不要拿掉」就跳過去了, 不會停下來問「它現在還對嗎」
⇒ 📌 那三個字保護的東西, 恰好就是最需要被質疑的那個部分。
```

## 實錘(2026-09-08,而過期它的是我)

`apps/admin/src/components/customers/profile-edit-form.tsx:15-17` 原文逐字:
> 「DB 端**連 service_role 都沒有那一欄的 UPDATE 權**(`20260717010000:175` 欄級 GRANT 只有
> name/phone/birthday/updated_at),**要改得另開一片**。欄位旁的說明文字就是講這件事,**不要拿掉**。」

```
① 我貼了 20260908100000 ⇒ service_role 現在【有】那一欄的 UPDATE 權
   (貼後唯讀對帳實測六欄:birthday, email, gender, name, phone, updated_at)
② 那份「只有四欄」的清單在 20260901040000(gender)之後就已經舊了
③ 「另開一片」那一片【就是我做的那一片】, 而它渲染在同一張卡的下面
⇒ 🔴 三句全假, 而我做完那一片【沒有回頭看它】
```
🛑 **而代價不是抽象的**:那句話對應的 `footerHint`(「要改請**另開片處理**」)
**當天誤導了老闆本人** —— 他的截圖切在那一行下面,他把它讀成「功能不在」。
⇒ 📌 **一句在正確的時候寫下、而沒有人負責讓它過期的話, 會在它最不該說話的時候被讀到。**

## ✅ 修法(寫的時候, 不是複查的時候)

紀律語氣的註解要帶**它成立的條件**或**誰會讓它過期**,不要只寫「不要動」:

```
❌ 「…要改得另開一片。說明文字不要拿掉。」
✅ 「…要改得另開一片。⚠️ 這一句在【那一片做出來的那天】就過期 ——
     做那一片的人請回來改這裡, 並把 footerHint 一起改成指路。」
```
🎯 **判別句**:我寫的這一句,**有沒有一個【可以指名的人】會讓它變假?**
有 ⇒ **把那個人寫進句子裡**。那是這條唯一便宜的修法 —— 事後複查太貴,而且沒有人會做。

## 🔬 查重(我開了哪幾條、為什麼判它不同族)

`scripts/traps-neighbours.py` 最高分 **0.2254 < 0.25** ⇒ 工具自己說那是「**尺沒接上**」。
✅ 尺二撈到兩條真近親(`grep -n '^## ' <正本> | grep -E '註解|過期|不要|拍板|到期|舊字面'`,
⚪ 負對照現造標題 ⇒ 0),**我兩條都開檔讀了**:

```
正本 :7240「改一塊註解時只更新【自己新增的那半】」
  ⇒ 不同族:那一條的人【正在那塊註解裡打字】(「不是忘了看 —— 我當下正在看它」),
     而我這一條的人【整支檔都沒開過】。它治「看了而漏半邊」, 我治「根本不會去看」。

     而我這一條多一格:那個語氣**主動抑制了複查**, 那不是單純的靜默。
```
⇒ 📌 兩條都沒有說「**祈使句會保護它自己**」這件事 ⇒ 判為新條。

## ⚠️ 這一條不涵蓋什麼

- **不是**「不要寫『不要拿掉』」—— 有些東西真的不該被動(例:留痕的舊字面、刪除線)。
  🎯 **要分的是:那句話保護的是【一個事實】還是【一個決定】。** 決定可以說不要動;事實不行。
- 🔴 **未量**:我沒有掃過 repo 裡還有幾句同型的「不要拿掉 / 不要改」掛在事實陳述上。
  **那是一個量得到而我還沒量的東西**,標在這裡而不是假裝它是零。
