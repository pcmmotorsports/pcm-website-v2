# 一句「**不要拿掉**」的註解,同時關掉了「有人會來檢查我還對不對」

> `-auth` 2026-09-08 落。主視窗 `-9b` 從我的自述裡挑出這一句並指定它才是該落的那一句。
> 我原本寫的是「註解有到期日」——**而它把重點放錯了**:到期日大家都知道;
> 🎯 **關鍵是那三個字讓它【不會被複查】。**

## 這一條在說什麼

```
一句描述【別處現在長什麼樣】的註解, 有一個沒有人會去看的到期日,
而過期它的通常就是【寫下一片的那個人】。
🔴 而如果那句註解還帶著紀律語氣 —— 「不要拿掉」「不要改」「這是拍板」——
   它就把一個【會過期的事實】包裝成一條【不該被動的規矩】。
```
🎯 **差別在讀的人會做什麼**:
```
事實  ⇒ 應該被【複查】(它現在還對嗎?)
紀律  ⇒ 應該被【遵守】(照做, 不要動它)
🛑 而讀的人分不出來 —— 他看到「不要拿掉」就跳過去了, 不會停下來問「它現在還對嗎」
⇒ 📌 那三個字保護的東西, 恰好就是最需要被質疑的那個部分。
```

## 實錘(2026-09-08,而過期它的是我)

`apps/admin/src/components/customers/profile-edit-form.tsx:15-17` 原文逐字:
> 「DB 端**連 service_role 都沒有那一欄的 UPDATE 權**(`20260717010000:175` 欄級 GRANT 只有
> name/phone/birthday/updated_at),**要改得另開一片**。欄位旁的說明文字就是講這件事,**不要拿掉**。」

```
① 我貼了 20260908100000 ⇒ service_role 現在【有】那一欄的 UPDATE 權
   (貼後唯讀對帳實測六欄:birthday, email, gender, name, phone, updated_at)
② 那份「只有四欄」的清單在 20260901040000(gender)之後就已經舊了
③ 「另開一片」那一片【就是我做的那一片】, 而它渲染在同一張卡的下面
⇒ 🔴 三句全假, 而我做完那一片【沒有回頭看它】
```
🛑 **而代價不是抽象的**:那句話對應的 `footerHint`(「要改請**另開片處理**」)
**當天誤導了老闆本人** —— 他的截圖切在那一行下面,他把它讀成「功能不在」。
⇒ 📌 **一句在正確的時候寫下、而沒有人負責讓它過期的話, 會在它最不該說話的時候被讀到。**

## 🎯 壞範例 vs 好範例 —— **同一個 repo 裡都有, 而差別不是語氣**

```
❌ 壞  profile-edit-form.tsx(原文)
       「…要改得另開一片。欄位旁的說明文字就是講這件事, 不要拿掉。」
       ⇒ 一條【沒有出口】的紀律:讀的人不知道什麼情況下該回來看它
       ⇒ 而它三句全假之後, 沒有任何東西會叫

✅ 好  apps/admin/src/lib/staff.ts:96(逐字)
       「⚠️ **3 秒是選的、不是量的**:PK 單列查詢正常在數十毫秒內… 
         **若日後量到誤殺, 調它、不要拿掉它。**」
       ⇒ 它同時說了【不要拿掉】與【什麼情況下該回來動它】
```
🎯 **差別不是語氣, 是【有沒有給出一個會讓你回來的條件】。**
📌 一條**沒有回訪條件**的紀律, 就是一個**沒有到期日的事實** —— 而那正是 `profile-edit-form.tsx`
那一句變成假的的原因。⇒ 🔵 **好範例是現成的, 不是我發明的形狀。**

## 🔴 而這一族裡有一種【比過期更難處理】的:**不可證偽的守衛**

```
scripts/w6a-unvoid-race.sh:44 原句逐字「後人改這支時, 那四道自證一個都不要拿掉」
🔬 而本檔具名的自證標記有 10 種(:456 的 KEYS_FROZEN 逐字列出全部十個)
🛑 「那四道」是哪四道, 句子裡沒有寫
```
⇒ 📌 **那不是「過期而沒有人複查」, 是【想複查的人做不到】。**

### 🔴🔴 而這一段才是這一族真正的危險(主視窗 `-9b` 2026-09-08 從上面那個觀察挖出來的)

> **一個不可查的句子, 不會與任何東西衝突 —— 它不參與比對, 所以它永遠不會紅。**

📌 **前面幾節解釋的是「怎麼寫才對」;這一句解釋的是「為什麼寫錯不會被發現」。**
```
一句可查的話    會與現況比對 ⇒ 錯了會撞上某個讀數 / 某個測試 / 某個人的 grep
一句不可查的話  沒有任何東西可以與它比 ⇒ 它在任何世界都印同一個東西
⇒ 🛑 所以它不是「比較難發現」, 是【結構上不可能被發現】
```
🎯 **實例就在同一支檔裡**:`w6a-unvoid-race.sh` 一句說「**四道**」、`:456` 一行列了**十個**,
**同一支檔、並存了一段時間、而沒有人覺得矛盾** —— 因為前者從來沒有被當成可以查的東西。
⇒ 📌 **兩個互相矛盾的字面躺在同一支檔裡而不會打架, 那本身就是「其中一個不可查」的證據。**
⇒ 🎯 而它與 `KEYS_FROZEN` **在同一支檔裡並存了一段時間** —— 一個說「四道」、一個列了十個,
   **而沒有人覺得矛盾**, 因為前者從來沒有被當成【可以查的東西】。
✅ **已補**(`3fe84693a`, 只動註解):四道都具名, **而每一條附我憑什麼這樣判**,
   依據最弱的那一條(③)明寫「這是判讀不是原文」並列出排除掉的候選。
🛑 **為什麼不四條都寫成斷言**:猜錯會產生一個**看起來可以被查、而其實指錯**的守衛
   ⇒ **那比原本更糟, 因為它會讓下一個人停止懷疑。**

## ✅ 修法(寫的時候, 不是複查的時候)

紀律語氣的註解要帶**它成立的條件**或**誰會讓它過期**,不要只寫「不要動」:

```
❌ 「…要改得另開一片。說明文字不要拿掉。」
✅ 「…要改得另開一片。⚠️ 這一句在【那一片做出來的那天】就過期 ——
     做那一片的人請回來改這裡, 並把 footerHint 一起改成指路。」
```
🎯 **判別句**:我寫的這一句,**有沒有一個【可以指名的人】會讓它變假?**
有 ⇒ **把那個人寫進句子裡**。那是這條唯一便宜的修法 —— 事後複查太貴,而且沒有人會做。

## ⚠️ 這一條不涵蓋什麼

- **不是**「不要寫『不要拿掉』」—— 有些東西真的不該被動(例:留痕的舊字面、刪除線)。
  🎯 **要分的是:那句話保護的是【一個事實】還是【一個決定】。** 決定可以說不要動;事實不行。
- 🔴 **未量**:我沒有掃過 repo 裡還有幾句同型的「不要拿掉 / 不要改」掛在事實陳述上。
  **那是一個量得到而我還沒量的東西**,標在這裡而不是假裝它是零。
