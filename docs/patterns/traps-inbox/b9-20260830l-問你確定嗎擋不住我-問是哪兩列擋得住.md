## 實錘

它於是對我端出去的那個數做減法:**「產品 ∩ open:13 → 11」**。


✅ 主視窗回:「**【乙】。我搞混分母,13 不動。**」

## 🔴 而抓到它的不是懷疑

> ### 只有數字 ⇒ 我只能問「**你確定嗎**」——而他會說確定,因為他真的以為確定。
> ### 有成員 ⇒ 我能問「**是哪兩列**」——而那一句他答不出來。

📌 **⇒ 一個問「你確定嗎」的人擋不住他;一個問「是哪兩列」的人擋得住。**

**兩句話都是「質疑」,而只有第二句需要對方拿出【可以被比對的東西】。**
第一句要對方**重新確認一次他的信心**;第二句要對方**指出一個位置**。
⇒ 而**錯的分母指不出位置。**

## ⇒ 這是「成員清單」那條規矩的**第二面**

```
前半（今晚一直在講）：成員讓你知道【是哪幾件】
🔴 後半（今天才出現）：成員讓你【拒絕得了一個錯的數字】——包括來自上游的
```

⚠️ 而它為什麼要單獨寫:**前半聽起來像「資訊比較完整比較好」,是一句軟話。**
**後半是硬的:沒有成員清單,你在結構上沒有能力反駁一個數字** ——
**你只剩下「相信」或「不相信」,而兩者都不是證據。**
