## 正本 `:13449` 已經有的, 與這條【新增】的那一格

正本講的是:**兩個地方對同一件事講相反的話**, 情況 A =「兩句在同一支檔裡 ⇒ 你以為自己讀完了」,
並補了方向(過期的在上、更正的在下 ⇒ 由上往下讀的人先讀到假的)。
它的判別句是:**我剛改的那句話, 這份檔裡有沒有第二個地方也在講它?**

🔴 **而它假設【矛盾的兩半都在我看得到的地方】—— 我這一次不是。**

```
矛盾的兩半住在【我引用的那份外部權威】裡,

```

**⇒ 正本那個判別動作在這裡不會啟動**:我沒有「剛改一句話」, 我是**引用了一句別人的話**。
我在自己的檔裡再 grep 一百次, 也只會撈到我自己那一條 —— **它是對的。**

## 🔴 為什麼沒有任何訊號 —— 這才是本條的機制

把引用完整性能查的東西列出來, 逐條打勾:

| 檢查 | 結果 |
|---|---|
| 我引的那支檔存在嗎 | ✅ 在 |
| 引號裡的字面在那支檔裡嗎 | ✅ 在, 逐字 |
| grep 撈得回來嗎 | ✅ 命中 1 |
| 行號漂了嗎 | ✅ 沒漂 |
| 引用者有沒有重述 / 加油添醋 | ✅ 沒有, 複製的 |

**五格全綠。** 而結論是錯的。

📌 **⇒ 壞掉的不是「我引的東西存不存在」, 是「我引的是不是【最新的那一半】」——**
**而那件事不是一個屬性, 是一個【比較】, 它需要第二個載體才問得出口。**
**一份來源只被打開一次的時候, 那個比較【在物理上不可能發生】。**

🔴 而它比正本那個情況 A 更難發現一格:
- 情況 A(同檔兩句):**兩句都在我打開的那支檔裡** ⇒ 我至少有機會撞到第二句。
- 這一條:**第二句在另一個載體裡, 而我沒有理由去開它** —— 我要的答案第一個載體就給了, 而且給得很乾脆。
- 🔴 **而下一個回來查的人會做什麼?** 他會核我的引用 ⇒ **五格全綠** ⇒ **他比我更有信心。**

## 判別動作(可跑, 而它問的是【載體數】不是【字面】)

```bash
# 引用一份稿 / 一份外部權威之前, 先問它有幾個載體:
ls <那份稿的目錄>
# 然後拿【同一個決定的關鍵字】, 在【每一個載體】上各 grep 一次
grep -rn '<那個決定的關鍵字>' <那份稿的目錄>
```

- **兩個載體給出不同答案** ⇒ 去找**日期與因果**(誰是為了修誰才寫的), **不要挑先撞到的那一個**。
- **只有一個載體給得出答案** ⇒ 那才是可以直接引的。
- 🔴 **grep【那個決定】, 不要 grep【我要的那句話】** —— 這一句與正本情況 A 的忠告同源,
  而在這裡它換了一個座標:正本是「不要只 grep 支持我的那句」, 這裡是「**不要只 grep 我先打開的那個載體**」。
