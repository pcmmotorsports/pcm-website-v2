# 【新增實例】一道閘可以正確運作,而它守的是一個【形式】不是一個【事實】

> 2026-08-28 夜,線B(`-d3`),把 `scripts/naked-cells.py` 收進 repo 時撞到。
> **不推翻既有任何一條。** 母題的父條 = 正本 `:10486`
> 「**把突變留成測試 ≠ 那個測試會抓到那個突變**」——
> 那一條講**我自己留的守門量錯東西**;這一條講**一道閘要求我留守門,而它自己說它驗不出內容**。

## 事發

`scripts-whitelist-gate` 擋下新腳本進 index,理由是它沒有【逐字路徑】的 `lint-staged` 條目。
而**那道閘自己的錯誤訊息裡逐字寫著**:

```
🔴 本閘【驗不出】那行命令有沒有判別力 —— 寫 "true" 一樣過得了。那一格靠人。
```

⇒ **它保證的是【格子被填了】,不是【格子裡裝著會叫的東西】。**

📌 **判別句:一個白名單條目要是恆綠的,它登記的是「有人負責」而不是「有東西在看」。**

## 🔴 而這一格最該學的不是那個病,是那道閘的【誠實】

那句自陳寫在**它擋你的那一刻你一定會讀到的地方** —— 不是檔頭、不是文件。
⇒ 我因此當場補了一發突變,而不是照規矩填一行就走:
```
突變:把 naked-cells.py 的 `it.each` 鏈式括號配對拿掉(= R2 那條 must-fix 的病)
     ⇒ `python3 scripts/naked-cells.py --selftest` rc=1
     ⇒ 而 FAIL 的是 **W9(it.each 那個世界)**
還原 ⇒ rc=0
```
🔴 **「它會紅」不夠,要「它紅在對的世界」。**
只證會紅的話,一個恆紅的守門也通得過這一關 —— 而那與**沒有守門**一樣沒有判別力,
只是失效的方向相反(正本 `:5575`「恆紅 —— 恆綠的對稱另一半」)。

## ⚠️ 而那句誠實同時是它的失效條件

那道閘把「這一格靠人」寫出來了 ⇒ **它把責任轉移完成了,而轉移之後沒有任何機制在看那一格。**
```
讀到那句而照做的人   ⇒ 補一發突變（我這次）
讀到那句而沒照做的人 ⇒ 填一行 "true"，而閘【正確地放行】
兩者在 index 上長一模一樣：一個被填好的白名單條目
```
📌 **一道閘把自己的盲區寫在訊息裡,擋不住任何人 —— 它只是讓踩到的人事後知道自己踩了哪裡。**
⇒ 這與正本「機制優先律」那一族是同一句話的另一面:
**把「靠人」寫下來,不會讓那件事變得比較不靠人。**
