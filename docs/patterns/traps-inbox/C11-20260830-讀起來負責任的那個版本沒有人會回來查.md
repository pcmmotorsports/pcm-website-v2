# 現場①(我犯的)· 一個**發明出來的**範圍關係

上游交辦逐字:「**把兩個數字各自在數什麼寫清楚**」(22 件 vs 13 件)。

```
❌ 我寫的：「22 = 板子所有還開著的列；13 = 其中要動到程式的那些
            ⇒ 13 是 22 的【子集】⇒ 所以 22 − 13 沒有意義」
🛑 而我【沒有把兩份逐列比對過】—— 我只知道另一個窗算出 13
⇒ 那個「子集」是我為了讓句子讀起來乾淨而**發明**的關係
```

## 🔴 而危險不在「我編了」,在**我編出來的東西是哪一種形狀**

> ## 「**兩個都對,只是範圍不同**」——
> ## 這句話**聽起來就是負責任的那個版本**。

```
它同時做到三件事：
  ① 沒有指責任何人算錯      ⇒ 沒有人需要防衛
  ② 承認了不確定性          ⇒ 看起來已經很謹慎了
  ③ 給出一個乾淨的解釋      ⇒ 讀的人覺得問題已經被處理完
⇒ ⇒ 🔴 **而 ③ 正是它關掉查證的地方** —— 一個看起來已經解決的問題，沒有人會再解一次。
```
✅ **改成**:「**我沒有逐列比對過 ⇒ 我不知道 13 是不是 22 的子集 ⇒ 兩個都不要相減**」。

# 📌 兩個實例的共同形狀

> ## **編造與遮蔽,都發生在【讓事情看起來更好】的方向上。**
> ## **而那個方向,恰好是最不會被質疑的方向。**

```
往壞的方向講錯 ⇒ 有人會來反駁（他要洗清自己）⇒ **錯誤有回饋路徑**
往好的方向講錯 ⇒ 沒有人有動機來查     ⇒ 🔴 **錯誤沒有回饋路徑**
⇒ 兩種錯的【存活率】不一樣 ⇒ 久了，檔案裡剩下的會系統性地偏樂觀
```
🔴 **⇒ 而這不是誠信問題** —— 我兩次都不覺得自己在編,**我覺得我在把事情講清楚。**

# ✅ 判別動作(落筆當下,不是事後)

> ## **我這句話,會讓讀的人【停止查證】嗎?**
> ## **如果會 —— 那我對它的把握,夠不夠支撐那個效果?**

```
高風險句形（照抄自 CLAUDE.md「一個字回得完」那條的延伸）：
  ·「兩個都對，只是範圍不同」
  ·「這個已經處理掉了 / 你可以劃掉了」
  ·「不是你的問題」
  ·「應該是 X 造成的」        ← 「應該」戴著謙虛的面具做斷言
✅ 解法不是不講，是【把把握度綁在同一句裡】：
   「我沒有比對過 ⇒ 我不知道」比「兩個都對」短，而且它是真的
```

## ⚠️ 而它有一個成本,寫明免得被當成「什麼都要加免責」
```
· 每句都加不確定性 ⇒ 讀的人會【全部忽略】⇒ 那等於一句都沒加
🔴 ⇒ 所以判準不是「有沒有把握」，是**【這句話會不會關掉別人的查證動作】**
  ⇒ 不會關掉的（描述、過程、我做了什麼）⇒ 照常平直寫，不要降級
```
