# 「沒有紅」有四種來源,而它們印同一個字

> 線【出貨】`-1e` · 2026-08-31 · 四種**全部發生在同一天、同一條線上**,不是設想

## 母題

一天之內我拿到四種「測試沒有紅」,**只有第一種是好消息**,而它們在 `rc` 與
`Tests` 那一行上可以印出一樣的東西。

## 四種(每一種都附當天的實測數字)

```
① 真的對          被測物正確、斷言跑了、過了。
                  —— 這是唯一一種好消息。

② 突變沒落地      我的 replace 縮排/字面猜錯 ⇒ 檔案根本沒改 ⇒ 測試 rc=0 全綠。
   **今天發生三次。** 三次都是 `assert s.count(old)==1` 擋下的,不是我看出來的。
   📌 一發【沒落地】的突變與一發【殺不掉】的突變, 在輸出上印同一個東西。
   分法:先比 sha(突變前後必須不同), 或讓 replace 自己 assert 命中數。

③ 檔死掉          突變改壞語法 ⇒ `Test Files 1 failed` 而 `Tests 105 passed (105)`
   ⇒ **零紅格**, 而總數從 **186 掉到 105** ⇒ **81 格靜靜消失**。
   📌 「檔案紅了」與「有格子紅了」是兩個宣稱, 而大家引用的是 `Tests` 那一行。
   分法:比【測項總數】, 不是只看有沒有紅。

④ 餵錯清單少跑    我餵 **6** 條測試路徑, 它跑 **5** 支。
   那一條檔名【不在我這棵樹上】(它在 origin/dev 上, 我從一份舊清單的記憶裡撈的)。
   **vitest 不報錯、rc=0、就少跑一支。** 總計行只印「它跑了幾支」, 不印「你餵了幾條」。
   分法:比【我餵幾條】vs【它跑幾支】—— 那是鐵則 11 那一格。
```

## 📌 一句話

**四種都可以印綠,而分得出它們的四個動作互不相同 ——**
**②比 sha ③比測項總數 ④比餵進去的條數 ①什麼都不用做。**
🔴 **⇒ 所以「跑了、綠了」這句話沒有資訊,除非它同時說了你比了哪一個。**

## ⚠️ 射程

```
· 四種是我今天【撞到】的, 不是窮舉。第五種很可能存在而我沒撞到。
· ②的三次都是 assert 擋下的 ⇒ 我沒有一次是靠讀輸出發現的
  ⇒ **這一格的防線是機制, 不是注意力。**
```
