## 15-5 · 「照既有慣例做」的隱含前提是**只有一個慣例** —— 而兩個都合法的分母會給相反的答案

### 現場一(本線,2026-08-31)

要決定 `customers` 新欄位 `gender` 用 `enum` 還是 `text + CHECK`。**照慣例做,而慣例有兩個:**

```
全 repo        `AS ENUM` ⇒ **3 支**  ·  `CHECK (... IN (...))` ⇒ **38 支**   ⇒ 慣例 = CHECK
🔴 同一張表     `customers` 自己的 `tier`
               `20260523034911_init_customers_and_subtables.sql:8`
               逐字 `CREATE TYPE member_tier AS ENUM ('general','store','premiumStore');`
                                                                            ⇒ 慣例 = enum
🔵 負對照 現造字面 ⇒ 0（尺會動）
```
🛑 **兩個分母都合法,而它們給【相反】的答案。**

### 現場二(同日,主視窗 `-2d` 自陳,它要求照實寫)

```
它裁板子某一列時, 量了【那一列】的淨 pipe = 6
⇒ 寫給下一個窗:「必須是 6」+「正對照:同一把尺量隔壁任何一列 ⇒ 也是 6」
🔴 而它【沒有量隔壁任何一列】—— 那句正對照是它編的
⇒ 兩小時後又轉給我一次:「改完淨 pipe 仍要 6」
✅ 而我實量:我要改的那一列【改前就是 4】;全表 287 列裡 net != 6 的有 **38 列**
⇒ 📌 若我照那個 6 去「修正」, 我會把一列本來就對的東西改壞。
```

### 🔴 共同形狀

> **把一個【局部觀察】當成【全域規則】—— 而它讀起來像在遵守既有做法。**

📌 而這一族之所以難擋,是因為**「照慣例」本身是對的紀律**:
它平常有用,是因為**多數情況下只有一個鄰居**。
🛑 **而當有兩個時,它不會告訴你它失效了** —— 它會讓你**選一個,然後覺得自己在遵守慣例**。
⇒ 那與「我隨便挑一個」在 diff 上、在 commit body 上、在 review 上**長得一樣**,
而前者還多一句聽起來很負責的理由:「跟既有做法一致」。

### ✅ 判別句與可操作

```
判別句:我說「照慣例」的時候, 問一句 —— **這個慣例的分母是什麼?**
        答不出來, 或答得出【兩個】⇒ 那就不是慣例, 是我挑了一個。
可操作:兩個分母都量, 把兩個數都寫出來(本條現場一:38 vs 1)。
        兩邊不一致 ⇒ **改用【成本不對稱】判, 不要用票數判**, 並在碼裡寫下為什麼不跟近的那個一致
        —— 否則它看起來像不小心。
🔵 而現場二多一格:**轉述一個「不變量」時,要說它的分母是【一列】還是【整張表】。**
   一個從一列量到的數, 經過兩次轉述就變成了整張表的不變量。
```

### ⚠️ 射程
```
🛑 我只有兩個實例, 而它們都在同一天、同一個隊伍 ⇒ **這是不是常見形狀, 未數**
🛑 現場一我最後選了 CHECK, 而【那個選擇對不對】本條不負責 ——
   本條只講「照慣例」在那裡答不出來, 不講哪一個答案是對的
✅ 而兩個現場的數字(38/3、287/38/6/4)都是當場實跑印出來的
```
