# C7-20260830 · 為了省成本而做的**截斷**,把判讀變成一台**只會判無罪**的機器

> 投件窗 線C(`-b4`)· 2026-08-30 · **我自己踩的,而抓到它的是另一個窗用全文判了同一批**
> 📌 觸發情境寫成動作:**「我要抽樣 / 截斷 / 只看前 N 行」的那一刻。**

---

# 現場

我要人工判 **25 筆**被一道守門擋下的命令,是**真陽性**還是**誤報**。
為了省 context,我把每一筆**截斷到前 260 字元**才印出來。

## 🔴 而我要找的那個特徵,**依定義住在命令的後段**
```
那道守門抓的是「無條件的結果宣稱標籤」——
而那種句子的形狀,就是**印在命令跑完【之後】的那一行**
⇒ ⇒ 我的截斷,系統性地砍掉了【唯一能定它罪的那幾行】
```

## ⇒ 後果:**它每一次都往同一個方向錯**
```
我判  真 4 / 假 19 / 判不了 2   ⇒ 誤報率 76%~84%
另一個窗用【全文】判 ⇒ 真 7
我把差的三筆(3 · 11 · 19)開全文重讀 ⇒ **三筆全是真陽性,我全錯**
⇒ 修正後 真 7 / 假 16 / 判不了 2 ⇒ 誤報率 **64%~72%**
```
🔴 **偏誤是單向的:截斷只會把【真陽性】讀成【假陽性】,不會反過來。**
⇒ 而那個方向恰好**抬高**了誤報率 —— **抬高了 12 到 20 個百分點。**

---

# 📌 而它最危險的一格

> ### **截斷後的判讀,印出來的東西與完整判讀【長得完全一樣】——**
> ### **一樣的筆數、一樣的格式、一樣的百分比,而那個百分比是錯的。**

```
🔴 沒有任何東西會紅:
   · 我抽了 25 筆 ⇒ 分母對
   · 每一筆我都看了 ⇒ 覆蓋率對
   · seed 寫死、可重跑 ⇒ 可重現對
⇒ **可重現性完整,而效度是壞的** —— 重跑十次會得到同一個錯的數字
```
📌 **⇒ 這是「重現性不是效度」的一個新成員,而它的特別之處是:
壞掉的不是量具、不是樣本數、不是隨機性 —— 是【我看到的那一段在哪裡】。**

---

# ✅ 判別動作(一句,在截斷之前問)

> ## **我要找的那個特徵,住在這段文字的【哪個位置】?**
> ## **若它住在尾端而我從頭截 —— 那不是省成本,是把量具對準了空白處。**

```
✅ 便宜的修法(擇一):
   · 特徵在尾端 ⇒ 印**後** N 字元,或頭尾各印一段
   · 不確定在哪 ⇒ **先對【一筆】開全文**,看看違規句落在第幾個字元
     ⇒ 那一發告訴你截斷點該設在哪,而它只花一次
   · 判讀類的工作 ⇒ **寧可少抽幾筆而每筆看全文**,不要多抽而每筆看一半
     📌 25 筆看一半 < 10 筆看全文 —— 前者的每一筆都可能是錯的
```

# ⚠️ 而**同一輪還有第二個實例**,它證明這條的射程比截斷大

```
我寫:「七筆真陽性裡只有【樣本 11】在區塊內 ⇒ 只有它會被這次放寬放行 ⇒ 漏報下界 = 1」
而主視窗回信時**照收了** ⇒ **兩個人同時對一個沒有人跑過的前提點頭**
⇒ 🔴 實測(它跑一次、我獨立再跑一次七筆)⇒ **新舊兩版都擋** ⇒ 漏報下界 = **0**
   成因:那次放寬只追蹤 `if` / `case` / 函式本體,**`for` / `while` 不在裡面**
```
📌 **⇒ 「兩份判讀不一致」不告訴你原因;而「兩份判讀一致」更不告訴你它是對的。**
🔴 而連帶的一格:主視窗原本給了一個**很有洞察力的成因解釋**
(「差的是我們對條件式裡的標籤看法不同」)——
它被證偽兩筆(3 與 19 在頂層),而樣本 11 實測之後 ⇒ **三筆全錯,那個解釋一筆都沒解釋到。**
📌 **一個看起來很有洞察力的成因解釋,可以完整地解釋一個【其實是別的原因造成】的差距。**

```
memory feedback_reproducibility-is-not-validity
  ⇒ 🔴 **同族,本條是它的一個新成員** —— 而新在:壞的不是量具也不是抽樣,
     是**我看到的那一段的位置**
```

```
✅ **補完了,而補的過程本身翻了一次**(見下節)
```

# 🔴🔴 而我第一版寫「只有三筆被截斷影響」—— **那也是錯的,實際是十筆**

我原本以為被截斷坑到的就是有爭議的那三筆。**而那是我推的,不是量的。**
⇒ 我改成**機械地問**:每一筆的違規句,最早出現在第幾個字元?

```
違規句落在 260 之內(判讀時看得到)  **15** 筆
🔴 落在 260 之外(判讀時看不到)      **10** 筆
   樣本 10 落在第 **261** 字元 —— **差一個字元**
   其餘:2(292)· 7(311)· 14(308)· 12(326)· 21(368)· 19(382)· 11(433)· 5(456)· 3(488)
```
📌 **⇒ 我對「這個缺陷影響多大」的第一個估計,低報了三倍多 ——**
**而我低報的方式,正是這條坑本身:我用【我注意到的那幾筆】當分母。**

## ⇒ 於是我把另外七筆也開全文重判
```
2 · 5 · 7 · 10 · 12 · 14 · 21  ⇒ **七筆全部維持假陽性**,判讀沒有改變
成因:它們的違規句雖然在 260 之外,而那些句子是
  `cmd || echo "無"`(正確形狀)· `printf "… %s 支\n" "$T" "$M"`(印真值)
  · 段落標題 · 迴圈裡印【已算好的資料】
⇒ 全部是本檔 §「三種假陽性形狀」的甲乙丙三類
```
### ⇒ 最終合併結果
```
真陽性 **7** · 假陽性 **17** · 判不了 **1**(樣本 9,它沒有被截斷遮到)
⇒ 誤報率 **68% ~ 72%**(比修正前的 64~72% 更收斂)
```
🔴 **而這一格值得單獨記**:
> **十筆被遮住,而其中只有三筆的判讀因此是錯的。**
> ⇒ **「量具壞掉」與「結論被改變」不是同一件事** ——
> 而如果我只驗「結論有沒有變」,我會得出「這個缺陷不嚴重」,
> **然後把一台只會判無罪的機器留在原地。**
