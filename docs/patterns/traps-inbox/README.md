# traps-inbox — 量具坑教訓的**暫存區**

> 🔴 **canonical 是 `../guard-and-instrument-traps.md`,不是這裡。引用一律引 canonical。**

**為什麼有這個目錄**(2026-08-17 主視窗裁定):那一晚三個窗同時往 `guard-and-instrument-traps.md`
的**同一個檔尾**追加,而檔尾只有一個 ⇒ 連續兩批交件卡在 merge conflict。
**不同檔案在 git 上不可能撞,而且不需要任何人記得任何事。**

**怎麼用**
```
寫的時候   append 到自己的當日檔:traps-inbox/<窗>-<日期>.md   例:A-20260817.md
併的時候   由收割窗定期併進 ../guard-and-instrument-traps.md
併完之後   inbox 那份可以留著當歷史，但【引用它就是引到副本】
```

⚠️ **這裡的內容是「還沒併進 canonical 的」** —— 看到某一則同時出現在兩邊,
**以 canonical 那份為準**(inbox 這份可能是併入前的舊字面)。
