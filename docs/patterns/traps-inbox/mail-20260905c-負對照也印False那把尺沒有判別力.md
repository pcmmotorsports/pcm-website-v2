# 那條的【對稱面】:負對照也印 False ⇒ 尺沒有判別力

> 投稿人:線【信】`-mail` 2026-09-05。
> 📎 **併入建議**:`guard-and-instrument-traps.md:30846`
> 「一個結論有幾個【不同的成因】會產生它, 就要幾發正對照 —— 而且要比它們印的東西」
> ⇒ 🔵 **本篇是它的對稱面:那條講【正】對照, 這一篇是【負】對照, 而結構一模一樣。**

## 事件

零留痕檢查:審前算一個 hash, 審後算一個, 比對。而它印 **False**。
🔬 而那兩行字串**在畫面上肉眼相同**。

「不同」在這個脈絡下是一個**很嚴重的宣稱** ——
它的意思是「**有人在審查期間改了受審檔**」⇒ 整輪審查作廢、要去查是誰。

🔵 **而我沒有直接下那個結論。** 我先跑了負對照:
把其中一個值**故意改一個字**再比 ⇒ **它也印 False。**

## 🎯 那一刻它自己現形

```
該相同的世界   ⇒ False
該不同的世界   ⇒ False
⇒ 📌 **它對兩個世界印同一個答案 ⇒ 它沒有在回答那個問題。**
```
🔬 去看實際的值:
```
BASELINE 切出來  長度 64  ← 純 hash
CURRENT  切出來  長度 136 ← 🔴 我的切法把後面的說明文字也切進來了
```
⇒ 成因是我的字串切法(`split('CURRENT=')[1].strip()`), 而 `--unlock` 的輸出在 hash 後面**還有一行說明**。

## 🔴 而它與被併入那條是同一個結構, 只是換了一側

| | 原條(正對照) | 本篇(負對照) |
|---|---|---|
| 一發的問題 | 一發正對照只證「尺會動」, 不證「尺分得出來」 | 一發比對只證「它印了某個答案」, 不證「那是量出來的」 |
| 現形的方式 | 餵**第二個成因** ⇒ 也印同一個 rc | 餵**該不同的那一側** ⇒ 也印 False |
| 判別句 | 這個結論有幾個成因?N 個 ⇒ N 發正對照 | **這個比對式在【該相反】的世界會印什麼?** |

## 🛑 而本篇要加的那一句, 在後果那一側

原條的失效後果是「**我以為我驗過了**」——**安靜的**。
🔴 **而本篇的失效後果是【一個假的事故】** ——
```
· 我會回報「受審檔被動過」
· 那會讓一整輪審查作廢
· 而別人會去查一件【沒有發生的事】
```
⇒ 📌 **⇒ 壞掉的量測不只會讓你放心, 它也會讓你恐慌。**
　 🎯 **而假警報動員的是別人的時間, 所以它的成本不落在犯錯的人身上** ——
　 　 那讓它比假綠更不容易被回頭檢討。

## ✅ 可機械執行的形狀

```
任何一個比對式印出【意料之外】的答案時, 先問一句:
   「這個比對式在【該相反】的那個世界, 會印什麼?」
⇒ 印一樣 ⇒ 🔴 尺壞了, 那個「意料之外」不是發現
⇒ 印不一樣 ⇒ ✅ 這時候才輪到「所以真的出事了」
```
🔵 **代價很低**:那一發負對照是**改一個字元再比一次**。
🔴 **而不做它的代價是【動員一組人】** —— 那個不對稱本身就是理由。

## ⚠️ 這一篇證不到什麼
```
· 它沒有回答「為什麼我的切法會錯」—— 那是另一條(輸出格式改了而切法沒跟著改)
· 它假設「跑得起負對照」—— 有些比對的另一側造不出來(例如需要真的並發)
  ⇒ 那時候正確的動作是【明說造不出】, 不是把單邊結果當結論
```
