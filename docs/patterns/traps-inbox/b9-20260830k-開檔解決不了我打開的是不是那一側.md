> `-b9` 2026-08-30 自陳。`-48` 定為「開檔比 grep 可信」那條鏈的**最後一格**。

## 實錘

Sean 答混合收款「照現行做法」。我要判「現行做法還在不在」,於是**開檔**:

```
我開的:  apps/admin/src/components/orders/manual-refund-entry-gate.ts
我讀到:  :85 / :92  MANUAL_REFUND_ENTRY_BLOCKED_BY_787 = true
我寫的:  「匯款那一軌【兩道閘都關著】（#866）」   ← 講的是【收款】
```

🛑 **而那支檔的檔名逐字寫著 `manual-refund-`。它是【退款】那一側。**

`-e9` 複量:同型旗標在**收款**那條路上的原始碼命中 **0**
(掃 `apps` + `packages`,**排除 `.next/` 建置產物** —— 我第一發沒排,撈到一堆 chunk)。
負對照 `ZZQBLOCKED_20260830` ⇒ 0。
而收款那條路 `-e9` 量到**五格全開**(migration / 開權片 / 後台入口被渲染 / 表單支援 `bank_transfer` / 呼叫端接上)。

⇒ **他描述的那個「現行做法」不但存在, 而且是通的。我的結論方向完全相反。**

## 🔴 為什麼這一格特別難被抓到

> ### **一份「我開檔讀了」的證據, 在【讀錯了哪一側】的時候, 與讀對了長得一模一樣 ——**
> ### **它甚至【更可信】, 因為它附了行號。**

今晚整條鏈是這樣長的:
```
grep 不夠 ⇒ 因為它只答「這個字面在不在」
✅ 所以要開檔 ⇒ 開檔答得出「它在什麼上下文裡」
🔴 而開檔答不出的那一格:【我打開的是不是我要判的那個對象】
```
📌 **⇒ 開檔升級的是【證據的品質】, 不是【對象的正確性】。**
而報告上兩者都只印一句「我開檔看了 `<檔>:<行>`」。

## ✅ 可機械執行的自檢(它就在檔名裡)

```
寫下「我開檔量到 X」之前, 把【檔名/路徑本身】與【我的結論句】並排讀一次:
   檔名說的是哪個對象？結論句說的是哪個對象？兩個一樣嗎？
```
🔴 本例裡那兩個字面**就寫在同一個句子附近**:`manual-refund-entry-gate.ts` 與「匯款(收款)」。
⇒ **不需要任何工具, 只需要把它們放在一起看一次。**

## ⚠️ 而順帶量到的第二個分母錯

我第一發 `grep -rn '<旗標>' .` **沒有排除 `.next/`** ⇒ 撈回一整頁建置產物。
📌 **那不是雜訊而已** —— `.next/` 裡的命中會讓「這個字面在不在原始碼裡」**恆真**。
⇒ **掃原始碼的分母永遠是 `apps` + `packages`, 不是 `.`。**
