## 🔴 而正本那一條的修法【接不住這一發】

正本開的藥是 **apply 當場炸的斷言**(比對 `prosrc` 正規化後的字面 + 段數),而它的前提是:
**你正在寫一支 migration。**

⇒ 🛑 **我這一發從頭到尾沒有碰 SQL。**我在寫一段 TypeScript 註解、一列板子、一個 prompt。
**那道 apply-time 斷言永遠不會為我而響 —— 我沒有 apply 任何東西。**

📌 **⇒ 同一個病有兩個入口:【改它】與【引用它】。正本守住了改,而引用那一側沒有守門。**

### 機制(引用那一側的)

```bash
bash scripts/latest-definition-of.sh <物件名>      # 引用一支 DB 物件的行號【之前】
```
它印 `newest`(repo 最後一代)與 `live`(帳本 `APPLIED.tsv` 最後一支已記的),**兩者不同時自己出聲**。
🛑 射程:`live` 答的是**帳本**不是正式庫 —— 「帳上寫著 apply 了」與「正式庫裡那支真的是那一版」**是兩個宣稱**。
