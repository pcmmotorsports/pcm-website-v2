# 為什麼「射程節」是最糟的落點(而它看起來是最好的)

```
🔴 那一節讀起來像作者在【自我克制】——
   而自我克制的句子**天生帶著誠實的外觀** ⇒ 沒有人會回頭驗它
🔴 而它一旦錯,錯的方向是**把東西說得比實際【寬】**
   ⇒ 下一個人會以為那一塊已經有人顧了 ⇒ **它關掉的是別人的查證動作**
```
📌 **⇒ 一份產物裡最不會被驗的那一節,正好是專門用來裝【限制】的那一節。**

# ✅ 修法兩條,都機械

## 一、承重的話**貼在它修飾的那一行旁邊**
```
✅ 檔頭那份【留著】—— 它講全域
✅ 而承重那句【複製一份】貼到它修飾的那個值/斷言/欄位的正上方或正下方
⇒ 重複不是浪費:兩個讀者路徑不同
   (掃檔頭的人 / 只看輸出那一行的人 —— 而後者才是多數)
```
**實例**:`latest-definition-of.sh` 把
「`live` 答的是【帳本】不是正式庫 —— 兩個宣稱」
印在 `live = …` **那一行的正下方**,不放射程節。

## 二、🔴 **射程節每宣稱一件事,就要有一格自檢在演它**
```
它把「一句話」變成「一個 checklist 的欄位」⇒ 新增射程句時,同一輪要新增它的格
```
**實例**(同一支工具,檔頭逐條對上):
```
射程句「動態 SQL 算得到」          ⇒ 自檢 ⑩
射程句「… ON tbl 不算 tbl 的一代」 ⇒ 自檢 ⑪
射程句「帳本欄印得出兩種值」        ⇒ 自檢 ⑬
```
⚠️ **而這一條只解得了①(內容錯),解不了②(位置錯)** ——
一句住錯地方的**正確**話,自檢會**通過**。⇒ ②只有第一條修法擋得住。

# 🔴 續章 · **這條規矩會撞上另一條規矩,而兩條都對**

> 2026-08-30 03:3x · `-48` 指定寫進本檔。**成因是當場撞到的,不是想到的。**

## 現場

`-48` 交辦:把「`INNER` 在這裡是對的,不要照 view 的 COMMENT 改成 LEFT JOIN」
**貼在那支 view 的 `COMMENT` 旁邊** —— 照的正是本檔立的那條規矩(承重的話貼在它修飾的那一行旁邊)。

**而那個位置改不動。**
```
那支 COMMENT 在 supabase/migrations/20260814190000_…_refund_manual_corrections.sql
⇒ 它【已 apply】,而 supabase/APPLIED.tsv 記著它的 **sha256**
⇒ 🔴 改它 ⇒ 那本帳對不上 ⇒ 「這支檔就是當初套上去的那一份」這個宣稱當場失效
```

## ⇒ 兩條規矩,**都對,而它們在這一格衝突**
```
規矩A(本檔)     承重的話要貼在它修飾的那一行旁邊
規矩B(帳本紀律) 已 apply 的 migration 不可改 —— 它的 sha256 是一個對外宣稱
⇒ 而 A 指定的位置,恰好落在 B 保護的檔案裡
```

## 🔴 而它為什麼比「單一規矩被違反」難發現

```
單一規矩被違反 ⇒ 違反的人【知道自己在偏離】,或者有一道閘會叫
🔴 兩條規矩衝突 ⇒ **照著 A 做的人,感覺自己完全合規** ——
   他不會停下來,因為他正在遵守一條真的規矩
⇒ 而**沒有任何閘會叫**:A 沒有閘;B 的閘(sha 對帳)要等下一次有人查帳才發現
⇒ ⇒ **偏離發生在「遵守」的外觀底下。**
```
📌 **⇒ 這與本檔主題同源**:那裡是**一句正確的話住錯地方**,
這裡是**一條正確的規矩用在錯的位置**。**兩者都不會紅。**

## ✅ 這一格當時的處置(留下來當形狀,不是當標準答案)
```
① 不改那支已 apply 的檔 —— B 不讓步(它保護的是一個【對外宣稱】,比可讀性硬)
② 落點退到【最近的、會被改動者讀到、而且改得動】的地方
   實際落點:packages/domain/src/order/refund-remaining-single-source.test.ts
   理由:改那段算式的人一定會弄紅這支測試 ⇒ 他一定會讀到這裡
③ 🔴 **把「我沒有照字面做」與理由寫進那段註解本身**
   ⇒ 而這一步不能省:交辦的人看到的是【他要的位置沒有東西】,
     若不寫,他會以為沒做 —— 或者更糟,自己去改那支已 apply 的檔
```

## ⚠️ 而**通則只到這裡**,不要外推
```
❌ 這【不是】說「A 遇到 B 就讓步」—— 這一次讓步是因為 B 保護的是對外宣稱
✅ 真正可帶走的只有一句:
   **兩條規矩衝突時,選一條、然後【把沒選的那條為什麼沒選寫在現場】。**
   ⇒ 因為下一個人會從【沒選的那一條】那個方向走過來,而現場是他唯一會經過的地方
```
