## 🔴 為什麼它不是 `:11766` 那一則(**這是本則存在的唯一理由,請先讀這格**)

正本 `:11766` 已經有 `head -1` 這個成員,而**它整條的失準方向是【窄】** —— 該條逐字:
> 「② `sed +80p` ⇒ 用行數當範圍…**失準方向永遠是「少看到」**」
> 判別句:「起點、範圍、字集…靠『第一個命中 / 固定行數 / 命名慣例』的,**都是會安靜變窄的那一種**。」

**而本則是反方向的:**
```

```
📌 **判別句:**
> **一把會把【缺席】報成【存在】的尺,比一把把存在報成缺席的危險一個量級 ——**
> **因為它產出的是【不需要任何人再看一眼】的結論。**

⚠️ **而我發現它不是因為它看起來可疑** —— 它印出一個乾淨的 `307 / 78`。
是因為我照慣例把命中**逐條印出來人工掃過**,而其中一條的路徑一眼就不對。
🔴 **⇒ 那一步(把命中印出來)在這一發裡是我實際拿到的訊號來源,而它常常被當成「輸出太吵」砍掉。**
⚠️ **「是不是【唯一】的訊號來源」= 未數** —— 我沒有去構造別的訊號路徑來排除,只知道那一條是實際生效的那條。

## ✅ 修法
**`fallback` 的結果不可以與主查詢的結果放進同一欄。**
主查詢答「在/不在」,fallback 答的是「有一支同名的東西」——**那是兩個不同的宣稱,不能共用一個計數器。**
