# 板子合併守則 —— 六窗同時寫一張表, 而 git 看不出兩行是同一列

> 立於 2026-09-07 · `tidy` · 每一條都帶當夜的實錘座標。
> **它答什麼**:`docs/launch-todo.md` 這種「多人同時改、一列一行、行內容很長」的表,
> 合併時會壞在哪、以及每一種壞法的**判別式**。
>
> 🛑 **它在什麼情況下會變成假的**:
> · 板子改成一列多行(YAML / 每欄一行)⇒ 下面關於「git 逐行比對看不出同一列」的推理整段不成立。
> · 每一條的數字都綁 **2026-09-07 那一夜**。**引用前重量, 不要抄。**
> · 它答不出「這一對該不該合」—— 那是判斷。它只答「合的時候會掉什麼」。

---

## 母題

> ### 🔴 **一列的身分, 在 git 眼裡不存在。**
> git 比的是**行**。而板上一列 = 一行, 兩個窗各改一次 ⇒ **兩行不同 ⇒ 它保留兩行**,
> 而那兩行是**同一件事的兩個版本**。⇒ **重複列不是誰寫錯, 是合併的預設行為。**

---

## ① merge 會自己生出重複列 —— 而它每次回來都讓「還在擋」+1

**實錘**:`⟦b9-ACLDRIFT5⟧` 那一對, 2026-09-07 一夜**回來三次**(04:0x / 05:0x / 06:2x 各合一次)。
**06:2x 那一發把擋數從 90 推到 92, 其中一件就是它。**

🔴 **⇒ 若沒有逐列差集, 那個 +1 會被讀成「今晚又多發現一件缺陷」。**
一個純粹由合併產生的幽靈, 在報表上與一件真的新缺陷**印同一個東西**。

**判別式**:擋數自己動了而沒有人改態 ⇒ **先跑差集找出是哪一列**, 不要編一個講得通的原因。
(同夜實錘:我為 97⇒96 編過一個「新開了一列不擋」的原因, 而那在算術上不可能;真兇是 ship 改了別的列。)

---

## ② 去重會刪掉「你做完之後才長出來的東西」

**實錘**(db 2026-09-07 06:3x 轉):我 06:2x 去重 `Q15GAP` 那一對時,
db 在**被我刪掉的那一列**上加了三段 —— **當時我看不到, 因為我沒有 fetch。**

> 🔴 **一次正確的去重, 對【它做完之後才長出來的內容】是一次刪除。**
> 而 diff 上它與「清理重複」長得一模一樣。

**修法兩件, 缺一不可**:
· **去重前 `git fetch origin dev` 對齊**(⇒ 看得到別人剛加的)
· **合併時算差集, 不是挑一個留下**(⇒ 沒對齊到的那些仍然被搬進倖存者)
✅ db 那次做對了:差集 15 段搬進倖存者, 原列刪。

---

## ③ 「最長的那一列」不是超集

**實錘**:色票那族六列(`:1006`–`:1011`, 長度 1692 / 1700 / 1951 / 1959 / 2087 / 2482)。
逐句差集量到:**最長那列缺了另外 4 列共 7 段**, 其中包括
**關閉條件**(「若還有殘餘 ⇒ 把態改回 `open` 並寫誰」)、ship 的重複列標記、tidy 稍早的合併紀錄。

> 🔴 **「取最長的當底、其餘刪掉」會安靜地丟掉東西, 而 diff 上看起來像清理。**

**判別式**:合併前**逐句算差集**(切 `<br>` 與 `。`, 正規化空白後比)。
差集非空 ⇒ 那幾段要逐字併進去, 不是「應該包含了吧」。

---

## ④ 相似度門檻配得出「一對」, 配不出「一族」

**實錘**:同樣那六列, `≥0.90` **不遞移** ——
`:1006↔:1007 = 0.9861`, 而 `:1006↔:1010 = 0.8902`、`:1006↔:1011 = 0.8122`。

⇒ 它們**跨越門檻分佈** ⇒ 任何「兩兩比、超過就合」的做法都撈不起整族。
(這也是為什麼那六列**不能當 `board-merge-rows.py` 新後備路徑的正對照** —— 它證不到那條路。)

**而三把尺為何同時失明**:
· **規則⑤(錨重複)**:六列**全部無錨** ⇒ 對它們零判別力
· **弱身分(事欄前 40 字)**:其中兩列被貼了 `⛔ [重複列]` 標籤 ⇒ 前 40 字被改動 ⇒ **拆成兩組**
· **`row_key`**:一列有錨一列無錨時, 一個回 `anchor` 一個回 `literal` ⇒ **永遠配不上**

> 📌 **貼上「這是重複」的標籤, 讓量具看不出它們是重複的。**(同夜第三次;
> 另一次是 ACLDRIFT5 那一對, 標記前相似度 0.999 / 標記後 0.979 —— **差的 2% 就是標籤本身**。)

## ⑤ 合併註記寫【裸行號】⇒ 它在合併完成的那一刻就開始指向別人

**實錘**:`⟦b9-ACLDRIFT5⟧` 裡的引文寫 `併自原 :565`。合併把列往上移一格之後,
今天的 `:565` 是 **`⟦b9-Q15GAP⟧`** —— **一件真的、還在擋的 RLS 缺口**。
account 讀到那段引文, **判它是重複列、要求別派**。

> 🔴 **一段誠實的註記, 在寫下的那一刻是對的, 而它在下一次合併就開始說謊, 而沒有東西會出聲。**
> 而**它讀起來像那一列的欄位**, 所以人不會去懷疑它。

**分母**:🔴 **這個數會長, 而它在【我寫這一段到我 commit 之間】就長了一次** ——
06:5x 量到 **12 處 / 5 個相異行號**(4 個當時指到別的有錨列);合了 `origin/dev` 之後
2026-09-07 07:00 CST 重量 ⇒ **28 處 / 9 個相異行號**。
> 📌 **一份講「行號會漂」的守則, 它自己的分母在寫完到 commit 之間過期了一次。**
> ⇒ **不要抄上面任何一個數**, 當場跑:
> ```bash
> python3 -c "import io,re;t=io.open('docs/launch-todo.md',encoding='utf-8').read();print(len(re.findall(r'併自原 :\d+',t)),'處 /',len(set(re.findall(r'併自原 :(\d+)',t))),'個相異行號')"
> ```
> ⚠️ 尺別寫成 `併自原 :\d+(?!⚠️)` —— 它會**回溯少吃一位**, 把 `:565⚠️` 讀成 `:56` 後面接 `5`
> ⇒ 印出「全部都是裸的」這種假紅。要 `(?!\d|⚠️)`。
**修法**:寫 `⟦錨⟧`, 不寫行號。已裝 `board-token-normalize.py` **規則⑧**(warn-only)。
🛑 **而它有兩個邊界, 兩個都是實測**:
· 它會咬到**解釋它自己的文本**(⟦tidy-STALELINEREF⟧ 那一列)—— **那個叫是對的形狀, 不要為了讓它閉嘴而刪掉實錘**
· `` 以 `:684` 那一份為準 `` 這種寫法**它不咬** ⇒ **規則⑧ 的 0 不等於板上沒有裸行號**

## ⑥ 「改成錨」有時做不到

**實錘**:`#64` 那一對 —— **兩份用同一個識別字**, 沒有唯一錨可改, 只能補警語。

> 📌 **一道叫你做 X 的閘, 要先確定 X 在每個情境都做得到, 否則它會逼人做假動作。**

⇒ 那一族在 `⟦tidy-ANCHORUNIQBLIND⟧`。

## 動手前的四句

1. **`git fetch origin dev`** —— 沒對齊就去重 = 刪掉別人剛寫的(②)
2. **逐句算差集** —— 不要挑最長的(③)
3. **合併註記寫錨不寫行號**(⑤)
4. **合完跑 `python3 scripts/board-state-consistency.py`** —— 規則⑤ 是事後閘;
   ⚠️ 而它只看**帶錨的列**, 無錨列重複時**它不會叫**(④)

工具:`scripts/board-merge-rows.py`(衝突區塊, 帶 ≥0.90 後備)· `scripts/board-token-normalize.py --check`
· `scripts/board-row-by-anchor.sh`(定位;**錨欄帶反引號的是引用列, 不是它自己**)
