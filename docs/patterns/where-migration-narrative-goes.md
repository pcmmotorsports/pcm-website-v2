# 寫 migration 的時候,敘事該寫在哪裡

> 窗B · 2026-09-19 · 起因:板 `20260918060000` 走完四輪對抗審查之後,**705 行註解 / 995 行**,
> 而它已經貼上正式庫 ⇒ **那 705 行從此改不動**(改了 sha 就對不上帳本第二欄)。
>
> 🛑 **這份檔自己守它訂的規矩** —— 所以它短。

---

## 一句話

**SQL 檔只留「讀這一段 SQL 需要知道的」;「為什麼這樣決定 / 量過什麼 / 審查抓到什麼」寫 plan。**
SQL 檔頭放**一行 plan 路徑**。

---

## 為什麼:已貼的 migration 是被 sha 鎖住的

`supabase/APPLIED.tsv` 第二欄 = 那支檔的 sha256(部署閘比的就是它,`scripts/deploy-order-gate.sh:429`)。

🔬 **2026-09-19 實量**(板 `20260918060000`,已貼):
```
帳本 714 列        c5232cf4…023b5
檔案現在           c5232cf4…023b5     ✅ 對得上
剝掉註解後         7ceeaa06…3cd1      ⇒ 完全不同
只刪【一行】註解    69c40175…a4bc      ⇒ 也完全不同
⚪ 完全不動        c5232cf4…023b5     ⇒ 尺會動, 不是對什麼都回同一個
```
⇒ 📌 **sha 吃的是整份檔案的位元組,而註解也是位元組。「只搬註解」在這把尺底下不存在。**

⇒ 🛑 **所以那句話要講精確**:
**⛔ ~~「寫在已貼的 migration 裡就改不動了」~~**
**✅ 「它改得動,代價是【讓帳本說謊】。」**
而帳本說謊的代價這個 repo 當天才付過一次:板 `20260905210000` 的 view ——
帳本誠實記了貼的那一份,**而檔案在被記下來之後繼續改** ⇒ 今天正式庫跑的是舊版,**沒有任何東西會叫**。
📌 **為了瘦身去改帳本,是把那個病從【意外】變成【故意】。**

---

## 判準(照著做,不是描述現象)

**寫進 `.sql` 的**
- 這一段 SQL **在做什麼**、它的**前置條件**、每一道閘**擋的是什麼**
- 🔴 **貼的人當場需要的**:訊息怎麼讀、失敗了下一步做什麼、貼完要跑哪幾句
- 已貼檔裡**被翻掉的舊字面**(那是凍結的歷史,不能搬走)

**寫進 `docs/plans/` 的**
- **為什麼這樣決定**、誰拍的板、推翻了什麼
- **量過什麼**、對照組、讀數與出處
- **審查每一輪抓到什麼**、修法、以及修法自己造出的新問題
- 盲區、待決題、端給人的選項

**`.sql` 檔頭放一行**:`-- plan: docs/plans/<那一支>.md`

## 🔴 而「比例」是錯的尺 —— 這一格是量出來才知道的

```
已貼 497 支的【註解行數】中位數 = 121 行
註解 >= 500 行的 = 20 支     板 20260918060000 的 705 行排第 3
  （最多 887 行 20260901030000 · 812 行 20260915060000）

⚪ 而註解【比例】>=70% 的那 22 支, 絕對行數是:
   20260710120000 ⇒ 14 行 · 20260519152353 ⇒ 31 行 · 20260519031049 ⇒ 36 行 · 20260605120000 ⇒ 74 行
```
⇒ 📌 **一支 19 行的檔有 73% 是註解,那不是問題,那是正常。**
⇒ 🛑 **所以判準要看【絕對行數】,不要看比例。** 比例會把小檔誤報成病、把大檔放過去。

**可以照著做的線**:
```
註解 <= 150 行   ⇒ 正常（中位數 121)
150 - 300 行     ⇒ 停下問一次:這裡面有多少是「為什麼」而不是「是什麼」?
> 300 行         ⇒ 🔴 把「為什麼 / 量過什麼 / 審查抓到什麼」搬去 plan, 檔頭留一行路徑
                    （而【貼之前】搬還來得及;貼之後就只剩「讓帳本說謊」那條路)
```

## 🛑 這份檔證不到什麼

1. 那 29 支我是用「註解 <30% **且**檔頭 20 行有 `docs/plans/`」抓的 ——
   **兩個都是代理**。一支檔可能敘事很少而單純沒有 plan,也會被我算進去。
2. 我**沒有讀**那 29 支的內容去確認它們真的把「為什麼」寫在 plan 裡。**那是推的。**
3. 上面那三條線(150 / 300)是**從中位數與分佈挑的,不是從任何實驗來的** ——
   它們是**起點**,不是結論。用起來發現不對就改。
4. 🔴 **本檔解決不了板 `20260918060000` 那 705 行** —— 它已經凍結了。
   本檔能做的只有**讓下一支不要再長成那樣**。
