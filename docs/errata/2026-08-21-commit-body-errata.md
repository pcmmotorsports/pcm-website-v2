## 不成立 ②· `7775d78a` 的兩個數字走鐘,而同一句話裡另一組是對的

```

```


## 🔴 而抽驗者自己量錯兩次,兩次都差點交出假 finding —— 這是本表的效度證據

```
① 從 /tmp 跑 harness ⇒ 0 格 PASS ⇒ 差點報「12 格不成立」
   成因:該腳本 `cd "$(dirname "$0")/.."` ⇒ 從 /tmp 跑會 cd 到 /
   從 repo 內重跑 ⇒ 12 PASS
② 把 body 裡的裸檔名自己補成一個目錄 ⇒ fatal: path does not exist ⇒ 差點報「路徑錯」
   而真實位置是另一個目錄 ⇒ 是抽驗者補錯了目錄,不是 body 寫錯
```
🔴 兩次都是**量具設定錯,而它印出一個看起來像 finding 的結果**。
⇒ 兩次都靠「**下『不成立』之前再看一眼**」擋住。
⇒ **若直接交表,這張表會有兩條假 finding —— 而假 finding 會讓人去 amend 一顆本來是對的 commit。**
