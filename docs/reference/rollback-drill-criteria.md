## 🛑 這份判準管不到的那一層(先讀)

`scripts/rollback-drill.sh` 自己檔頭逐字:

> **空庫上的回滾演練,對【資料相依的回滾】天生全綠 —— 它發一張綠票,去做一件在正式庫上會炸的事。**

⇒ 📌 **這份判準只答「哪幾支值得演練」,不答「演練綠了就退得回來」。** 兩件事。

---

## 🔴 兩把被否掉的尺(這一節比結論重要)

### 第一把:照鐵則 12 六類直接抓關鍵字 ⇒ 命中 **105 / 112 = 94%**
`權限` 一類就命中 **102 支** —— 因為這個 repo **每一支都寫 `GRANT` / `REVOKE` / `SECURITY DEFINER`**,那是房規。
⇒ 📌 **一個命中 91% 母體的訊號,不是訊號。**

### 第二把:加上 `ALTER` / `INSERT` / `UPDATE` ⇒ 命中 **83 / 112 = 74%**,而「改資料」虛報 55%
成因:`INSERT INTO public.admin_audit_log` 出現在**幾乎每一支 RPC 的函式體裡** ——
⇒ 🔴 **那是【執行期】的事,不是【貼板當下】的資料搬移。**

### ✅ 第三把對的地方:**它換了母體**
前兩把量的是「**這支檔裡有什麼字**」;第三把量的是「**貼下去會發生什麼**」。
⇒ 作法:**剝掉行註解 + 剝掉所有 `$tag$…$tag$` 區塊**(函式體 / DO 區塊),**只看貼板當下真的會跑的頂層 SQL**。
⇒ 📌 **只有後者跟回滾有關。**

---

## ✅ 判準(第一版):只看頂層 SQL,三類

| 類 | 抓什麼 | 2026-09-16 支數 | 為什麼它「出事要能退」 |
|---|---|---|---|
| **A 一次性資料搬移** | 頂層 `UPDATE` / `INSERT INTO` / `DELETE FROM public.*` | **8**(7%) | 🔴 **最該跑而最跑不準** —— 空庫演練對它天生全綠 |
| **B 改結構** | `ALTER TABLE` · `ADD`/`DROP COLUMN` · `CREATE`/`DROP TABLE` · `ALTER TYPE` | **30**(26%) | 加了欄退不掉、改了型別回不去 |
| **C 刪既有物件** | `DROP FUNCTION` / `VIEW` / `TRIGGER` / `POLICY` | **14**(12%) | 刪掉的要靠還原檔**重建**,不是換定義 |

```
三類任一命中 = 45 / 112(40%)
都沒命中     = 67 / 112(60%)⇒ 純「換函式 / view 定義」, 退回去只是【再換一次】
```
🔵 **那 67 支刻意不演練,而理由不是「略過」**:它們的還原路徑就是「把上一代貼回去」,
而那條路 2026-09-16 已經**實跑證明過一次**(`20260916210000-rollback.sql`:退前後 md5 各自對上、
負對照「已經退過的庫再退一次」會被前置閘擋)。

## 🔴 判分不能單獨讀 —— 要配著還原檔宣稱的契約

2026-09-16 跑 A 那 8 支,兩支被判 **`NOT-CLEAN`**(反向跑完而 `pg_catalog` 沒回到原樣)。
而開檔一看,**那是它們自己寫明的刻意取捨**:
```
20260915220000-rollback.sql:4  本回滾【只拆 trigger 與函式】, 不刪欄 —— 這是刻意的
20260915230000-rollback.sql:5  只 DROP 那支函式。表與回填列【保留】(plan §9)
```
⇒ 📌 **還原檔宣稱的是「退掉【行為】」;演練問的是「目錄回到原樣了嗎」。兩件事。**
⇒ 🔴 **而 `NOT-CLEAN` 三個字讀起來像「這支壞了」—— 它沒有壞。**
⇒ 🎯 **把一個刻意的取捨報成 bug,與漏掉一個真的 bug,都是判分沒配契約讀。**

## ⚠️ 已知缺口(明寫,不假裝沒有)

1. **`supabase/rollback-drill-fixtures/` 對 A 那 8 支是空的** ⇒ 資料相依那一關**全部未測**。
   🛑 **未測不是通過。**
2. **拋棄式 PG 上有 108 / 488 支 migration apply 不起來**(演練自己印的)
   ⇒ `ENV-BLOCKED` 這個判分**有一部分是環境缺件,不是那支的錯** ⇒ 它今天判別力有限。
3. **這份判準只看【靜態字面】** —— 一支用 `EXECUTE format(...)` 動態組 `ALTER TABLE` 的 migration,它看不到。
