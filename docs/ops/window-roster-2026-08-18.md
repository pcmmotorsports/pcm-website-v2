# 窗代號 ↔ 位址 對照表(2026-08-18 夜)—— **磁碟證據,不是自陳**

> **為什麼有這份檔**:2026-08-18 夜主視窗的「窗名 ↔ 位址」對照表掉了,
> 它**發得出訊息而分不出誰是誰** ⇒ 風險:**把 A 的工作派給 B,而兩邊都會照做**。
> 🔴 **它一開始的做法是【發訊息問各窗「你是誰」】** —— 而那三封的答案**在原則上全不可信**
> (它們剛好都是真的,**而「剛好是真的」不是方法**)。
> **⇒ 這份檔的整個重點:對照表要從【磁碟】重建,不是從【窗的自陳】。**
>
> 🔴 **本檔會過期**(pid 每次重啟就變)⇒ **不要照抄下面的數字,照抄下面的【三把尺】重跑。**

## 三把尺(全部可重跑)

```bash
# 尺A|各代號的活動足跡（信箱前綴 = 代號，而它在磁碟上，不是誰說的）
cd ~/pcm-mailbox && ls -1 *.md | sed -nE 's/^([A-Z]+[0-9]*)-.*/\1/p' | sort -u | while read p; do
  last=$(ls -t ${p}-*.md 2>/dev/null | head -1); [ -z "$last" ] && continue
  printf '%-6s %s  %s\n' "$p" "$(stat -f '%Sm' -t '%m-%d %H:%M' "$last")" "$last"
done

# 尺B|現在【活著】的 session（socket 檔）
ls -l /tmp/cc-socks/*.sock

# 尺C|socket 背後的行程還在嗎（socket 在而行程死了 = 送得出去、沒人收）
for f in /tmp/cc-socks/*.sock; do p=$(basename $f .sock)
  ps -p $p >/dev/null 2>&1 && echo "$p 活著" || echo "$p 🔴 socket 在而行程死了"; done
```

## 🔴 尺A 單獨用會誤導 —— 這是本檔最該被讀到的一句

信箱裡有 **30+ 個前綴**,而其中**多數是【前幾晚艦隊的代號】**(`A`/`B`/`C`/`D`/`E`/`F`/`I`/`P`/`R`/`S`/`T`/`V`/`W1`–`W9`…)。
**只看「最後一封信的時間」會把一個【早就退場的代號】讀成「今晚沒落信的窗」。**
```
⇒ 尺A 答的是「這個代號【曾經】活動到什麼時候」
⇒ 尺B/C 答的是「現在【有幾個 session 活著】」
⇒ 兩者【不能互推】：尺A 有 30+ 個代號，尺B 只有 8 個活 session
```
🔴 **而【代號 ↔ pid】這一格,三把尺都答不出來。**
能答的只有:**那個窗自己在某封信裡寫下它量到的 pid**(例 `G5-011` 寫了 `ps -o ppid= -p $$ ⇒ 61587`)
—— **那仍然是自陳,而它是【可被複驗的自陳】**:`ls -l /tmp/cc-socks/61587.sock` 對得上就是對得上。
📎 **判別句**:**自陳不是問題,【不可複驗的自陳】才是。**
