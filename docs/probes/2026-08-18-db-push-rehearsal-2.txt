## 🔴 那個 trigger 我不只驗它「存在」,我驗它「會做事」——兩個世界
```
世界一  trigger 在   insert occurred_at='2001-01-01' ⇒ 存進去是 2026-08-18   ✅ 被覆寫
世界二  trigger 拿掉  同一句 insert                    ⇒ 存進去是 2001-01-01   ✅ 留下來
```
⇒ **負向對照證明那個綠是 trigger 造成的,不是 DEFAULT 造成的。**
   (該欄同時有 DEFAULT;只驗世界一的話,兩個成因分不開。)
📌 這正是該 migration 檔頭寫的理由:`GRANT INSERT ON TABLE` 是**整列**的
   ⇒ 拿到 key 的人可以自己指定 `occurred_at`,**DEFAULT 擋不住他,只有 trigger 擋得住**。
   **那句宣稱現在有實測了。**
