> 這是我自己在帳號被盜那份標「沒查到底」的那一格。主視窗指定先查第 3 格,**因為它有停止條件**。
> **純讀。沒有改任何訂單、沒有改任何地址。**

## 🔴 ① 先答有停止條件的那格:**是【快照】,不是參照 ⇒ 停止條件不觸發**
```
supabase/migrations/20260604120000_m3_s2a_orders_order_items.sql:97 逐字:
  shipping_address_snapshot jsonb NOT NULL,
  -- 🔴 收件地址凍結快照（白名單 name/phone/line）；**防客人刪地址後訂單失履約地址**（codex k2 WARN-1）
而 admin 讀模型明文排除參照:SupabaseOrderAdapter.ts:241「**零 cart_session_id / address_id**」
```
⇒ ✅ **攻擊者改客戶通訊錄裡的地址,【不會】改動任何已成立訂單的收件地址。**
⇒ 🔴 **那句「立即暫停」的份量因此【降一級】** —— 在途訂單不會被改向。
📌 而這**不是運氣**:那個快照是**為了另一個理由**做的(防客人刪地址後訂單失履約地址),
**而它順便擋掉了攔貨。** —— **一個為 A 做的設計,擋住了沒人想過的 B。**
