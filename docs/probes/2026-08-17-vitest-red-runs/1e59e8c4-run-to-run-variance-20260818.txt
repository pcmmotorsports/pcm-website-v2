## 🔴 我原本要寫的結論,被自己的資料擋下來了
我本來要寫:「5-9x 遠超出觀察到的變異 ⇒ 逾時是**另一種現象**(離散卡住),不是抖動的尾巴」。
**擋住它的是 `500ms-1s` 那一層的倍率最大 `9.42x`** ——
⇒ **那個量級的格子,9 倍的爆炸在三發之內就出現過。**
⇒ 所以「5.2x 不可能」是**錯的**;正確講法只有:
   **在這三發裡,那兩個格子沒有跑出那種倍率;而同量級的別的格子跑出過。**
📌 這條記下來的價值不在結論,在**它是「n=3 看不到尾巴」的具體長相** ——
   三發是我能負擔的樣本數,而**尾巴正是三發最看不到的東西**。
