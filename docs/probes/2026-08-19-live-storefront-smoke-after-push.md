## 判別法:hydration 探針(不是「按鈕在不在」)

「按鈕在不在」在**頁面活著**與**整頁是死的 HTML** 兩個世界會印同一句話。
所以每一頁量的是 **React 有沒有接手**:
```js
const els = [...document.querySelectorAll('input,button,a')];
({ 掃到: els.length,
   被接手: els.filter(e => Object.keys(e).some(k => k.startsWith('__reactFiber'))).length })
```
**掃到 N / 接手 N ⇒ 活的;掃到 N / 接手 0 ⇒ 整頁是死的 HTML。**
