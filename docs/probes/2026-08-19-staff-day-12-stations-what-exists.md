# 🔴 第 5 站(出貨):**功能存在,而且是接完整的** —— 這一格答掉了主視窗的問題

主視窗問:那五支出貨 RPC **有沒有呼叫端**?
```
數法:對每一支跑 `grep -rl <RPC名> apps/admin/src`,再濾掉 *.test.*
  admin_create_shipment        非測試檔命中 4
  admin_add_shipment_items     非測試檔命中 3
  admin_mark_shipment_shipped  非測試檔命中 1
  admin_void_shipment          非測試檔命中 2
  admin_unvoid_shipment        非測試檔命中 1
🔴 負向對照(證明尺會動):admin_cancel_order(我知道畫面上有)⇒ 非測試檔命中 4  ← 同一個量級
```
**而它們一路接到畫面**:
```
apps/admin/src/lib/shipping/shipment-actions.ts 被這些 UI 元件引用:
  shipment-dialog.tsx / shipment-mark-shipped-button.tsx / shipment-section.tsx /
  shipping-selection.tsx / shipment-void-button.tsx / order-detail.tsx
而 order-detail.tsx:304 逐字 `<ShipmentSection detail={detail} />` —— **無條件渲染,沒有旗標**
```
⇒ ✅ **第 5 站【不是「功能不存在」】。它存在、接完整、而且畫面上就有那顆鈕。**
