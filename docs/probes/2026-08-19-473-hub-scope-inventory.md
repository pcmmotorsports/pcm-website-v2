## §1 ① 三條真的要同一片嗎(用 G6 的判別句)

**判別句**:只做 A 不做 B,會不會**新增一個原本不存在的壞狀態**?

### `#473` + `#497` ⇒ 🔴 **要同一片**
```
今天    manual_failed 是死路 ⇒ 沒有人在更正判定 ⇒ #497 的症狀【很少被觸發】
只做 #473 接線 ⇒ 員工開始更正判定
       而客人的訂單頁仍然停在「處理中」(payment_status 走不到 refunded)
       且【員工無從得知】客人看到的是錯的
⇒ 新增的壞狀態:「**我更正好了**」與「**客人看到的仍是錯的**」同時成立,而沒有人會發現
⇒ 那不是把舊 bug 留著,是把一個【很少發生】的東西變成【每次更正都發生】
```

### `#473` + `#445b` ⇒ **不同片,而順序是硬的**
```
backlog:13311 逐字「#445 的 apply 停點是【#473 沒有出口之前不得 apply 445b】」
⇒ #473 是 #445b 的【前置】,不是同一片
⇒ 只做 #445b 不做 #473 ⇒ 那張單永遠退不了款而解鎖入口不存在 ⇒ 所以才有那個停點
⇒ 而反過來(只做 #473 不做 #445b)【不會製造任何壞狀態】—— 那正是它可以先做的理由
```
