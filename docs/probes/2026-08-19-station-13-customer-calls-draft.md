# 第 13 站 · 客人打電話來問東西

| | |
|---|---|
| **這一站在測什麼** | 客服一天裡最常做的事:**客人問一件事,員工查不查得到、答不答得出來**。前面 12 站測的是「你主動去做一件事」,這一站測的是「**別人來找你**」。 |
| **怎麼測** | 你不用真的接電話。**假裝你是客服**,照下面每一列的「客人說什麼」,去後台把答案找出來。 |
| **回報什麼** | 每一列回一句:**我找到了 / 我找不到 / 我找到了但不知道怎麼跟他說**。🔴 **第三種最重要** —— 那代表畫面上沒有告訴你該怎麼辦。 |

## 逐列

| # | 客人說什麼 | 員工今天做得到嗎 | 卡在哪 | 🔴 畫面上有沒有告訴他做不到 |
|---|---|---|---|---|

| 13-3 | 「我地址打錯了,幫我改」 | 🔴 **做不到** | 「編輯訂單」那一區只有**出貨方式 / 開票狀態 / 發票號碼 / 發票金額**,**沒有地址欄** | ❌ **沒有** —— 地址在上面「收件與出貨」看得到,而**看得到改不了,畫面上沒有一個字解釋** |
| 13-4 | 「我要退款,退到哪了?」 | ⚠️ **看情況** | 系統內退的:退款紀錄區有金額/日期/誰做的。**系統外退的**(例 `PCM-2026-0102`):付款狀態寫「已退款」而**整個退款紀錄區都不存在** | ⚠️ 退款區有一句「Portal 場外退款不在其中」,而**那句話在沒有退款紀錄區的那張單上根本不會出現** |
| 13-5 | 「我要你們刪掉我的資料」 | ⚠️ **接得住,做不完** | `data-rights-sop.md` §0 三格待你拍(保存期限 / 硬刪 vs 匿名化 / 窗口是誰)⇒ 現在只能做到「收件、驗身分、確認期限」 | — SOP 有寫,而**那份 SOP 不在後台畫面上** |

| 13-7 | 「我要看你們有我哪些資料」 | ⚠️ **做得到而很慢** | 客戶頁看得到基本資料;而**完整清單散在 `data-rights-sop.md` §4 那份表**(訂單快照 / 自由文字欄 / 同意證據…) | — 同 13-5 |
| 13-8 | 「幫我在單子上記一下」 | ✅ **做得到** | 訂單頁有「新增備註」 | ✅ 而它自己寫著「**備註為永久紀錄、送出後不可刪除**」——**這是好的**,按之前就知道後果 |

## 🔴 這一站真正要你看的一件事

```
13-2 / 13-3 / 13-6 三列的共同點:**員工會去找、找不到、而畫面上沒有一個字告訴他為什麼**。
⇒ 那一刻他手上沒有東西可以跟客人說,**只能說「我幫你問一下」然後掛掉。**
⇒ 而那三件事你這邊都有解(找人查 DB / 你自己改 / 你進 Supabase 後台)——
   **問題是那三件事今天沒有一件是【員工做得到】的。**
```
