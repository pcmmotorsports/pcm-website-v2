## 二 · 入選判準(兩軸的聯集;答不出 yes/no ⇒ 視為 no、不入選)
```
軸①【客人看得見】：商品頁 / 結帳 / 訂單頁 / 會員中心 / 寄給客人的信

⇒ 入選 = 軸① OR 軸②
⇒ 排除 = 純內部工程債（型別、拆檔、CI、測試結構、docs 自身、lint、快取）
```
⚠️ **邊界情況先講死,免得中途自己放寬**:
- 「後台某頁的版面 bug」⇒ **入選**(員工每天看)。
- 「某支 adapter 的型別謊言」⇒ **不入選**,除非條目自己寫了客人/員工面的症狀。
- 「等 Sean 拍板某個文案」⇒ **入選**(客人看得見)。
- 「等 Sean 提供素材/名單/費率」⇒ **入選但只報不改**(那是真的在等他,我改不動)。
