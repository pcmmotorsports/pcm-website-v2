## 附錄 · **「待辦排在拍板上面」這一類,掃完了(2026-08-19 G2)**

`#639` 那一筆(待辦粗體排在 ✅ 拍板上面)讓人懷疑它是一族。**掃了,它不是。**

**尺**:條目內第一個 `狀態` 欄仍是待辦(允許 emoji/標記在 `- ` 與 `**狀態` 之間),
而**它下面**有未劃線的完成宣告(`🏁 **已` / `✅ **已` / `✅ **Sean`)。

🔴 **第一版的尺回 0,而那個 0 是假的** —— 它寫成 `^- \*\*狀態`,
而 `#639` 那行是 `- 🔴 **狀態(...)`(emoji 卡在中間)⇒ **它連【已知的那一筆】都抓不到**。
⇒ **一把抓不到已知實例的尺,回 0 只代表它瞎了。**

**正向對照(這是這一發能算數的原因)**:
```
拿 8626f5e6~1（修 #639 之前）跑同一把尺 ⇒ 8 筆，其中包含 #639 ✅ 尺看得到它
拿今天的樹跑                            ⇒ 7 筆，#639 不見了
⇒ 兩個世界印不同的東西 ⇒ 尺有判別力，這個結果才能引用
```

**剩下 7 筆逐條開檔核 ⇒ 全部是假陽性**:它們的「✅ 已…」是**子事實**
(表格裡的一列 / 某個子項做完了 / 某條危害已證實),**而條目本身確實仍待辦**。
例:`#231` 的 `② 真 alert channel ✅ 已實作` 是三條邊界表的一列。

⇒ 🔴 **結論:這一類在 backlog 裡只有 `#639` 一筆,已修。不必再掃。**
