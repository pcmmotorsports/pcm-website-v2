```
量到的兩件事:
① /login 頁面上【沒有任何一句話說明他為什麼被導來】
   數法:登入頁全文 /結帳|登入後|請先登入/ ⇒ **false**
   它寫的是「登入您的 PCM 帳號,查看訂單與收藏。」—— 講的是訂單與收藏,不是結帳
② 登入成功後落在 `https://shop.pcmmotorsports.com/`(首頁),不是 /checkout
   而 /login 的網址上**沒有 next / redirect 之類的參數**(逐字就是 `/login`)
```
**客人實際會經歷的**:
```
按「前往結帳」→ 突然到一個講「查看訂單與收藏」的頁 → 他不確定剛才那一按有沒有生效
→ 登入 → 被丟回首頁 → **他要自己想起來回購物車、再按一次結帳**
```
✅ **好消息:購物車沒有掉。** 登入後 header 徽章仍是 **1**(localStorage 存活)。
⇒ 所以損失的是「他要多走兩步、而且中間有一段不知道發生什麼事」,**不是把單弄丟**。

**分類**:機制是 ①(擋得住、登得進、車還在),而**缺的是【告訴他發生什麼】與【送他回去】**。
📎 這與 `#659` 同族:**系統知道發生什麼事,而客人不知道。**
