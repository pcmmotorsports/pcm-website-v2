### 🔴 5-2a ⇒ 這一族**不是偶發,是結構性的**

F-1 / F-5 / F-6 三個實例共用同一個生成機制:

> **一個描述「我出生之前的世界」的數字,會被【我的出生】改掉 —— 而那句話留在原地。**

```
而它幾乎是【必然】的, 因為:
  一支測試檔在檔頭寫「我為什麼存在」時, 最有說服力的寫法就是
  「在我之前, 這裡 grep 出來是 0 / 是 N」
  ⇒ 而那條 grep 的關鍵字, 正是這支檔的主題
  ⇒ **它一定會命中自己。**
⇒ 📌 **越是誠實地記錄「我出生前的覆蓋率」, 越保證那個數字會在出生當下作廢。**
⇒ 這不是紀律問題(三次都是有紀律的人寫的, 其中一次是我今天全程開著這個意識時寫的)
  ⇒ 🔴 **是形狀問題 ⇒ 該用機制擋**(常載 §4 機制優先律)。
```

**候選機制(不是本片實作,是給折 plan 的人;三個實例的落點見 `§2` F-1、`§5-1` F-5、`§5-2` F-6)**:
```
甲 寫「出生前」的數字時一律附 commit hash 當錨:
   「在 `<hash>` 之前 ⇒ 0」—— 那句話永遠為真, 因為它綁死了一個時點
```
