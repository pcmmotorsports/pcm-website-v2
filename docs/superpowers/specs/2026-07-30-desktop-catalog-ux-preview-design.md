# Desktop Catalog UX Preview Design

## 2026-07-30 現況檢查後修訂（本節優先）

Sean 看過第一版桌機預覽後，確認桌機正式商品頁的整體架構不需要重畫。新版視覺參考改成直接使用正式 `/products` 的完整 UI 與真資料，只在網址帶 `vehicle-ui=preview` 時，局部替換上方車輛選擇列的視覺提示。

- 一般 `/products` 必須維持目前字面、樣式與行為。
- 預覽網址使用正式 Header、左側 `FilterSide`、商品卡、排序、分頁與頁面寬度，不建立第二套桌機型錄。
- 預覽選車列維持目前高度與 sticky 位置，改顯示「選擇適用車輛」及「可直接選擇，也可輸入搜尋」。
- 三欄 placeholder 改為「搜尋或選擇廠牌／車型／年份」，並以搜尋圖示強化可輸入提示。
- 年份選項只在預覽模式改為最新年份在前；品牌、車型與年份仍沿用正式 `VehicleCombo` 行為與字典資料。
- 「我的愛車」及「清除車輛」保留原本位置與功能。
- 拿掉 `vehicle-ui=preview` 即完整 rollback，不修改資料、URL 車輛參數語意或正式部署設定。

## 目標

在既有 `/dev-preview/mobile-catalog-ux` 本機路由加入可操作的桌機商品目錄版本。桌機版維持 PCM 目前「上方選車、左側分類與商品條件、右側商品」方向，透過層級、字級、間距與清除出口改善操作，不延伸成滿螢幕寬度。

## 已確認基線

- 真正設計來源：`design-reference/components/FilterTop.jsx`、`design-reference/styles/filter-top.css`、`design-reference/components/ProductsPage.jsx`。
- 正式現況：`CascadeFilterTop.tsx` 提供可輸入的廠牌／車型／年份，`ProductsPage.tsx` 使用固定寬度 shell、左側 `FilterSide` 與右側商品區。
- 本次只做隔離預覽，不修改上述正式元件、正式 CSS、URL state、Supabase 或商品資料。
- 預覽文字與假資料屬一次性 L1 內容。

## 版面

桌機寬度 `> 1024px` 顯示桌機預覽，內容最大寬度為 1180px 並置中；`<= 1024px` 對齊正式網站的手機／平板導覽切換點：

1. 精簡頁首與「全部商品」標題。
2. 上方車輛工作列：
   - 「選擇適用車輛」標題與輔助說明。
   - 「我的愛車」快速選擇。
   - 廠牌、車型、年份三個可輸入也可展開捲動的 combobox。
   - 清除輸入與清除已套用車輛使用文字操作，不增加大型按鈕。
3. 下方兩欄：
   - 左欄 232px：商品分類、商品品牌、價格。
   - 右欄：結果數、排序與三欄商品卡。

手機寬度維持已核准的 390px 操作版；尚未選車的紅框移除重複說明句並縮短上下留白，不改手機資訊架構與操作出口。

## 互動

- 點「我的愛車」可直接套用車輛。
- 三個車輛欄位均支援文字過濾與捲動點選；沒有欄位會在頁面載入時自動取得焦點。
- 清除輸入只清空三個草稿欄位；清除車輛會取消套用車輛與車輛相關分類。
- 分類直接在左欄選擇，不開滿版面板。
- 商品品牌與價格在左欄展開選擇；不提供「現貨商品」。
- 排序維持右上角單一選單。

## 視覺原則

- 沿用 PCM 黑、白、紅色票與現有商品目錄的克制風格。
- 字體大小以 14–18px 為主，重要標題與選中狀態有明確差異。
- 下拉選項限制高度並可捲動，避免大量車種把頁面撐長。
- 不加入車輛圖片，不用圖片協助辨識車款。

## 驗證

- 元件測試覆蓋我的愛車、輸入過濾、套用、清除輸入、清除車輛、分類、商品條件與排序。
- 1365×900 與 1025×768 驗證桌機內容維持置中且不滿版；1024×768 驗證正確切換手機／平板版；390×844 回歸手機版。
- 執行 targeted Vitest、storefront typecheck、lint、build、水平溢出檢查與 axe 自動檢查。

## Rollback

刪除新增的桌機預覽元件、測試與 CSS，並還原手機預覽容器中桌機元件的匯入與顯示規則，即可完整回復；正式商品頁不受影響。
