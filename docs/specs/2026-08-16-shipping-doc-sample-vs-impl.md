**⇒ 可做成機制的修法**(不是「下次記得」):
```
① 任何 plan 寫「設計稿/樣張」時，【位置欄】必須寫【canonical 來源】而不是某個副本路徑。

## 🔴🔴 §5 一條我要主動提的風險:**樣張那條對帳式在第二箱不成立**

樣張逐字:`訂購 29 ＝ 本次出貨 23 ＋ 尚未出貨 4 ＋ 已取消 2`(23+4+2 = 29 ✅)

**而那是【第一箱】的數字** —— 它沒有「先前已出貨」那一項。
第二箱時正確的式子是:`訂購 = 先前已出 + 本次 + 尚未 + 已取消`(**四項**)。

📎 而 **Sean 2026-08-16 自己拍過這件事**:
> 「會算錯就不印,**只計算本次出貨**,然後第二或這第三批出到沒貨時尚未出貨那邊就空了就好」

⇒ **樣張(08-15)早於那次拍板(08-16)** ⇒ 兩者可能只是時序差,不是矛盾。
```
Q-C17：第二箱時那條對帳式怎麼辦？
A：加第四項「先前已出貨」，式子變四項（誠實，但比樣張多一個數字）
B：第二箱起【不印】對帳式（樣張的簡潔留給第一箱）
C：維持三項 —— 🔴 不推薦：第二箱會印出一條加不起來的等式，
   而「印一條加不起來的等式，比不印更糟」
```
**C 窗推薦 A。** 但**這一題我不自己拍** —— 它動的是樣張上的字面。
⚠️ **在它答之前,我不實作對帳式那一列**,其餘六項可以照搬。
