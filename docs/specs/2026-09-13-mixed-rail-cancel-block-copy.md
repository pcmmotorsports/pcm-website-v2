```
標題
這張單收過兩種方式的錢,先不開放在這裡結掉

說明
這張單的錢不是只用一種方式收的(例如刷卡之外還收過匯款或現金),
而系統現在算不出卡片那邊還有沒有錢沒退回去。
這種單如果直接標成已取消,少退的那一筆不會出現在任何一張待辦上,不會有人再發現它。
請先不要按,把單號告知系統維護。
這張單本身沒有問題 —— 客人確實是用兩種方式付的,也不是你操作錯誤。
本頁的「收款」裡看得到這張單收過哪幾種方式。
```

## 每一句在做什麼(給 Sean 看的對照)

| 句 | 它在做的事 | 為什麼是這樣寫 |
|---|---|---|
| 「收過兩種方式的錢」 | 講**為什麼擋** | 🔴 **不用內部詞彙**(不講「混軌」「跨軌合算」「payment_status」)。員工要聽懂的層次是「這張單的錢分兩種方式收過」。 |
| 「算不出卡片那邊還有沒有錢沒退回去」 | 講**系統的限制**, 不是他的限制 | 把責任放在系統身上。而這句是**事實**:待退款那支算式只跑匯款與現金兩軌, 卡那軌根本不在裡面。 |
| 「少退的那一筆不會出現在任何一張待辦上」 | 講**風險** | 📌 沒有這一句, 這道閘看起來只是龜毛。有了它, 員工知道**繞過去的代價是什麼**。 |
| 「請先不要按,把單號告知系統維護」 | 講**下一步** | 🔵 「告知系統維護」是這個後台**既有的說法**(至少三處在用, 見下面〈沿用了什麼〉)⇒ 不是我新發明一個他沒聽過的窗口。 |
| 「這張單本身沒有問題…也不是你操作錯誤」 | 擋他**不是因為他做錯** | 那張單是合法的 —— 客人真的用兩種方式付過錢。⚠️ **而這一句有一個技術前提**, 見下面那段紅字。 |
| 「本頁的『收款』裡看得到…」 | 指**位置**, 不指流程名 | 🔬 字面當場核過:`payment-list.tsx:234` 的 `<h2>收款</h2>`;而那張清單**逐列印收款方式**(`:59` 的 `{e.railLabel}`)⇒ 這句話是真的。 |

## 沿用了什麼(不是新發明)

```
· 形狀 = 這個後台既有的 {tone, title, hint} 擋住文案家族
  (`cancel-review-section.tsx` 的 BLOCK_REASON_TEXT / `cancel-result-panel.tsx` 的 MARK_REJECTED_TEXT)
· 「指位置,不指流程名」 —— `cancel-review-section.tsx:78-83` 逐字寫著這條紀律,
  而它旁邊記著一次事故:有人把 title 寫成「要走**退款流程**」而畫面上根本沒有那個東西。
· 「這不是你操作錯誤」 —— `payment_rail_unverifiable` 那一則的結尾就是這句(同檔 :113)。
· 「告知系統維護」 —— 同上, 以及 MARK_REJECTED_TEXT 與 MARKED_CANCELLED_UNVERIFIED_TEXT。
· 語氣 = 那顆鈕自己的那句(`order-cancel-block.tsx:191`
  「錢已經退完了,這一步只是把訂單標記成已取消 —— 不會再動到任何一筆錢。」)
```

## 刻意沒寫的

```
🔴 **一個金額都沒有。**
   那道閘擋的正是「系統算不清楚金額」⇒ 📌 **在那個訊息裡印一個數字,
   就是印一個我們自己不相信的數字。**
   ⚠️ 而「印一個還差多少讓他安心」是很自然會想做的事 —— 所以寫下來擋住它。
🔵 **沒寫「這張單該怎麼退」** —— 那是另一片的射程
   (`cancel-review-section.tsx:83` 逐字:三句都不講各收款方式該怎麼退)。
```

## 🔴🔴 一個技術前提 —— 而它會讓上面那句「不是你操作錯誤」變成假話

```
🛑 **今天這條路的【所有】拒絕都收斂成同一句話。**
  `cancel-actions.ts:400-404`:`outcome.code === 'rejected'` ⇒ 一律 `markRejectedResultQuery()`
  ⇒ 畫面顯示 `MARK_REJECTED_TEXT`(`cancel-result-panel.tsx:181-198`)。

🔴 **而那一句【列舉】了它的原因**, 逐字:
    「『把這張單結掉』只適用於刷卡收款、而且錢已經全額退完的單,
      並且這張單先前沒有部分取消過。」
  ⇒ 📌 **加了混軌這道閘而不給它自己的訊息 ⇒ 那個列舉就少一項 ⇒ 那句話變成假的。**
    而員工會對著一張「刷卡、已全退、沒部分取消過」的單, 讀到一句說它應該可以結掉的話。

🔴🔴 **而更硬的一格在同一支檔 `:191-196`** —— 那裡有一段 codex R2 must-fix 的留痕,
  逐字:「**不可以斷言『這不是系統出錯』**…那支 RPC 的 `P0001` 同時涵蓋四族…
  SQLSTATE 分不出它們 ⇒ **一句安慰的話, 在四分之二的世界裡是假的** ——
  而它會讓員工不去回報。」
  ⇒ 🛑 **所以「不是你操作錯誤」這句話, 只有在那道閘【可分辨】的時候才寫得下去。**

⇒ ✅ **本文案的交付條件(不是文案問題, 是接線問題)**:
   混軌那道閘必須回一個**與其他拒絕分得開**的碼(自己的 SQLSTATE 或自己的 outcome code),
   讓這條路能選到這一則、而不是落進那句共用的。
⇒ 📌 **這一條先前沒有人寫下來** —— 我寫文案的時候才撞到它。
```
