> **給誰看**:端這兩支給 Sean 的人(主視窗-87),以及貼的人。
> **這份檔什麼時候會【變成假的】**:**任何一支的呼叫端 / 寫入端被寫出來的那一刻。**
> 🔴 而下面整份的結論**都建立在「今天零呼叫端」這個量測上** ⇒ 那個前提一旦不成立,結論全數重來。
> ⇒ 📌 **不是時間到期,是別人動了東西** —— 而**沒有機制會叫**,讀的人自己重跑 §0 那兩發。

## §3 🔴 真正要小心的是【第三種順序】:**呼叫端先上,而 SQL 還沒貼**

主視窗-87 問對了一格:**「碼先部署而 SQL 沒貼會怎樣?那才是真正會發生的順序」** ——
因為**收割推 dev 隨時會發生,而 Sean 可能明天才貼**。

### 3-a #3(品牌搜尋)—— **這一支的風險最大,而它今天還沒到**
```
今天:零呼叫端 ⇒ 碼推上去也沒有人叫它 ⇒ 安全
而【有人寫了呼叫端】之後, 若函式還沒貼:
  PostgREST 對不存在的 RPC 回 404 / PGRST202
  ⇒ 🔴 **顧客站的搜尋會【整條壞掉】**, 而那是客人直接碰得到的路徑
```
🛑 **⇒ 所以呼叫端那一片有一條硬約束,現在就寫下來,免得寫的人自己想**:
> **呼叫端不得「直接改用新函式」** —— 它必須**留一條退路**:
> 叫不到那支函式時,**退回今天的四欄 ILIKE 述詞**(那條路今天是綠的),
> 而**不是**讓整個搜尋壞掉。
> ⇒ ✅ 判別句:**「SQL 還沒貼的那一天,客人搜尋的結果會變差,而不是消失。」**
⚠️ **而我沒有寫那個呼叫端** ⇒ 這是**寫給下一個人的約束**,不是已經做到的事。

### 3-b #2(取消信)—— **風險方向相反:它會【安靜地不寄】**
```
今天:零寫入端 ⇒ 安全
而【有人寫了 enqueue】之後, 若 CHECK 還沒放寬:
  DB 用 23514 當場擋 ⇒ 那一列**寫不進 outbox**
  ⇒ 🔴 **客人收不到取消信, 而畫面上沒有任何東西說這件事**
```
🔵 **而失敗方向本身是安全的**(不會寄錯信、不會寄垃圾)⇒ 但**它是靜默的**。
🛑 ⇒ 寫 enqueue 那一片的人要決定:**寫不進去的時候要不要留下訊號**(而預設是不會留)。

## §4 ⚠️ 一格我要自己揭露:**我的新守門有一個它自己看不到的盲區**

`scripts/email-event-type-union-vs-db.test.ts`(本次同批)斷言「TS union 不得有 DB 沒有的值」——
🔴 **而它掃的是 repo 裡的 migration 原始碼,不是【正式庫真的在跑的那一版】。**
```
今天的實況:20260903040000 在 repo 裡, 而它【沒有被 apply】
⇒ 我的測試看得到那個檔 ⇒ 它判「TS ⊆ DB」成立 ⇒ 綠
⇒ 🛑 而**正式庫上那個值域還沒放寬** ⇒ 那個綠**答的是 repo 的一致性, 不是正式庫的**
```
📌 **⇒ 「repo 一致」與「正式庫一致」是兩個宣稱,而我的守門只答得出前一個。**
✅ **要答後一個,唯一的方法是對正式庫查 `pg_get_constraintdef`** —— 而那要 DB access,我沒有。

### 🔴 4-a 而主視窗-87 03:2x 替我查了,**答案是:那個問題拿去問正式庫,今天是紅的**
```
正式庫實測 email_outbox_event_type_check 全文:
  CHECK ((event_type = ANY (ARRAY['order_created','order_shipped','order_cancelled'])))
⇒ 正式庫 **三值**, 而【沒有】 order_unpaid_cancelled
而 TS union 今天是:order_created / order_shipped / order_unpaid_cancelled  ⇒ 也是三值, 但**不是同一組**
```
🎯 **⇒ TS 有一個正式庫沒有的值** ⇒ 若今天有人寫了 enqueue 並部署,而 SQL 還沒貼
   ⇒ **DB 用 `23514` 擋 ⇒ 那封信永遠寄不出去**(正是 §3-b 那一格)。
🟢 **而今天不會發生** —— 零寫入端(§0 量過)。
⚠️ **而那個「三值」會過期**:**Sean 貼下去的那一刻它就變四值** ⇒ 引用它的人**看日期與來源**。
🔵 **我沒有因此改那格斷言,只加了射程** —— 把它改成問正式庫,會讓它需要 DB 連線
   ⇒ 在 CI 與每個施工窗都跑不動 ⇒ **它會變成一格經常被跳過的測試,而那比一格射程窄但一直在跑的糟。**
⇒ 那一格**歸有 access 的人**,而 `-db` 今晚做的「逐支產出貼了沒的唯讀 SQL」那支工具**應該會掃到我這兩支**。
