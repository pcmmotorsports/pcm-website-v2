  • ③ 跨頁抬頭:第 2 頁、第 3 頁的最上面,有沒有「出貨明細單 PCM-2026-0042」?
    有 ⇒ 技法可用。只有第 1 頁有 ⇒ 不可用,要換做法。
  • ④ 頁碼:每一頁的最下面正中央,有沒有「第 N 頁 / 共 M 頁」?
    有 ⇒ Chrome 支援 @page 邊距框,頁碼可以做。 完全沒有 ⇒ 不支援,頁碼要另外想辦法(或改用 Chrome 自己的頁尾設定)。 ⚠️ 前提是你已經把 Chrome 的「頁首及頁尾」關掉了,不然看到的可能是 Chrome 印的。
  • ⑤ 簽名只在最後一頁:「出貨人簽名 / 收件人簽名」那兩條線,是不是只在最後一頁出現一次?
    前面幾頁也有 ⇒ 技法選錯。另外請看:那條虛線的 「⑤ 反例對照」是不是每一頁都有?(它應該每頁都有,那是刻意的反例。)
  • ⑤b 簽名有沒有被擠到單獨一頁:最後一頁是不是只有簽名欄、沒有品項?
