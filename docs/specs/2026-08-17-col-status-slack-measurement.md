# `col-status` 餘裕量測 —— 片 1 動版面之前先知道哪一格會先爆

> **這是一份量測,不是 plan 改動。** V 窗那份 plan 審查還在跑 ⇒ **本檔不動 plan 本體**,審完一次併。
> **作者**:A 窗,2026-08-17。**問句**:片 1 要動版面,**那個改動本身會不會製造新的說謊?**

## 0. 🔴 結論先講(而它推翻了我原本的直覺)

```
「未知」不是最脆弱的那一格 —— 它是【餘裕最大】的那一格
88px 欄:四字狀態餘裕 24px ／「未知」餘裕 48px
84px 欄:四字狀態餘裕 20px ／「未知」餘裕 44px
⇒ 片 1 若動 col-status 的寬度或 padding，【先爆的是四字狀態】，不是「未知」
```
⇒ **驗收 13(可見性)守的不是「被擠掉」,是「被【隱藏】」** —— 寬度不會是「未知」那格的死法。
**這一句要寫進 plan(等 V 窗審完一起併),否則做的人會去盯錯的那一格。**

## 1. 量法(可重跑)

**取值來源逐條(repo 字面,不是估的)**
```
.orders-grid .col-status{width:88px}          globals.css:848-849
@container 窄版 .col-status{width:84px}       globals.css:1037-1038
const TD = 'px-3 py-2 …'                      orders-table.tsx:115   ⇒ 左右各 12px
STATUS_CAPSULE = 'inline-flex px-2 py-0.5 text-xs font-medium'
                                              order-list-view.ts:193 ⇒ 左右各 8px、12px 字
九個狀態字面（全部都是 4 個中文字）           order-status-axes.ts:49-51
截斷時的字面「未知」（2 個中文字）            orders-table.tsx:431
```
**跑法**:`scratchpad/colstatus-measure.html` → 本機靜態服務 → 真 Chromium 量 `getBoundingClientRect()`。
`可用 = td.clientWidth − 24（左右 padding）`;`餘裕 = 可用 − 膠囊實測寬`。

**🔴 量具自檢(兩個世界要給不同答案)**
```
餵一個一定爆的:八字膠囊 ⇒ 實測 112px > 可用 88px ⇒ 判爆 ✅
正常四字膠囊              ⇒ 64px < 88px          ⇒ 判不爆 ✅
⇒ 這把尺分得出來，上面的數字可以信
```

## 2. 逐格結果

| 欄寬 | 字面 | 膠囊實測 | 可用 | 餘裕 |
|---|---|---|---|---|
| 88px | 九個四字狀態(未收未定…貨到在庫) | 64px | 88px | **24px** |
| 88px | **未知**(截斷時) | 40px | 88px | **48px** |
| 84px(卡片) | 九個四字狀態 | 64px | 84px | **20px** |
| 84px(卡片) | **未知** | 40px | 84px | **44px** |

**九個狀態全部同寬(64px)** —— 因為它們**都是 4 個中文字**,沒有例外(`order-status-axes.ts:49-51` 逐字)。

## 3. ⚠️ 這份量測的限定(不帶著它就不要引用)

```
① 🔴 本機沒有 BMWTypeNext ⇒ 量到的是【系統備援字】的字寬
   真字型若比備援寬，24px / 20px 那個餘裕會【縮小】，方向是變差不是變好
   ⇒ 這些數字是【下限風險的樂觀版】，不是保證
② 這是我用 repo 的字面值重建的量測頁，【不是 apps/admin 的編譯產物】
   本機沒有資料可以打開真的訂單列表（我整晚的一貫限定）
③ 只量了 88 / 84 兩個寬度（repo 現有的兩個）；片 1 若引入第三個寬度要重量
④ 未經 Sean 肉眼確認
```

## 4. 這份量測改變了什麼

```
改變了【驗收要盯哪一格】:
  原本的直覺  截斷時「未知」會不會被擠掉        ⇒ 量完知道它餘裕最大，不是威脅
  真正的風險  四字狀態只剩 24px / 20px 餘裕     ⇒ 動 padding、動字型、動 font-size 都吃它
📎 與 #614「六顆欄寬餘裕債」同族 —— 那條記的是六顆欄，本檔把 col-status 這顆量到底。
```
🔴 **而驗收 13 仍然要留**:它守的是**被隱藏**(`display:none` / `visibility` / 零尺寸),
**與寬度是兩條不同的死法**。本量測只排除了其中一條。
