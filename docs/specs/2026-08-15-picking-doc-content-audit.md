## §0 🔴🔴 動手前必讀三件(答案不含、而執行者必須知道)

### ① `品項:N 項` 是**全部品項**,不是**這次要揀的量**

```
apps/admin/src/components/print/picking-doc.tsx:109
  <span>品項:{detail.items.length} 項</span>
```
`detail.items` 是**整張訂單的品項**,含「這次不用揀」的列(未到貨 / 已出貨 / 已取消)。
🔴 **直接把它改成合計會錯** —— 它現在與表格列數一致(每個品項都有一列),那是對的;
要加的是**另一個數字**(見 §2 第 1 欄),不是改這個。
**兩者長得像同一種數字,語意不同。**

### ② 前提是「內部**但實體暴露**」,不是「內部所以隨便」

作者自己在檔頭逐字寫著(`picking-doc.tsx:8`):
```
而這張紙會被拿到倉庫、放在桌上、可能被客人瞄到 ⇒ 少印一個欄位就少一個外洩面。
```
🔴 **這兩個前提推出來的結論方向相反**:
- 「內部所以隨便」⇒ 可以多印點資訊(**錯**)
- 「內部但實體暴露」⇒ **現行的「少印一個欄位就少一個外洩面」是對的**

⇒ **不得以「反正是內部的」為理由加收件電話 / 地址 / 金額。**
那條禁令**有守門而且突變驗過**:
`apps/admin/src/app/print/orders/[id]/picking/page.test.tsx:136`
格②「揀貨單上不得有**任何**金額欄位,也不得有收件電話 / 地址」。

🔴🔴 **真正的損害不是他加錯欄位,是他被守門擋下之後【去改守門】** ——
而他會覺得自己在排除障礙。**這段話存在的唯一目的就是攔那一刻。**
(同機制:`apps/storefront/src/components/HomeFooter.tsx:50-58` 的鐵則 1 具名例外。)
