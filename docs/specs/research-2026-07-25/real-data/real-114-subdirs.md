## 3. 外層沒有的新文件種類(逐一說明欄位結構)

### 3.1 綜合損益表(記帳軟體格式,2 頁)
- 表頭三列:公司名 / `綜合損益表` / `期間:<民國年>年<月>月<日>日 至 <民國年>年<月>月<日>日` + `頁次 : n`
- 表格 4 欄:**會計項目 | 金額 | 小計 | 總計**
- 會計項目前綴 **4 碼會計科目代號**(自訂科目表,例:41xx 銷貨收入類、51xx 進貨類、59xx 其他營業成本、60xx-63xx 營業費用、70xx 非營業收益、80xx 非營業損失、90xx 所得稅費用;11xx 存貨科目在成本區塊借用)
- 區塊順序(固定):
  營業收入 → 營業收入淨額 → *(獨立百分比列 `100.00 %`)* → 銷貨成本(買賣業:期初商品存貨 / 進貨 / **減:**期末商品存貨)→ 銷貨總成本 → 其他營業成本 → 營業成本 → **成本率 %** → 營業毛利(或毛損) → **毛利率 %** → 營業費用(逐科目)→ 營業費用總額 → **費用率 %** → 營業利益(或損失) → **營業利益率 %** → 非營業收益 → 非營業損失及費用 → 本期損益 → **純益率 %** → 課稅所得額 → 減:所得稅費用 → 稅後淨利 → 其他綜合損益 → 本期其他綜合損益淨額 →(第 2 頁)本期綜合損益總額
- 格式:金額千分位逗號、無貨幣符號;比率 = 兩位小數 + `%`,且**比率自成一列**(不與科目同列),機器解析時要當獨立列處理。

### 3.2 資產負債表(帳戶式,1 頁)
- 表頭:公司名 / `資產負債表(帳戶式)` / `民國<年>年<月>月<日>日` / `頁次: n`
- **左右對開 4 欄**:資產項目 | 金額 ‖ 負債及權益項目 | 金額

- 格式:小計/總計列前置**全形 `＄`**;負數用**半形括號** `( )` 包住(非負號)。
- ⚠️ 解析陷阱:長科目名會被 PDF 換行拆成兩列(如「減:累計折舊-運/輸設備」),不能逐行硬切。
