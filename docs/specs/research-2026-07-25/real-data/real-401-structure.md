## 3. 申報期別怎麼標示

四種寫法並存,核心都是**民國年 + 期別**:

| 場合 | 格式 | 樣式 |
|---|---|---|
| 申報書/繳款書表頭 | `<民國年3碼> 年 <MM> － <MM> 月` | 逐字含全形破折號 |
| 檔名與統計表「資料所屬年月」 | **`YYYMM`(5 碼)= 民國年3碼 + 期別末月2碼** | 雙月申報 → 末月恆為偶數:`02 04 06 08 10 12` |
| 資料夾名 | 無統一規則 | `113 07-08`、`115_0506`、`112年度`、`113 11-12/113111260430` |
| 發票明細表 | `中華民國 <民國年> 年 <MM>～<MM> 月份` | 用全形波浪號 |

- 期別 = **雙月(每 2 個月一期)**,一年 6 期。註記欄雖有「核准按月申報」選項但本批資料走雙月。
- `收件編號` 格式:`F` + 統編8碼 + 期別5碼 + 流水5碼(共 19 碼)。
- 繳款書右上另有 10 碼列印批號,及條碼區三段條碼(其一形如 `401` + 期別 + 補零稅額)。
- 民國年區間:112–115(對應西元 2023–2026)。

## 4. 進項與銷項各需要哪些明細欄位才填得出這張表

### 4.1 銷項(來源:統一發票明細表)

明細表分「二聯式(號碼段 50~99)」「三聯式(號碼段 00~49)」兩張,欄位:

`序號` / `買受人統一編號`(非營業人免填) / `銷售額`(發票總計金額) / **課稅別勾選 3 選 1:應稅 / 零稅率 / 免稅** / `稅額` / `備註`

表頭另需:`統一編號`、`營業人名稱`、`稅籍編號`、`年月份`、**`發票字軌`**(2 碼英文,如 `ZZ`/`ZX`)、**`發票前六位號碼`**。
表尾「發票使用情形 / 銷售額及稅額計算」:`使用份數`(應稅/零稅率/免稅分列) / `作廢` / `空白` / 售與營業人的 `銷售額`+`稅額` / 售與非營業人的 `發票總金額(1)`、`銷售額(2)=(1)*100/105`、`稅額(3)=(2)*5%` / 零稅率銷售額 / 免稅銷售額;分「本表合計」與「本期(月)總計」兩列。作廢者該列填「本張作廢」。

→ **填 401 所需最小集合**:每張發票的 銷售額、稅額、課稅別、發票種類(二聯/三聯/電子)、是否作廢、是否退回折讓、買受人是否營業人。

### 4.2 進項

需要按**憑證類別**歸類(決定進 401 的哪一列)、再按 **進貨及費用 / 固定資產** 二分、再標**可扣抵 / 不可扣抵**。統計表的「不可扣抵」區用 `扣抵代號 3 / 4 / 空白` 分類。

每筆需要:`發票號碼`、`發票日期`、`賣方統一編號`、`銷售額(未稅)`、`營業稅額`、`課稅別`、`格式代號`、`發票狀態`。

### 4.3 二手車進項(附件表,特殊路徑)

`營業人購買舊乘人小汽車及機車進項憑證明細表` 欄位:

- 銷項側:`序號`、`車種`(代號)、`車牌號碼`、`銷售日期`、`發票字軌號碼`、`銷售額`、`銷項稅額(1)`
- 前手車主:`姓名或名稱`、`身分證字號或統一編號`
- 進項側:`購入日期`、`購入金額(含其他規費等)`、`進項金額 (2)=(3)`(公式 `(1+徵收率)` 除)、`進項稅額 (4)`(公式 `×徵收率`)、`得扣抵進項稅額 (5) = 取 (1) 或 (4) 較小者`、`購車憑證代號`
- 代號表:購車憑證 `1 普通收據 / 2 個人一時貿易資料申報表 / 3 特種統一發票 / 4 買賣合約書或讓渡書 / 5 其他`;車種 `1 小客車 / 2 小貨車 / 3 小客貨兩用車 / 4 代用小客車 / 5 小型特種車 / 6 機車`
- 表尾明載:**本表「得扣抵進項稅額」須併入申報書「進項」-「載有稅額之其他憑證」欄位**(即 401 代號 36/37)。

### 4.4 統計表 → 申報書的對應(實測驗證通過)

統計表以**格式代號**分列,可直接對到 401 的進項/銷項列:

| 統計表格式代號 | 對應 401 欄位 |
|---|---|
| 銷項 (31) | 三聯式發票、電子計算機發票 → 代號 1 / 2 |
| 進項 (21) | 統一發票扣抵聯 → 代號 28 / 29 |
| 進項 (25) | 三聯式收銀機發票扣抵聯及電子發票 → 代號 32 / 33 |
| 進項 (28) | 海關代徵營業稅繳納證扣抵聯 → 代號 78 / 79 |
| 進項 合計 | → 代號 44 / 45 =`(9)` |

統計表出現的完整代號位:銷項 `31 32 -33 -34 35 36 37 -38`;進項 `21 22 #22 -23 -24 25 26 27 28 -29`。前綴符號有意義:**`-` = 退回/折讓(減項)**、**`#` = 法院或行政執行機關拍定或承受貨物**、**`@` = 購買舊乘人小汽車及機車進項憑證**(符號說明逐字印在表尾)。統計表另附 `銷項使用發票數(不含銷貨退回或折讓證明單)` / `銷項空白發票數` / `銷項作廢發票數`,並註明「本表各金額欄項之加總僅供參考,申報書之填寫仍須依營業稅法規定計算」。

## 5. 媒體申報檔 / 固定格式文字檔
