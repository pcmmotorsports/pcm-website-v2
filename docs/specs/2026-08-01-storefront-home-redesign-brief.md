## 背景

PCM Motorsports 是重機改裝零件**電商**(真購物車、結帳、TapPay 金流、會員經銷價分級)。
現行首頁自述美學是 `v2 · Editorial aesthetic (Apple × Hermès × Uniqlo)` ——
**偏形象刊物不是實作走鐘,是設計當初就這樣定的**,所以這次要改的是定位本身。

Sean 原話:「首頁偏視覺概念形象取向,但我們實質是購物車網站,又想保有一點風格跟美感。」

## 這次動什麼 / 不動什麼

- **動:版面結構** — 區塊順序、份量比重、可砍可併、首頁到底要講什麼。
- **不動:視覺調性** — 黑白節奏、紅色只當 accent、現有字體
  (Inter / Noto Sans TC / Noto Serif TC / Cormorant Garamond / JetBrains Mono)、
  `styles/tokens.css` 既有語彙。換調性是另一題,這次不碰。

## 真站量出來的問題(重排要解的,全部有數字)

1. **首屏零商業訊號** — Hero 佔桌機 824px(視窗 892)⇒ 進站第一屏幾乎只有一張圖跟一句英文標語。
   無搜尋框、無商品、無價格。
2. **唯一入口埋在第二屏** — 手機上選車器起點在 **841px**,要捲過將近一整屏才看得到,
   而它是全站唯一的「依車輛找料」入口,自己只佔 3.5%。
3. **版面比重跟商業價值相反** — 純文字品牌牆桌機 **1791px = 全頁最高區塊**,
   是商品區(669px)的 **2.7 倍**。全頁 6686px 裡真正在賣東西的只有 669px = **10%**。
4. **全頁 11 個手機螢幕高** — 要捲 11 屏才到底。
5. **文案與事實打架** — 服務宣言寫「**8 大品牌**正式代理」,而它下面的品牌牆列了 **17 家**。
6. **編號撞號(既有 bug)** — Hero 標 `N°01`,選車器標 `01 ·`。重排時一併解掉。

## 要產出什麼

**3 個互相打架的方向**,不是同款微調。每個方向都要:
- 桌機(1200)+ 手機(390)兩個尺寸
- 用**上表的真實內容**(真分類名、真件數、真品牌名、真商品與真價格),不要編新的
- 落在 Open Design,一個方向一個 artifact

### 三個方向的軸線(視覺表現由 Design 決定,這裡只定結構立場)

- **A · 型錄優先** — 首屏直接是選車器 + 商品。Hero 壓成窄帶或直接砍。
  編輯感只靠字體、留白、紅點存活。最像電商。
- **B · 封面內嵌入口** — 保留全幅 Hero 的氣勢,但把選車器/搜尋**嵌進 Hero 裡**,
  首屏同時有態度也有入口。編輯區塊砍半。
- **C · 上下分軌** — 上半頁純購物(選車 → 分類 → 大量商品),
  下半頁純編輯(本月聚焦 → 品牌 → 服務宣言)。壁壘分明,不交錯。

三個方向都必須回答同一個問題:

> **一個第一次來、想買排氣管的人,在第一屏能不能開始?**

### 不要做的事

- 不要三個都是「現況微調」—— 要真的能吵起來
- 不要換配色 / 換字體(那是另一題)
- 不要用假商品名或假價格
- 不要照 `design-reference/components/HomePage.jsx` 那份假稿 —— **它與真站不符**

Design 定案 → Claude Code 用 OD MCP 把 artifact 拉進 `design-reference/`
