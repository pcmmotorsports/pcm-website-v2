## 🔵 為什麼加那兩句「金額可能變高」——**已答, 而措辭有邊界**

```
🔴 病灶:金額可能【比他下單時看到的高】, 而第一版草稿沒有一個字解釋為什麼。

成因(plan §2 逐字):effective_total 不只是「扣掉取消的件」, 它還會
  ① 券整張作廢、算回原價(Sean Q39 逐字「那優惠卷就不能使用, 這樣最簡單, 算回原價」)
  ② 運費照規則重算(Sean 09-05 拍乙:跌破 5000 門檻要補收 100)
⇒ 一張用過券、取消之後跌破門檻的單, 這封信的數字會比他原本要付的【多】。

✅ **Sean 2026-09-13 答甲 = 要在信裡講一句為什麼**(A2 甲「照寄」是另一題, 已答在前)。
```

**措辭的邊界(主視窗 2026-09-13 轉達, 我照著寫)**
| 邊界 | 我怎麼落 |
|---|---|
| 用客人看得懂的話, 不要出現「券作廢」「原價回算」「門檻」這類內部說法 | 寫「原本使用的**折扣可能不再適用**」「運費也可能**隨金額變動**」 |
| 兩個成因都要涵蓋 | 折扣 + 運費各一個子句 |
| 不要寫成規則條文 | 用「可能」不用「將」;不提 5000、不提百分比、不提券的名字 |
| 位置接在「已經照舊金額匯了怎麼辦」附近 | 排在它**上面** —— 先講「為什麼變了」, 再講「已經匯了怎麼辦」, 那是客人讀的順序 |
| 形狀貼著他 09-06 核可的匯款信、改動最小 | 新增 2 行 + 一個空行, 既有每一行仍然一字不動 |

🛑 **而這兩句仍然要他親自核可** —— 他答的是「要有這一句」, 不是「這個措辭可以」。
📌 兩件事不一樣, 而把它讀成一樣就是**拿一個有前提的同意當成沒前提的**(接手包 §7 ③ 那個病)。
