## 0. 一段白話(給 Sean)

後台訂單列表現在是**一個品項就一列**。一張單有幾個品項,它在列表上就佔幾列。

- 今天沒事,因為**目前最大的單只有 2 個品項**。
- 而你自己說過**一張單可能到 200 個品項**。真的來一張,那**一張單就會在列表上鋪開 200 列**,
  而同一頁還有另外 19 張單。
- 另外系統有一個**一次最多載 500 個品項**的限制。超過 500 的那一張,列表會知道自己沒載完
  (狀態欄會印「未知」,不會騙人),但**畫面還是會鋪開 500 列**。

**要你決定的是:訂單列表上,一張單要不要把品項全部攤開?** 選項在 §4。

## 2. 🔴 `#631` 條目沒寫、而我認為更該先處理的一面

原條目(`4d4261dc`,在 `bmw-m-headline` 分支)整條圍繞 **501**:「第一張 501 項的單進來會靜默算錯」。
**而逐品項展開這件事在 200 就痛了,不必等 501**,並且:

```
501 那條  ⇒ 狀態欄已經 fail-closed（印「未知」）⇒ 不會騙人，只是難看
200 這條  ⇒ 沒有任何旗標在管它 ⇒ 一張單吃掉整頁，而【沒有任何東西會紅】
```
⇒ **先痛的是後者,而它今天零守門。**

## 3. 🔴 未量的一條 —— 它會改變選項的優先序,不要當成已知

`db-max-rows`(2026-08-18 起 `2000`)套用到內嵌陣列時,**是每個陣列各自 2000,還是整份回應合計 2000?**

- 查證正本 `docs/specs/2026-08-16-postgrest-max-rows-embed-finding.md` **沒有回答這一題**
  (它回答的是「套不套用」= 套用,且截斷時零訊號)。
- **若是整份回應合計**:20 張 × 各 200 項 = 4000 > 2000 ⇒ 截斷會發生在一個
  **`>= 500` 判定看不見的位置** ⇒ `itemsTruncated` 恆 `false` **而資料真的少了**
  ⇒ 那才是真正的靜默,比 `#631` 描述的嚴重。
- **若是每個陣列各自**:今天的形狀安全,`500` 這個常數繼續有效。

🔴 **這一題只能實測**(拋棄式 PG + PostgREST,`docs/runbooks/local-admin-with-real-data-probe.md`)。
⚠️ **本機測得出 PostgREST 的行為,測不出正式站的 `db-max-rows` 設定值** —— 兩件事分開講。

## 4. 要 Sean 拍的題

```
Q-631:訂單列表上,一張單的品項要怎麼顯示?

A. 甲 = 收起來（我建議）
   一張單最多顯示前 3 個品項，後面收成一行「另有 N 項，點進去看」。
   好處：不管 5 項還是 500 項，列表一頁的長度都固定；今天就能做。
   代價：要在列表上一眼掃過所有品名的話，得多點一下。

B. 乙 = 全部攤開，維持現狀
   代價：真的來一張 200 項的單，那一頁就等於只剩那一張單。
   （這是今天的行為，選它 = 知情接受。）

C. 丙 = 先不決定，我先去把 §3 那條未量的實測完再回報
   代價：多花半天，而甲/乙 的答案不會因為那個實測而改變（它改變的是「還要不要另外修」）。
```

**我建議甲。** 理由:它同時解掉 200 那條(今天就會痛)與 501 那條(畫面部分),
而且**不動 adapter、不動查詢** ⇒ 不觸發 schema/API 風險,rollback 就是改回去。

## 5. 甲的影響面與 rollback(鐵則 8 要求)

| 項 | 內容 |
|---|---|
| **要改什麼** | `orders-table.tsx` 的 `rows` 加一個顯示上限 + 一行「另有 N 項」;對應 smoke test |
| **為什麼** | 一張單的品項數是**業務資料**,而它今天直接決定**畫面高度**,沒有上限 |
| **影響面** | 後台訂單列表一頁的外觀;**不動查詢、不動 adapter、不動 schema、不碰 `packages/ui`** |
| **不影響** | 狀態欄/金額欄的既有 `itemsTruncated` 閘(那半照舊)、明細頁、列印單 |
| **rollback** | 單檔改回 `rows = order.lines`,一顆 revert |
| **鐵則 12** | 六類**皆不中**(不動錢的計算、不動權限、不動 schema、不動平台設定、不對外送出、不動 `packages/ui`) |
| **⚠️ 撞車** | `orders-table.tsx` 是 W7 的施工檔(`bmw-m-headline`)⇒ **批了之後要由 W7 做,或等它收割完再動** |
