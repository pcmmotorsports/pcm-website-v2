## §2 · 員工日常操作流程(白話版)

> 寫法照 Sean 2026-08-11 立的「操作直覺化」準則:寫怎麼做、不寫內部語彙
> (出處=memory `project_admin-ux-operation-intuitiveness`)。
> 每一步 = 去哪裡 → 按什麼 → 出錯時看什麼字。
> ⚠️ 本節是否每一句都合乎那條準則 = **未確認**(沒有機械檢查工具,我**未逐句核**);
> 讀起來卡的地方請直接說,那是文案問題不是功能問題。

### 步驟 1 · 接單:找到那張單

1. 進**訂單列表**(左側選單「訂單」)。
2. 找單有兩條路:**上方搜尋框**打關鍵字(客人名字、訂單編號、供應商單號、料號都可以),
   或用**篩選**縮小範圍。
3. 找到後**點單號**——桌機會從右邊滑出一個面板,手機會整頁打開。
   > 整列都可以點,不是只有單號那幾個字。
4. 列表上一眼能看到的:日期、品牌、料號、品名、車種、數量、金額、客戶、**訂貨**、**發票**、**操作**。

### 步驟 2 · 收款:錢進來了要登記

1. 在訂單詳情頁找到**收款卡**。上面固定四點:**應收多少、已收多少、還差多少、收了哪幾筆**。
2. 客人匯款進來 → 按**登錄收款**,填金額與收款方式。
3. **收多了 / 登錯了** → 在那一筆上按**沖銷**。沖銷不是刪除:原本那筆還在,另外多一筆把它抵掉,
   帳上兩筆都看得到(這是刻意的,錢的紀錄不消失)。
4. 刷卡的單不用手動登記——刷卡成功會自己進來。

### 步驟 3 · 叫貨與到貨:東西還沒到就出不了

1. 詳情頁的**採購區**,每個品項可以分別標「已向供應商下單」、填**供應商單號**與**預計到貨日**;
   缺貨要等的話填**例外原因**,列上就看得到。
2. **貨到了** → 按那一列的**貨到了**登記到貨數量。
   > 🔴 **這步不做,後面出不了貨**:系統判斷「能不能出」看的是**到貨量**,不是訂購量。
3. 忘了先登記也沒關係:**建箱彈窗裡也有「貨到了」**,可以當場登記完直接接著出貨。
   > 這一步另有一份值班須知(含部署前置與出錯處置):`docs/runbooks/order-receipt-recording-duty.md`(106 行)。
   > 本節只講怎麼操作,那份講的是值班時遇到狀況怎麼辦 —— 兩份不重疊,要一起看。

### 步驟 4 · 出貨:裝箱與寄出

1. 兩個入口:**訂單列表勾選幾張單** → 按「出貨」(可以把同一位客人的多張單裝同一箱);
   或在**單張訂單的出貨卡**按「建立包裹」。
2. 彈窗裡每個品項寫著**還能出幾件**。
   - 能出的**排在前面**;出不了的沉到最後,並且會寫明為什麼:
     **未到貨 / 已裝進其他箱子 / 已取消 / 數量資料尚未就緒**。
   - 出不了的那些數量框會停用——不是壞掉,是那件現在真的出不了。
3. 選好數量、選快遞商、填**貨運單號**(新竹或順豐時必填),按「只建箱」或「建箱並標出貨」。
4. **出錯了怎麼看**:錯誤訊息第一行是人話、第二行告訴你下一步該做什麼,
   原始訊息收在**「詳細(每個品項可出幾件)」**裡面——那裡有逐品項的實際數字。
5. **建箱成功但掛品項失敗**(會留下一個空箱):訊息會給你**箱號**,並告訴你
   「再按一次沿用同一箱、不會重複建」;不要了的話,到**這位客人任一張訂單頁的「出貨」→「未收尾的空箱」**作廢它。
   > 那一區只在有空箱時才出現;它是**客人層**的,列出來的空箱可能來自這位客人的別張訂單。

### 步驟 5 · 取消與退款

1. **取消**:訂單列表最右邊「操作」欄按**取消**,或進詳情頁往下找取消區。
   - 系統會先給你一張**影響範圍複核**:取消什麼、幾件、多少錢、寄到哪。
   - 已到貨的品項**不能取消**——那要走退貨(退貨功能還沒做)。
   - 已付款的單要取消會連動退款。
2. **退款**:退款畫面已經做好,但**目前由一個開關控制是否顯示**;正式站現在是開還是關**未確認**
   (見 §4 待確認第 1 條)。
