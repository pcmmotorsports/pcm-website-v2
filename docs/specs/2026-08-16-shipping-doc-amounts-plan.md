## §3 要印哪些數字(每一個都附出處,`Q-D-7` 驗收條款)

| 紙上的字 | 值 | 出處 / 運算 |
|---|---|---|
| 品項「金額」 | `unitPrice.amount × 本區數量` | `types.ts` 錨點 `unitPrice: Money`;**整數 × 整數** |
| 本次出貨小計 | Σ(上一列,本區) | 本區各列相加,**不跨區** |
| 尚未出貨小計 | Σ(上一列,本區) | 同上 |
| 商品小計 | `detail.subtotal` | **直接印,零運算**(契約 `subtotal = Σ lineTotal`) |
| 運費 | `detail.shippingFee` | 直接印 |
| 折扣 | `detail.discountTotal` | 直接印,前面加負號 |
| 付款金額 | `detail.total` | **直接印,零運算** |

🔴 **結算四行全部直接印權威欄,零推算、零湊數。**
不變式(`types.ts` 錨點 `total = subtotal + shippingFee`)保證它們加得起來,
**而我不在紙上重算來「驗證」它** —— 重算等於在紙上多一個可能與權威值不符的數字。

🔴 **兩區小計【不等於】商品小計,而那是對的**:小計的母體是整張訂單(全下單量),
兩區的母體是「這一箱」與「還欠的」。**紙上不得出現任何跨區等式**(同 `#10` 片2b 已有的紀律)。
⚠️ 這一點要在紙上用一句人話講清楚,否則客人會自己相加然後發現對不起來。
