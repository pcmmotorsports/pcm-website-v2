- HTML demo,每個方向一個檔或一頁內可切換;要能直接開來看。
- 每個方向附一句「這個方向賭的是什麼」,讓 Sean 知道差別在哪、不用自己推。
- **不要**同時給五六個方向 —— Sean 要的是差異夠大的少數選項,不是選色盤。
