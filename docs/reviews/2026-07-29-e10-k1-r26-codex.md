2. PG session 中斷，advisory lock 自動釋放。
3. 新 recovery invocation B 取得鎖，但 state 仍是 `run id=A`。
4. 依新規則「state run id 必須等於本次」，B 必須因 `A != B` abort，無法恢復 sweeper或清除 state。
