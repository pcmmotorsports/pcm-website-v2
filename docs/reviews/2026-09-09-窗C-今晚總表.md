### 📌 今天量出來的方法教訓(不是猜的,每一條都有現場)
- **一個「沒紅」有兩種原因:閘壞了,或尺沒接上。前提斷言分得開。**(突變 B 第一次沒紅,是突變根本沒套進去)
- **一道用子字串當判準的閘,會被同名的參數餵飽。**(`zero_price_reason` vs `p_zero_price_reason`)
- **這個 shell 的 `grep` 是 ugrep 包裝**,bounded repetition 超過複雜度上限 ⇒ **錯誤進 stderr、stdout 空、rc=0**。要真數量用 `/usr/bin/grep`。
- **`pg_get_functiondef` 的輸出沒有結尾分號** ⇒ 直接貼進 rollback 會跟下一個 `CREATE` 黏成語法錯誤。**一個跑不起來的 rollback 比沒有 rollback 更糟。**
- **`CREATE OR REPLACE` 會把 `SET` 子句整組換掉**;七參數簽章不在時它會變成**新增函式**而拿預設權限。
- **撞號閘只看檔名、只看這棵樹** ⇒ 別窗貼了而沒 push,那個號在你眼裡是空的。**今晚我就是這樣撞的。**
- **git commit 時間 ≠ apply/deploy 時間**(今天錯兩次)。要問貼了沒,查 `supabase/APPLIED.tsv` 或 `scripts/is-migration-applied.sh`。
