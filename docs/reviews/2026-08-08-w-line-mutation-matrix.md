## 2. 🔴 本片清償的一筆:`w2` 的 `TMUT-WIRED` 承諾債

`w2-verify.sh:18` 逐字寫著:

> 本檔的 `TMUT-ACL` / `TMUT-WIRED` 因此逐成員打,全部翻面才算。

**`TMUT-WIRED` 從來沒有被寫出來。** 全 repo `grep` 只命中這句承諾本身。
⇒ `W2-WIRED-*` 五格(守的正是「五支 writer 真的接上冪等層,不是只有骨架還在」)
自 W2 落檔起一直是**零靶**族,而檔頭寫著它已逐成員打過。

已補(`w2-verify.sh` §12 ⓪),三腿逐支跑:

| 腿 | 動作 | 觀察 |
|---|---|---|
| 基準 | 不動 | 必須是 `P2B22 payload_mismatch` |
| 突變 | 換回骨架版(`RAISE P2B20`) | 翻成 `P2B20` |
| 還原 | 從 `pg_get_functiondef` 存檔還原 | 翻回 `P2B22` |

實跑:五支全過,w2 由 69 綠 → **70 綠**(`EXPECT_TOTAL` 67→68)。

**施工中被自己的守門抓到兩次,兩次都記帳:**
1. 首版把靶排在 §12 ⑧ 之後 ⇒ 五支的基準腿全部量到「無錯誤」——前面的突變早把 mismatch
   那條路拆掉了,「突變後變 P2B20」根本不可歸因。**基準腿抓到了它自己要防的東西**(判準第三句)。
   ⇒ 移到 §12 第一個、並改成逐支「突變→觀察→還原→還原自證」(否則後面要呼 writer 的靶
   量到的是我的骨架 stub)。
2. 期望字面寫死 `P2B20|(null)` ⇒ 五支全誤紅。`RAISE … USING ERRCODE` 的 `CONSTRAINT_NAME`
   是**空字串不是 NULL** ⇒ `cap()` 的 `coalesce(n,'(null)')` 不觸發。
   fail-closed(紅在該紅的地方)不是假綠,但仍是「比錯東西」——與 memory 那條
   `psql -qtA` 字面族同源。修法=只釘 SQLSTATE 前綴。
