## 🔴 五次「把兩件事收斂成一個鍵」—— 本線的母題

```
① 標籤 vs 開關          fallback 不是標籤，是三張執法矩陣的鍵
② 列舉值 vs 性質        加 bootstrap 變體閃不開「有沒有具名 staff」那個以性質為鍵的閘
③ 身分 vs 認證強度      amr 不是缺陷，它是另一個軸
④ 證明方式 vs 證明時點  強度軸還有 auth_time 這個座標（而它自己也是收斂的）
⑤ 鑰匙 vs 稽核紀錄      sso_codes 一列同時是兩者，而兩者要求相反（⇒ #651）
```
📎 **主視窗逐字**:「收斂讀起來像簡化,而它是在刪掉一個真實存在的維度。」
🔴 **判別句**:**要把一個欄位/旗標/enum 拿來當閘之前,先問「誰會 branch 這個欄位?」**
—— 答案超過一種問題,那它就承擔了兩件事。
