## 5. 量測本身的限制
- 🔴 我一開始用的 grep 樣式把帶 `?` 的網址濾掉了,曾量到「目錄頁 0 個商品連結」。換樣式重量後是 **50 條**。上面寫的是**重量後**的數字。
- 🔴 本機鑽機的 DB 缺 `search_catalog_by_vehicle` 的 `p_categories` 多載(`up.sh` 自己有預告)⇒ 本機目錄回 0 筆 ⇒ 「目錄頁有沒有商品連結」「分類頁 h1 會不會變成分類名」兩格**本機無效**,前者改用線上量、後者標未確認。
