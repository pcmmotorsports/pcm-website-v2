# 五支排程外部存活訊號 —— 上線驗收表(受 git 追蹤,不是 mailbox)

> 🔴 **為什麼這份要在 repo 裡**(codex 2026-08-29 must-fix):
> 原本的驗收步驟寫在 `~/pcm-mailbox/` —— 而 **mailbox 不受 git 追蹤 ⇒ 沒有任何東西能證明驗收做過**。
> ⇒ 驗收結果請**直接寫進本檔並 commit**,一行一支。

## 這是在驗什麼
五支 pg_cron 排程在成功那一刻,會送一發「我還活著」到 healthchecks.io。
```
沒接上（env 沒設 / 貼錯 / 那支排程本來就沒在跑）⇒ 那支 check 停在 'new'
🔴 而 'new' 【不會告警】⇒ 【沒接上】與【剛建好還沒開始】印同一個字
⇒ 所以要有這一次人工驗收；而它【只需要做一次】——
   第一發訊號成功之後，任何後來的失聯都會讓它從 'up' 掉成 'down' ⇒ 它自己會叫
```

## 🔴 什麼時候看 —— **五支的週期不一樣,不能用同一個時限**
| check | pg_cron schedule | 設完之後多久該翻成 `up` |
|---|---|---|
| `pcm-settle-sweep` | `*/2 * * * *` | 約 2 分鐘 |
| `pcm-order-ineligible-gate` | `*/2 * * * *` | 約 2 分鐘 |
| `pcm-email-sweep` | `*/5 * * * *` | 約 5 分鐘 |
| `pcm-capture-recheck` | `*/10 * * * *` | 約 10 分鐘 |
| 🔴 `pcm-anomaly-alert` | `0 1 * * *` | **每天凌晨一點才跑** ⇒ 最久要等近 **24 小時** |

⚠️ **用同一個時限去驗五支,最後那一支會被判成失敗** —— 而它只是還沒到時間。
📌 **那個誤判會讓人去修一個沒有壞的東西。**

🔴 **填表時「什麼時候該看」要寫【那一支下一次預定執行的時刻】,不是「隔幾分鐘」**
(主視窗 2026-08-29 指定):
```
做法：設完 env 的當下，先照上表的 cron 算出每一支【下一次預定執行時刻】並寫在備註欄
     然後在那個時刻【之後】再去看 status
⇒ 一個籠統的「隔幾分鐘」會讓 anomaly-alert 被判成失敗，而它只是還沒到時間
```

**怎麼量**(唯讀,金鑰不進 argv):
```bash
# 金鑰讀自 .env.local，走 curl --config，用完刪；全程不印出值
GET https://healthchecks.io/api/v3/checks/     ⇒ 讀每一支的 status 欄
```
✅ 合格 = `status` 原字面是 `"up"`。
🔴 **貼原字面,不要寫「正常」** —— `new` / `up` / `grace` / `down` 是四個不同的字,而「正常」蓋掉了它們的差別。

## 🔴 為什麼【沒有】在 build 時擋(而這不是「比較省事」)

codex 2026-08-29 建議的最低修法有兩半:①production build 驗五值非空/origin 正確/互不重複 ②repo 內受追蹤的驗收表。
**主視窗 2026-08-29 裁:只做 ②,①改成部署後的一支腳本。** 理由:
```
① 擋的是一個【只有正式站才成立】的條件
⇒ 放進 build ⇒ 本機與 preview 每個人都被擋，而他們【本來就不該有那五個值】
📌 一道閘擋住了它從來不打算保護的那群人 ⇒ 它會被關掉，
   而關掉之後【正式站那一側也跟著沒有了】
🔴 一道會誤擋的閘，自己就會長出那顆「臨時關掉」的開關
```

### ⚠️ 而這個選擇的代價要寫出來,不要藏
```
只做 ② ⇒ 「正式站那五個值真的設對了」這件事，在【部署那一刻】沒有任何機制在看
        它靠一支【要有人去跑】的腳本 + 這張要有人填的表
⇒ 這是把一個【機制】降級成一個【動作】。
🔴 所以本表不得被讀成「已保護」——它只證明【有人在某個時刻看過一次】。
```

## 🔴 這份驗收【不】保證什麼
```
· 它證明「那支 route 跑得起來、而且訊號送得到 healthchecks」
· 它【不】證明那支 route 做的事是對的 —— 只證明它有跑完
· 它【不】涵蓋第六支 pcm-expire-unpaid-orders（純 SQL、不走這條路，設計上就沒有 ping）
🔴 · env 貼成【別支的 URL】⇒ 兩支都會翻 up，而它們指到同一個地方
     ⇒ 這份驗收【看不出來】。要看得出來得比對五個 uuid 互不重複，而那要拿到值 —— 本表不做
```
