> **給 Sean 跑的。** 兩行指令、三分鐘。`tidy` 2026-09-08 寫。
> 🔴 **要在【重新開一個視窗之後】跑** —— 規則是在 session 開始時載入的,現在這個 session 已經開過了。

---

## 為什麼要量這一發(一句話)

我們想讓**規則自己在該出現的時候出現**,而不是靠人記得去讀。
官方文件說做得到,而 **「文件說做得到」與「你這台機器上真的做得到」是兩件事。**

🛑 而它壞掉的時候**不會有任何紅字** —— 那正是要親手量一次的理由。

---

## 怎麼跑

**要找的那串字**(它只存在於一個檔案裡,不會跟別的東西搞混):

```
PATHSPROBE-K7Q4-REACTRULES-LOADED
```

### 第 ① 發 —— 它**該出現**的時候

1. 在 Claude Code 裡**打開任何一支 `.tsx` 檔**(例:請 Claude 讀 `apps/storefront` 底下任一支 `.tsx`)
2. 輸入 `/context`
3. 在畫面上找上面那串字

### 第 ② 發 —— 它**不該出現**的時候

1. **重新開一個視窗**(不要接續上面那個)
2. 打開任何一支 `.md` 或 `.sql` 檔 —— **不要碰 `.tsx`**
3. 輸入 `/context`
4. 一樣找那串字

---

## 三種結果,各代表什麼(🔴 這一段是重點)

| ① 開 `.tsx` | ② 開 `.md` | 意思 | 接下來 |
|---|---|---|---|
| **看得到** | **看不到** | 🟢 **機制成立** —— 規則真的會自己在對的時候出現 | 可以把更多「要人記得去讀」的規則改成這樣 |
| **看得到** | 🔴 **也看得到** | 🛑 **機制沒生效** —— 它其實是**每次都載入**,只是剛好①也對 | 那一支要撤掉(它沒有省到任何東西) |
| 🔴 **看不到** | 看不到 | 🛑 **這台機器上不支援** —— 或設定寫錯 | 一樣撤掉,而這個讀數本身值得記下來 |

🔴 **為什麼一定要跑第 ② 發**:
如果只跑①看到了就說「成功」——
📌 **那與「它其實每次都載入」是同一個畫面。** 兩個世界印一樣的東西,只有②分得開。

---

## 而不管結果是哪一種,回報這三格就好

```
① 開 .tsx  ⇒ 看得到 / 看不到
② 開 .md   ⇒ 看得到 / 看不到
③ 你是在【重開視窗之後】跑的嗎 ⇒ 是 / 不是
```
🛑 **第 ③ 格不能省** —— 若是在舊 session 裡跑的,①②都不算數(規則還沒被重新載入)。
