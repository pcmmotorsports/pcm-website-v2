# 夜跑怎麼跑(2026-09-11 · 窗B 寫,材料是 09-10 那一夜實際撞過的)

> # 🎯 一個夜跑的主視窗,第一件事該做什麼?
>
> ## **要一個分母。在派任何一個窗做任何一件事之前。**
>
> ```
> ❌ 「去把 ship- 那族查完」          ⇒ 那個窗查完才知道有幾列, 而你整夜不知道進度
> ✅ 「先數:ship- 帶擋未標有幾列, 報我。報完再開工」
> ```
> 🔴 **而 09-10 那一夜,「先報分母」救了三次** —— 三次都是**兩把尺數出不同的數字**,
> 而**逐一開檔看**之後發現是尺的問題,不是列的問題。
> 📌 **⇒ 沒有分母的夜跑,天亮的時候你只知道「做了很多」。**
>
> 🛑 **而流程那五條不在這一份裡** —— 它們在 `docs/handoff/CURRENT.md` 最上面。
> **這一份只講【夜跑的操作面】。**

## 一、🔴 什麼算「不用他決策」—— 一條判別句,不是一份清單

> ## **判別句:這件事做錯了,能不能【在他起床之前】變回去?**
>
> ```
> 能變回去  ⇒ 不用他決策。做。
> 不能      ⇒ 停下來寫成一題, 排進他早上那一份
> ```

### 而「能不能變回去」怎麼判(三問,依序)

```
① 它會不會【送到外面】?(對客人 / 對新竹 / 對銀行 / 對 Resend)
   ⇒ 會 ⇒ 🔴 不能變回去。停。
   ⇒ 📌 09-10 實例:叫車那顆鈕按下去 = 一台真的車開過來。而【閘預設關】就是為了這個。

② 它會不會【蓋掉一個已經存在的事實】?
   ⇒ 會 ⇒ 🔴 停。(改一個已寫入的欄 · 刪一列 · 覆蓋別人的標記)
   ⇒ 📌 09-10 實例:那兩枚查證章我【append 第二枚】而不覆蓋第一枚 ——
        刪掉它就看不出這一列是【怎麼前進的】, 只看得出它現在在哪。

③ 它會不會讓【下一個人讀到一個假的答案】?
   ⇒ 會 ⇒ 🟡 做, 而【把限定詞跟著數字一起寫】。
   ⇒ 📌 09-10 實例:「近 24h 零失敗」那個 0 沒有判別力, 而它印出來像一個答案。
```

### 🔵 而幾件今天已經有答案的(不要每次重問)

```
✅ 翻擋欄            不用 —— 他 09-10 逐字批過「依照推薦」
✅ 貼 migration      不用 —— 常設授權;而【前置閘紅了仍然停】
✅ 標查證章          不用 —— 只加不刪、態不動、token 不動
🔴 動 schema / 共用元件 / 權限 / 文案語氣   ⇒ 要他
🔴 而【碰錢的】      ⇒ 🛑 他 09-10 批的是【整包】不是逐格
                        ⇒ 📌 那不等於下一片碰錢的也批過了。要他。
```

## 二、🔵 一輪長什麼樣(09-10 那一夜證明有效的形狀)

```
① 派工:一句話說【要什麼】+ 一句話說【不要做什麼】
② 🔴 先報分母 —— 開工之前, 一個數字
③ 🔴 甲先報 —— 擋上線的那幾列【不要等整批做完才講】
④ 標記走信箱, 主視窗貼板(單一寫入者)
⑤ 收:一句話說做完了什麼、一句話說【還剩什麼沒人接手】
```

### 而三條紀律

```
⚪ 一列不超過兩分鐘。判不出來就【丁】, 而【丁一定要有東西】
   —— 「我判不出來, 因為 X」比一個猜的分類有用
🔴 分類【多一格】:乙*(觸發與客人數無關)
   —— 一個「等有客人再修」的清單, 會讓那幾列永遠等不到那一天
🛑 而【已標過的列不重查機制】—— 讀它自己的章, 直接判
```

## 三、🔴 夜跑會撞到的坑 —— 每一條寫成【開工前的一句自問】

> **這一節不是規則,是七句話。念完再開工。**

```
1. 「我讀的是【我這棵樹】還是 origin/dev?」
   📌 09-10:三個不同的窗各自讀到舊碼。而它不會紅, 它只是答錯。
   ✅ 便宜的做法:`git rev-parse HEAD:<那支檔>` 與 origin/dev 比 blob sha —— 不必 merge

2. 「我讀的是【標題】還是【列尾】?」
   📌 09-10:三次。而板上很多列的標題【被自己的內文推翻過】而標題沒改。
   ✅ 那一列最新的話在【最後一段】, 不在第一句。

3. 「我數的『擋』, 是不是把【不擋】也數進去了?」
   📌 09-10:主視窗數到 125, 而實際 34。整行 grep「擋」會撈到 ⟨不擋⟩。
   ✅ 而還有兩種錯法:數錯欄(標記裡的字也算)· 數到被劃掉的舊 token。

4. 「這一列的狀態, 真的在【態欄】裡嗎?」
   📌 09-10:一列 `doing` 同時裝著「已完成的一半」與「沒人領的一半」。
   ✅ 態欄答的是「有沒有人在做」, 不是「做到哪」。

5. 「我這把尺, 量得到我要量的東西嗎?」
   📌 09-10 至少十九次。而每一次印出來的東西【都完全正常】。
   ✅ 最便宜的解法:餵它一個【受詞不同而答案應該不同】的東西, 看它會不會變。
   ⇒ 而 09-10 最好的一次:我數「重複列」得到 4 組, 打開來看 —— 四組全是分隔線與表頭。

6. 「我要寫進板子的那一段, 裡面有【直線符號】或【收尾角括號】嗎?」
   📌 09-10:板上 1,013 個資料列有 248 列的格子裡有直線符號。
      而它今晚咬了三個窗, 其中兩次是【在描述那個坑的那一句上】咬的。
   ✅ 自驗五格:行數不變 · 原文完整保留 · 形狀是查證標 · 欄數不變 · 收尾直線之後為空

7. 🔴 「這個名字, 在別的地方是不是【另一件事】?」
   📌 09-10 兩次:`emark` 在送單是【備註】而在叫車是【派遣者】——
      而新竹自己的 PDF 目錄與內文對同一支 API 也講兩種。
   ✅ 而這一條【沒有工具擋得住】—— 只有「同一個名字出現兩次的時候多看一眼」。
```
