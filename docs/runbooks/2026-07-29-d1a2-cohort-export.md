## 執行

先設連線字串(**同早上那條**,直接用 1Password 裡那組):

```bash
export D1_DB_URL='...'
```

再跑這一段:

```bash
cd /Users/sean_1/pcm-website-v2 && \
npx tsx scripts/d1-export.ts ~/d1-backup-20260729-v2 > /tmp/d1-export.sql && \
test -s /tmp/d1-export.sql && \
psql "$D1_DB_URL" -v ON_ERROR_STOP=1 -f /tmp/d1-export.sql && \
( cd ~/d1-backup-20260729-v2 && shasum -a 256 *.csv > checksums.txt ) && \
echo "匯出完成"
```

🔴 **校驗碼一定要在資料夾裡面產(先 `cd` 再 `shasum *.csv`)。** 在外面產的話,
`checksums.txt` 每一行會記**絕對路徑**;半年後把備份解壓到別的位置,驗證會跑去找
原本那個早就被刪掉的路徑 —— 輕則卡死,重則**驗到的是另一包檔案、載入的是這一包**,
校驗形同虛設。

🔴 **這次不用管線接 psql**(早上那版是 `... | psql`)。zsh 預設不把管線前段的失敗
當成整條失敗 —— 產生器若在吐出任何 SQL 前就掛掉,psql 讀到空輸入照樣回報成功,
你會拿到一個空資料夾加一句「匯出完成」。改成先產檔、驗非空、再餵給 psql。

🔴 **`&&` 不能改成分號。** 用分號的話,匯出失敗了校驗碼還是會產出來,
你會拿到一份「有校驗碼但內容不全」的備份。

**看到 `匯出完成` 四個字才算成功。** 沒看到就是中途停了,把畫面訊息貼回來給我。

## 收尾:加密與保存

規格要求這份備份**加密後保存 180 天**,金鑰放 1Password。

```bash
cd ~ && tar czf d1-backup-20260729-v2.tar.gz d1-backup-20260729-v2 && \
age -p -o d1-backup-20260729-v2.tar.gz.age d1-backup-20260729-v2.tar.gz && \
echo "加密完成"
```

`age -p` 會問你要設什麼密碼 —— **那組密碼存進 1Password**,不要記在腦子裡也不要貼對話。

加密完之後可以刪掉未加密的資料夾與 tar 檔。

> ⚠️ `age` 這個工具本機可能還沒裝(`brew install age`)。
> 不想裝的話跟我說,我改成用系統內建的方式加密。
