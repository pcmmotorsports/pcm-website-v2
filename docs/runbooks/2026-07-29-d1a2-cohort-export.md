# D1a2 正式匯出 —— Sean 操作包

> **這一步是把 26 張要刪的訂單(加 3 張要留的)完整備份下來。**
> D1c 刪掉之後,這份檔案是**唯一**能把資料救回來的東西,要保存 180 天。
>
> 🔴 這一步**不會刪任何東西、不會改任何東西** —— 匯出是唯讀的,而且腳本自己開的是
> 唯讀交易,連寫都寫不進去。做錯最壞的結果是「檔案不對」,不是「資料壞掉」。

## 你需要準備的兩樣東西

**① 資料庫連線字串**(正式站、以 `postgres` 身分)

腳本開頭有一道守門,以下任何一種情況會**當場中止、不會產出半套檔案**:
- 不是以 `postgres` 身分登入
- 連到的不是正式站那座資料庫叢集
- 那 29 張訂單不是全都在(少一張、或編號對不上)

**② 一個空資料夾**放輸出。建議放在你自己的機器上、不要放專案資料夾裡(避免不小心 commit 進 git)。

```bash
mkdir -p ~/d1-backup-20260729
```

## 執行(一行,兩段用 && 串接)

```bash
cd /Users/sean_1/pcm-website-v2 && \
npx tsx scripts/d1-export.ts ~/d1-backup-20260729 | psql "$D1_DB_URL" -v ON_ERROR_STOP=1 && \
shasum -a 256 ~/d1-backup-20260729/*.csv > ~/d1-backup-20260729/checksums.txt && \
echo "匯出完成"
```

把 `$D1_DB_URL` 換成實際連線字串,或先 `export D1_DB_URL='...'`。

🔴 **`&&` 不能改成分號。** 用 `&&` 的話,前一段失敗就不會跑下一段;
用分號的話,匯出失敗了校驗碼還是會產出來,你會拿到一份「有校驗碼但內容不全」的備份。

**看到 `匯出完成` 四個字才算成功。** 沒看到就是中途停了,把畫面訊息貼回來給我。

## 收尾:加密與保存

規格要求這份備份**加密後保存 180 天**,金鑰放 1Password。

```bash
cd ~ && tar czf d1-backup-20260729.tar.gz d1-backup-20260729 && \
age -p -o d1-backup-20260729.tar.gz.age d1-backup-20260729.tar.gz && \
echo "加密完成，原始資料夾可以刪了"
```

`age -p` 會問你要設什麼密碼 —— **那組密碼存進 1Password**,不要記在腦子裡也不要貼對話。

加密完之後可以刪掉未加密的資料夾與 tar 檔。

> ⚠️ `age` 這個工具本機可能還沒裝(`brew install age`)。
> 不想裝的話跟我說,我改成用系統內建的方式加密。

## 🔴 一條時效規定

**這份匯出的有效期是 24 小時。**

如果從匯出到你批准 D1c 執行之間超過 24 小時,**必須重跑一次匯出** ——
因為這段時間資料可能已經變了,拿舊備份去對照就對不上。
