# 開新員工後台帳號時的檢查清單

> 什麼時候用：Sean 要幫新員工開後台帳號、或第一位真員工開始用後台的那一天。
> 為什麼有這張清單：很多權限設定當初的理由是「目前只有 Sean 在用後台」。真員工開始用之後，這些就要回頭確認一次。Sean 2026-10-03 選甲：用這張清單，不做自動提醒。

## 開帳號當天，逐項確認

1. **每位員工用自己的帳號登入，不要共用。**
   - 不要讓員工共用「員工 1（占位）」或「Sean 測試帳號」登入。
   - 第一位真員工上工後，把「員工 1（占位）」和測試帳號停用。
   - 為什麼：操作紀錄是用登入的帳號記的。共用帳號的話，哪筆是誰做的分不出來。

2. **新帳號的「管理者」預設是關的。**
   - 除非這位員工需要看商品成本、或要改手動商品的一般價與經銷價，否則不要開管理者。
   - 為什麼：只有管理者看得到成本、也只有管理者能改手動商品的價格。一般員工不需要這些，開了等於多給權限。

3. **確認後台要求真實身分登入。**
   - 正式環境的 `ADMIN_REQUIRE_REAL_IDENTITY` 應該是開著的（目前已開）。這會擋掉共用密碼那種登入，逼每個人用自己的身分。

4. **第一週看一次「操作紀錄」頁。**
   - 確認紀錄上顯示的是那位員工的名字，不是占位帳號或測試帳號。
   - 如果看到操作顯示成占位帳號或 Sean，表示有人還在用共用帳號，回到第 1 點處理。

## 新員工要知道的一件事

- 客人的收件人、電話、地址，**所有員工都可以改**（Sean 2026-09-15 的決定，這是設計，不是漏洞）。改這些會留在操作紀錄裡，所以請員工只在客人要求時改，不要隨意動。

---

這張清單只是流程提醒，不改任何程式或權限。要調整內容隨時改這一頁即可。
