## 五、怎麼知道「真的送出去了」——**開送前先記,開送後再看**

開送**之前**先請一個窗幫你唯讀查一次,記下這三個數字:
```
① 系統裡總共有幾箱          ② 其中「送出過的」有幾箱(開送前應該是 0)
③ 沒有被刪掉的箱有幾箱
```
🔴 **第 ③ 個數字今天是 0**(2026-09-05 量的)—— 意思是**現有那幾箱都已經被刪掉了**。
⚠️ 那很重要:**任何「只看沒刪的箱」的查詢今天都會回空,而那跟「沒有資料」長得一模一樣。**

送完之後再查一次:**②那個數字要從 0 變成 1**。那就是「真的送到了」。
🔵 而查的人要同時餵一個**不存在的狀態**當對照 —— 它必須回 0,證明那把尺是活的。

## 六、怎麼停(**這一節請整段讀完再開始**)

**要停下來的時候,把開關關掉。而關掉不是一秒的事:**

🔴🔴 **改了那個設定之後,要【重新部署一次】才會生效 —— 不重新部署就不會停。**
🔴🔴 **而切換的那一刻【已經在路上】的請求,停不住。**

⇒ 所以停送之後**還沒完**:要把「切換前後那段時間裡」所有狀態是「未知」的箱**逐箱查一次**,
　 確認新竹那邊到底收到沒。⇒ 🛑 **關掉開關 ≠ 沒有貨在路上。**
