## 二、按之前:這五題你要能自己回答。**任何一題答不出來 ⇒ 今天不送。**

> 🔴 **「答不出來」也是一個答案** —— 它的意思是「今天不送」,不是「應該沒問題吧」。

**① 我們現在連過去的那個網址,是新竹的【練習場】還是【真的會出貨】的地方?**
　🔴 **今天沒有人知道。** 這一格**未量**,而它是這五題裡最重的一題 ——
　　猜錯的兩個方向都很糟:以為是練習場而其實會真的出貨(一箱貨莫名其妙送出去)、
　　以為是真的而其實是練習場(以為送成功了,而客人永遠收不到)。
　✅ **怎麼答**:打電話問新竹,或請他們用白紙黑字回一句。**不要從網址長相猜。**

**② 新竹有沒有給我們一張「資料要長什麼樣」的完整範例?**
　🔴 **沒有。** 他們給的那份 PDF 裡**一個範例都沒有**(全文含範例格式的行 = 0)。
　　已經跟他們要了,還沒拿到。
　🛑 **在拿到之前,不准拿第一張【真的訂單】去試。** 用真單去試 = 拿客人的貨當實驗品。

**③ 如果那一箱卡住了,我們有沒有辦法把它救出來?**
　✅ **有。** `docs/runbooks/hct-unknown-stuck-manual-reset.md`。
　⚠️ 而那份的第 0 步是【什麼時候不准改】—— **按第一箱之前先讀完那一節**,
　　不然出事當下你會在壓力下做那份文件明講不要做的事。

**④ 這一箱是真的要送的貨嗎?**
　🛑 **不要用測試單送第一箱。** 送出去就是一張真的託運單,新竹那邊會收到。
　⇒ 第一箱請挑一張**你自己認得、地址你確認過**的真單。

**⑤ 你人在電腦前嗎?** 🛑 **要。** 第一箱不可以「開了開關就去睡」—— 按下去之後有幾種結果
　需要當場決定(見第四節),而其中一種**越晚處理越糟**。

## 三、開送的步驟(**一次一箱**,不要一次開一批)

1. **先記下現在的數字**(見第五節)—— 沒有這一步,你事後沒辦法證明「真的送出去了」。
2. 打開開關(Vercel 上那個設定,名字見附註 A)⇒ 🔴 **然後要重新部署一次才會生效**(見第六節)。
3. 後台找到那一箱 ⇒ 按「送新竹」。
4. 🔵 **第一次按可能不會送** —— 收件人姓名/電話/地址太長時系統會**先停下來**告訴你哪幾欄會被截短,
　 你看過再按第二次才真的送。**那不是壞掉**,它不讓系統靜靜把客人的地址剪掉送出去。
5. 看結果 ⇒ 照第四節做。
6. **這一箱完全處理完之前,不要送第二箱。**

## 四、按下去之後,三種結果各自怎麼辦

| 畫面說 | 意思 | 你要做什麼 |
|---|---|---|
| **送出成功** | 新竹收到了,我們也拿到貨號 | ✅ 正常。去第五節對一次數字。 |
| **送出失敗** | 新竹明確拒絕了 | 看錯誤訊息修好資料,**可以再按**。 |
| **送出結果未知** | 🔴 **我們不知道新竹收到沒** | 🛑 **不要再按那顆鈕。**再按可能會變成新竹那邊的**第二張託運單**。<br>照 `hct-unknown-stuck-manual-reset.md` 走。 |

> 🔴 **「送出結果未知」是刻意的**:系統在**送出去之前**就先把狀態改成「未知」,
> 這樣萬一送出去那一瞬間程式掛掉,下次也不會傻傻重送
> (`shipment-submit-hct-action.ts:164` 逐字:「送出【之前】先把狀態推成 `unknown`」)。
> 🛑 **而「未知」有兩個世界,畫面上一模一樣**:①新竹收到了而我們沒記到
> ②**新竹根本沒收到**(同檔 `:168` 逐字:「HTTP 發出去【之前】行程被砍 ⇒ 新竹從來沒收到,
> 而 DB 永久是 unknown」)。⇒ 📌 **所以它的出口是【去查】,不是【再按一次】。**

## 五、怎麼知道「真的送出去了」——**開送前先記,開送後再看**

開送**之前**先請一個窗幫你唯讀查一次,記下這三個數字:
```
① 系統裡總共有幾箱          ② 其中「送出過的」有幾箱(開送前應該是 0)
③ 沒有被刪掉的箱有幾箱
```
🔴 **第 ③ 個數字今天是 0**(2026-09-05 量的)—— 意思是**現有那幾箱都已經被刪掉了**。
⚠️ 那很重要:**任何「只看沒刪的箱」的查詢今天都會回空,而那跟「沒有資料」長得一模一樣。**

送完之後再查一次:**②那個數字要從 0 變成 1**。那就是「真的送到了」。
🔵 而查的人要同時餵一個**不存在的狀態**當對照 —— 它必須回 0,證明那把尺是活的。

## 六、怎麼停(**這一節請整段讀完再開始**)

**要停下來的時候,把開關關掉。而關掉不是一秒的事:**

🔴🔴 **改了那個設定之後,要【重新部署一次】才會生效 —— 不重新部署就不會停。**
🔴🔴 **而切換的那一刻【已經在路上】的請求,停不住。**

⇒ 所以停送之後**還沒完**:要把「切換前後那段時間裡」所有狀態是「未知」的箱**逐箱查一次**,
　 確認新竹那邊到底收到沒。⇒ 🛑 **關掉開關 ≠ 沒有貨在路上。**
