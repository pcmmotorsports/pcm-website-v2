# 夜跑:subagent 怎麼開(2026-09-11 · 窗B 寫,材料是 09-10 那一夜)

> # 🎯 什麼時候讀這一份?
> ## **在你想「開 subagent 加快一點」的那一刻,而【還沒開】之前。**
>
> 🔵 **授權沒有問題**:鐵則 7 逐字「**讀取 / 搜尋 / 審查委派不用問**」⇒ 板子分類是讀取 ⇒ **不用批。**
> 🛑 **所以這一份不講「能不能」,只講【切在哪裡】與【什麼時候不值得】。**
>
> 📎 派工的操作面在 `2026-09-11-夜跑怎麼跑.md`(那一份是**派工之前念一遍**的)。

---

> ## 🔴 **先講一件事:今晚的瓶頸不是「做得不夠快」,是「做得對」。**
>
> 全隊撞了 **19 次**同一族的錯(尺量到的不是它要量的東西),
> 而**抓到它們的幾乎每一次都是【另一個人】** —— 不是原作者複查。
>
> 🛑 **而 subagent 是【隔離的】**:它做完交一份報告,**中間沒有人跟它對話**。
> ⇒ 📌 **一個很有自信的錯答案,與一個對的答案,在報告裡長得一模一樣。**
> ⇒ ⇒ **而那正是今晚十九次的形狀。**
>
> 🔵 **⇒ 所以不是「能不能開」,是「切在哪裡開」。**
> ✅ 而授權沒有問題:鐵則 7 逐字「**讀取 / 搜尋 / 審查委派不用問**」⇒ 板子分類是讀取 ⇒ **不用批。**

### 🟢 適合 subagent —— **【量】**

```
· 讀那一列在講什麼(它自己的字面)
· 跑那幾發唯讀 SQL
· grep 那幾支檔, 數那幾個數字
⇒ 判準:【每一列獨立, 不需要看別列】
```
🔴 **而它交回來的是【讀數】,不是【結論】。**

### 🔴 不適合 —— **【判】**

```
「這一列擋不擋上線」要看【今天的世界】—— 而世界今晚變了六次
```
🎯 **而今晚最好的三個發現,全部是【跨列】看出來的**:
```
· 「八列裡有六列的觸發, 都是我們自己動手」
· 「那三列的描述比事實舊」
· 「一列的頭跟身體說不同的話」(同一夜三次)
```
📌 **⇒ 那些東西,一個只看一列的 subagent 看不到。**

### 🔴 而兩條紀律要寫死

```
1. subagent 交【讀數】不交【結論】—— 而讀數要附出處(檔:行 / 那一發 SQL 的原文)
2. 🔴 窗要能講出「我憑什麼採信它」—— 而不是照抄
   ⇒ 📌 那就是「一個數字要帶著它的限定詞走」在 subagent 上的樣子
```

### 🔵 而【什麼時候不值得開】—— 給一個數字,不是「看情況」

```
❌ 剩 17 列 × 2 分鐘 ≈ 半小時 ⇒ 開 subagent 的來回成本差不多就吃掉了
✅ 划算的量級(夜跑那種):
     帶擋 110 列(已掃 88)· 無編號 138 列(完全沒碰過)· 有編號 729 列
```
🎯 **⇒ 門檻:那一批要【三位數】才開。兩位數自己做比較快。**

### 🛑 而順帶一個【現成的實例】,它就是這一份要教的事

```
「無編號那一族有幾列」——  一個窗說 194 · 另一個窗說 138
🔴 而【沒有人去對過】。而採用 138 的理由不是「它比較小」,
   是【那個窗自己量的, 而 194 是轉述】。
```
📌 **⇒ 兩個數字對不上的時候,先問【受詞】,不要挑一個。**
🎯 **而那正是 subagent 最會製造的東西:兩份報告各自正確,而它們數的不是同一件事。**
