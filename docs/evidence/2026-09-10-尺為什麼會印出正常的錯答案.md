## 0 為什麼要分類,而不是列十八條

十八條的形狀不同,而**它們的防法不同**。列成一條會得到一句「要小心」,而那不是可以照做的東西。
📌 **而分成十八種也沒有用** —— 那只是把清單改個標題。

**分成五類,而每一類有一個【問它的問題】。**

## 甲 · 受詞錯了 —— 尺量的不是你以為的那個東西

**它長什麼樣**:尺沒有壞,它認真量了**另一個東西**,而回來的仍然是一個合理的數字。

```
【自量】Range.getClientRects().length 數「這段字幾行」⇒ 回 3
        而那顆鈕裡有一個 <svg>, 它的 path 各自有 rect ⇒ 受詞是「範圍裡所有的 box」
【自量】grep 錨 | head -1 ⇒ 撈到【別人引用那個錨】的那一列, 不是它自己那一列
【自量】1,646(單一列直接數)vs 1,640(整棵子樹 rollup)—— 我把它讀成「差 6 件」
【自量】pcm_readonly 的 rolbypassrls = t ⇒ 我查到的是【我的世界】不是【客人的世界】
        products 差 559 · product_variants 差 721
【轉述】整列 grep「擋」⇒ 撈到擋欄開頭是 ⟨不擋⟩ 的列(受詞是「整列」不是「那一欄」)
【轉述】拿函式名去問一個 view
【轉述】/0 件/ 偵測空頁 ⇒ 被「164【0 件】商品」餵飽(受詞是子字串不是整個欄位)
```

### 🎯 下一次怎麼先發現
**問一句:這把尺的受詞是什麼?然後找一個【受詞不同而答案應該不同】的東西餵它。**
- 要數「幾行字」⇒ 餵它一個**只有圖沒有字**的元素,它應該回 0。
- 要找「那一列」⇒ 餵它一個**只被引用而不存在**的錨,它應該回 0 列。
- 要問「客人看得到幾件」⇒ 找一件**已下架**的,它應該不在裡面。

### ⚪ 正對照擋得住嗎
```
🔴 擋不住(而這一類最容易被正對照騙)
   【轉述】a9 用零參數簽章問函式在不在 ⇒ 七支帶參數的全印「不存在」
           而它的正對照【自己也是零參數的】⇒ 正對照過了, 而錯照樣在
🟢 擋得住的長相:正對照與受測對象【同形狀】
   —— 要問帶參數的函式, 正對照就要用一支帶參數的
```
📌 **⇒ 甲類的規則:正對照要【同形狀】。**

## 乙 · 尺壞了,而它的壞沒有變成「壞」

**它長什麼樣**:尺失敗了,而失敗被包裝成一個**值**,於是 `|| 失敗處理` 那條路一次都不會走。

```
【自量】git rev-parse "<sha>:<不存在的路徑>" ⇒ 印 fatal 到 stderr,
        而【同時往 stdout 吐了那顆 commit sha】⇒ 我的 `|| echo "-無-"` 沒有救到我
        ⇒ 六支我新建的檔全部被誤判成「基底 = efe3894eef01」
【自量】psql -f 沒有 ON_ERROR_STOP ⇒ 中間炸掉後面照跑, 而 rc 仍是 0
【自量】裸 grep -c ERROR 會把【那句叫人去掃 ERROR 的提醒】自己數進去
【轉述】echo 出來的假標籤 · 壞掉的計數器
```

### 🎯 下一次怎麼先發現
**餵它一個【一定不存在】的輸入,看它回什麼。**
- 回空 / 回 0 / 真的非零 rc ⇒ 尺活著。
- 回一個看起來像答案的東西 ⇒ **那把尺不能用**。

### ⚪ 正對照擋得住嗎
```
🔴 完全擋不住 —— 正對照走的是【成功】那條路, 而壞的是【失敗】那條路
🟢 擋得住的是【負對照】, 而且它必須餵【尺會失敗】的那種輸入, 不是【答案是 0】的那種輸入
   ⚠️ 那兩者不一樣:
      「查一個不存在的商品」⇒ 尺成功而答案是 0
      「查一個不存在的【路徑】」⇒ 尺自己失敗
   📌 而只有後者驗得到這一類
```
🎯 **⇒ 乙類是「加正對照」唯一完全沒用的一類。**

## 丙 · 尺只看得見它已經知道的形狀

**它長什麼樣**:尺找的是**一種寫法**,而同一件事有第二種寫法,於是那些對它隱形。

```
【轉述】a9 用 grep 數 adapter 碰哪些函式 ⇒ 漏掉一支,
        因為那支的名字【住在一個常數裡】, 呼叫點是內插沒有那個字面
        ⇒ 📌 它不會少印一個警告, 它會少印一整支, 而印出來的 16 看起來像完整的分母
【自量】我用 grep 數「11 支檔還在用舊判準」⇒ 今天命中 26 支, 大半是 migration 歷史檔
        ⇒ 受詞是「repo 裡提過這個字的檔」, 不是「今天在擋客人的那個判準」
【自量】migration 靜態閘讀的是【碼長什麼樣】⇒ 它對【碼做什麼】沒有判別力
【轉述】6d 的尺只找得到它已經知道的東西
```

### 🎯 下一次怎麼先發現
**問:有沒有一種【合法而不同】的寫法會讓它隱形?然後故意造一個。**
（那就是突變:把受測對象改成另一種合法寫法,尺應該還是要抓到。）

### ⚪ 正對照擋得住嗎
```
🟡 擋得住一半 —— 而【方向與甲類相反】
🔴 正對照若與受測對象【同形狀】⇒ 它會過, 而錯照樣在
   (grep 字面的尺, 用一個字面寫的正對照去驗 ⇒ 當然過)
🟢 擋得住的長相:正對照要【不同形狀】—— 把名字放進變數, 看尺還抓不抓得到
```
🔴🔴 **⇒ 而這裡是本文最該記的一格:**
> **甲類要「正對照同形狀」,丙類要「正對照不同形狀」。**
> 📌 **同一句「加正對照」在兩類裡指的是相反的動作 —— 所以「有沒有加正對照」不是一個可以打勾的欄位。**

## 丁 · 格子沒有判別力 —— 兩個世界印同一個東西

**它長什麼樣**:每一把尺都對,而那一格**在對的實作與錯的實作下印同一個數**。

```
【自量】我的行為閘斷言 FIRE 必須回 0 ⇒ 而 FIRE 真的會回 19(從別的區塊)
        我的 fixture 剛好沒有 subtitle ⇒ 給了一個假綠
【轉述+自算】a2 挑「含稅 11」當判別格 ⇒ 我自己算:half-up 下兩法【都給 11】
【轉述+自算】改成「含稅 10」⇒ banker's 下兩法【都給 10】
        📌 兩次都挑到那個 `.5` 上, 而 `.5` 正是兩種捨入唯一會分岔的地方
【轉述+自算】混合列「含稅 1,100 + 未稅 1,000 ⇒ 2,150」⇒ 整包正推也給 2,150
【自量】「已取消的單身上有信 ⇒ 0」—— 而分母也是 0 ⇒ 那個 0 什麼都沒證
```

### 🎯 下一次怎麼先發現
**對每一格問:有沒有一種【錯的實作】也會過?而且要【算一次】,不是想一次。**
🔵 而有一個結構性的做法(今天在稅那一片用出來的):
```
把「錯的實作」也列成一個集合, 取【兩個集合的交集】來挑格子
  半數捨入 half-up 分岔 952 個 · banker's 分岔 952 個 · 而交集只有 476
  ⇒ 從交集裡挑(31 · 73 · 115 …, 公差 42)⇒ 兩種錯法都擋得住
📌 而「兩邊都是 952」曾經被當成「對上了」—— 同樣是 952, 可以是不同的 952。
```

### ⚪ 正對照擋得住嗎
```
🔴 擋不住 —— 正對照證的是【尺會動】, 不是【這一格分得開兩個世界】
   我今晚驗頁面時的正對照(頁面讀得到「維修零件」四個字)完全過, 而那與判別力無關
🟢 擋得住的是【反向突變】:故意做一個錯的實作餵那一格, 它必須紅
   —— 我那支 migration 的行為閘就是這樣抓到自己的假綠的
```

**它長什麼樣**:全綠,而綠的是**一句已經不成立的話**。沒有任何東西會變紅。

        它會【安靜換一個行為】。函式在 ✅ 呼叫端在 ✅ 測試綠 ✅, 差別只在回什麼
【自量】「migration 貼了」與「那件事做完了」是兩個宣稱, 而 prosrc 只量得到前一個

**量之前先問:這句話是誰、在什麼時候寫的?它的前提今天還在嗎?**
