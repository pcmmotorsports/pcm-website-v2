## 1-b 🔴 三格擺在一起才看得出來的兩件

```
① 三格【全部】在 Supabase 或 Vercel 的面板上, 沒有一格在我們的 repo 裡
   ⇒ 📌 我們所有的守門機制(三綠 / husky / codex / migration 閘)對它們是【全盲】的

② 三格的「今天狀態」是三種不同的東西, 而它們在文件上長得一樣:
   ① 關的(保護在)     —— 而它是【一個可以被點掉的設定】, 不是資料庫層的保護
   ② 開的(保護沒在)   —— 而那不是意外, 是【還沒有人去打開它】
   ③ 量不到           —— 而「量不到」不是「沒事」
   🔴 ⇒ 三種都可以被寫成「今天沒問題」, 而它們的下一步完全不同
```
