## 判準(不是我的品味,是可以照著檢查的)

每一句砍完之後**仍然要答得出兩件事**:
```
① 發生什麼事
② 我現在該做什麼
```
🔴 **砍掉之後有一件答不出來 ⇒ 砍太多,退回去。**
🔵 **而原文本來就答不出②的 ⇒ 那不是要砍,是要補** —— 那種句子**會變長,而那是對的**。表裡標「補②」。

### 🛑 三種字不准砍
```
1. 金額 · 單號 · 箱號 · 料號 —— 你要拿去對的東西
2. 「不可逆」「已寄出」「已作廢」這一類【後果】—— 砍掉它, 人會按下去
3. 錯誤訊息裡的【量法】—— 說我量了什麼, 不要只說什麼壞了
```

## 怎麼讀這張表

`docs/evidence/2026-09-10-後台提醒文案對照-第一批.tsv` 是同一份資料的機器可讀版,六欄:
```
在哪(檔:行) ⇥ 情境 ⇥ 現在的字 ⇥ 現在字數 ⇥ 建議的字 ⇥ 建議字數 ⇥ 為什麼改
```
🔵 **「建議的字」寫「不改」的那些是刻意的** —— 它們本來就答得出①②,而**為了平均字數去動它們只會變成換同義詞**,那不是你要的。
