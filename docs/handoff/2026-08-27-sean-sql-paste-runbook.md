## 🔴 零、先做這一件 —— 不做的話你複製到的可能是【空的】

**本檔量到:`cat <檔> | pbcopy` 在 locale 沒設的 shell 裡, 對中文內容會複製出【空白】, 而 `pbcopy` 回 rc=0。**

```
量到(2026-08-27 當場):
  LANG / LC_ALL / LC_CTYPE 三個都是空的 ⇒ 中文短字串 `中文測試-l1` 進 pbcopy ⇒ pbpaste 回【空】
  純 ASCII `abc`                        ⇒ pbpaste 回 `abc`   ← 所以「剪貼簿壞了」這個說法是錯的
  加上 LC_ALL=zh_TW.UTF-8 或 en_US.UTF-8 ⇒ 中文正常
```
📌 **失敗是安靜的**:`pbcopy` 不報錯、rc=0, 你只會貼出一片空白, 或貼出半截。

### ⇒ 複製時用這一行(每一支都一樣, 只換檔名)

