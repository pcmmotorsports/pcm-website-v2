| 收入分類 | 三項 | 商品銷售(訂單自動)/ 現場收現 / 其他。逐字:「訂單客人來現場付款,收現金,剩下就寫其他」 |
| 報表 | **全選 + 自訂區間** | 逐字:「都要,還有其他支出、收入的統計,到時候還要可以讓我選擇幾月幾號到幾號」⇒ **「月報表」正名為「區間報表」** |
| 報價單 | **作廢不用** | 逐字:「那些都是手 key 的報價單,不重要,因為夾雜很多假的」⇒ 相關發現(×1.2 加價率、`=TODAY()`、跨表列號錯開)**全部撤回** |
