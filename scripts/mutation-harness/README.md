# TS 突變 harness —— 而它存在的理由是【手跑會成功】

> 2026-09-08 · 線【退款】`-refund` · 為 `#787` 開封那片寫的,而寫完之後**我自己先手跑了三發**。
> 主視窗 A 叫我補跑,而**補跑的數字與手跑不同** —— 那個差就是本支的價值。

## 🔴 為什麼需要它(而理由不是「比較嚴謹」)

```
🛑 手跑每一次都成功, 所以【沒有訊號叫我停】
⇒ 而成功的手跑, 與用了 harness 的成功, 在輸出上長得一樣
⇒ 📌 差別只在【下一次】:harness 會逼你做 M0 與前後對照, 手跑不會
```
🎯 **而它與一般的偷懶相反**:偷懶會讓**結果變差**;這個**結果一樣好** ——
**少掉的是【下一次會問的那些問題】。**
📌 **⇒ 手跑少掉的不是正確性,是【知道自己知道多少】。**

**今晚那個差是具體的**:
```
手跑    ⇒ 「三發全咬」          ← 那是一個感覺
harness ⇒ 「0/4 ⇒ 4/4」        ← 那是一個數字
```

## 三條紀律(主視窗 A 2026-09-08 立;本支把它們做成機制不是提醒)

```
① 每發只退【一道】, 而記錄它紅在【哪一格】
   —— 一起退的那一發, 排除不掉「其實只有一道在守」
② 第一發固定 M0(不突變)且【必須綠】, 印在最上面
   —— 沒有它, 後面每一發的紅都可能是別的原因;M0 紅 ⇒ 本輪全部作廢
③ 同一發突變在【修之前 vs 修之後】各紅幾格 = 這次修法加了多少牙
   —— 那比「我補了 N 格測試」有意義(補 N 格可以一格牙都沒有)
```
🛑 **而「突變沒套用上」(anchor 對不上 / 餵 1 條而跑 0 支)一律計入【作廢】,不計入覆蓋。**
📌 **作廢不是殺死** —— 那一發什麼都沒問到,而它與「殺死」在綠數上都是「變少」。

## 🔬 2026-09-08 的實測(#787 開封那片)

| | M0 | M1 送出鈕永遠 disabled | M2 金額欄改名 | M3 整個 fieldset 停用 | M4 `<form>` 換成 `<div>` |
|---|---|---|---|---|---|
| **簡版**(只有兩行字串斷言) | ✅ 綠 | 🔴 存活 | 🔴 存活 | 🔴 存活 | 🔴 存活 |
| **現版**(section 內驗結構) | ✅ 綠 | ✅ 殺死 | ✅ 殺死 | ✅ 殺死 | ✅ 殺死 |

**⇒ `0/4` ⇒ `4/4`。那四格加了【整整四顆牙】,一顆都不是裝飾。**
🛑 **而「簡版存活 4」的意思很硬**:那個版本裡,**送出鈕永遠按不下去、金額欄不見了、
整組欄位停用、表單根本不是 `<form>`** —— **四種世界它全部印綠。**
📌 **而它會綠,是因為那兩行斷言問的是「畫面上有沒有那幾個字」——
而那幾個字【在四種壞掉的世界裡都還在】。**
🎯 **⇒ 那不是「測得不夠細」,是【那格測試與它宣稱要證的事沒有關係】。**

## ⚠️ 這組數字【證不到】什麼(不要讀得比它寬)

```
① 「簡版」是【重建的】—— 它從來沒有被 commit 過(我在同一輪裡就加強了)
   ⇒ 那個 0/4 是對【一個重建的基準】量的, 不是對一個歷史版本
   ⇒ 而重建它的是 to-simple.py, 那支檔頭也寫了同一句
② 四發都紅在【同一格測試】—— 而【紅的那一句】不同, 那才是「四道各自在守」的證據
   🛑 而本支的擷取寬度只有 46 字 ⇒ 四發印一樣 ⇒ **這一發沒有直接證明它們紅在不同句**
   ⇒ 我是從先前手跑那三發知道的。**擷取寬度是下一次要修的。**
③ 突變都打在【表單元件】上, 不打在測試上 —— 測試是量具, 量具不該被突變
```
