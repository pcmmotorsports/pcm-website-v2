# literal-sweep.sh --selftest 的【獨立答案卷】
#
# 🔴 它為什麼要獨立成一支檔(2026-08-29 -c8;code-reviewer R1 第 2 題抓到):
#    原本 probe 的期望字串與被 probe 的 print 字串【逐字相同、而且同一支檔】
#    ⇒ 有人做一次全域換字面(sed / 編輯器的取代全部)⇒ 兩處【一起】被改掉
#    ⇒ probe 仍然找得到它自己要找的東西 ⇒ 自檢全綠、rc=0
#    ⇒ 而輸出裡那句話已經變成別的字了。
#    實測(2026-08-29):七條限度 + 類別符號 ①，八處【全部】換完仍 rc=0。
#    ⚠️ 而【全域換字面】正是 literal-sweep 服務的那個動作 ⇒ 那道守門對它自己的使用場合失明。
#
# 📌 所以:改了 .sh 裡的限度文字 ⇒ 【必須】同時改這裡, 否則自檢會紅。
#    那個「必須同時改」不是麻煩, 它就是這道守門的全部價值 ——
#    它強迫換字面的人【看見】他換掉了什麼。
#
# ⚠️ 天花板:一次跨【兩支檔】的全域取代仍然會同時改掉兩邊。
#    本檔擋的是「在 .sh 上做取代」那一種, 不是所有的取代。
#
# 🔴🔴 第二個天花板(2026-08-29 線B 提醒 ⇒ `-c8` 當場構造出來的):
#    **這道守門問的是「那個字串在不在」, 而【突變體可以逐字保留它, 同時把內容掏空】。**
#    實測:把 `print("  2. 跳過的目錄:…")` 換成 `print("  2. 跳過的目錄 —— 本條已作廢, 不必理會")`
#    ⇒ 逐字保留了期望字串 ⇒ **自檢 rc=0 全綠**, 而那一條限度已經沒有內容了。
#
#    📌 **而這是【天花板】不是 bug** —— 任何「字串在不在」的斷言都擋不住這個:
#    「這句話還是不是它原本的意思」是語意判斷, 不是字面命中。
#    ⚠️ **而我刻意【不】加「不准出現『已作廢』這種詞」的補丁** ——
#       那會變成另一張詞表, 而詞表的分母是【我們想得到的詞】、病的分母是【任何人會打出來的詞】。
#       (同一個病寫在 guard-and-instrument-traps.md 的 ⑤ 那一條。)
#
#    ⇒ **所以這道守門的綠, 只能讀成:「那七句話的字面還在」** ——
#       **不能讀成「那七條限度還成立」。**
#
# 🔴 而線B 那句原話值得留(它與另一條【方向相反】, 不要合成一句):
#    「錨要釘【突變體不會產生的結構】, 不是『有沒有東西』。」
#    (另一條是「不要釘合法世界裡可能為空的集合」—— 兩條都是射程問題,
#     合起來講會變成一句沒有用的話。)
#
# 🔴🔴 2026-08-29 R1 之後改成【整段逐字】而不是七條子字串:
#    code-reviewer 實作並跑過 —— 子字串錨擋不住「逐字保留那句話而把內容掏空」;
#    整段錨擋得住, 而它【一個詞表都不用】。
#    ⇒ 原本作者判「任何字串在不在的斷言都擋不住」是【放大了一格】:
#      正確的是「檢查【子字串】在不在的斷言擋不住」—— 錯的是【錨的粒度】, 不是字面 vs 語意。
#
# ⚠️ 殘餘天花板(誠實那部分, reviewer 給的):整段錨擋的是【輸出文字】被改。
#    它擋不住「限度說的是真的, 而工具行為改了」—— 例如限度 3 寫「一個檔只歸一類」
#    而 BUCKETS 被改成會重複計數。那要把限度變成【可執行斷言】, 是另一片。
